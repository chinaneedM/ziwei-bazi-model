# 八字胎元、命宫、身宫确定性坐标 R1

## 范围

本轮补充三个只读排盘坐标：胎元、命宫、身宫，并在四柱栏补充“自坐”十二长生。所有结果随候选盘写入视图哈希，只表示古法规则下的干支或阶段身份，不生成旺衰、格局、用神、喜忌或吉凶结论。

## 冻结口径

profile 为 `BAZI-DERIVED-COORDINATES-YHZP-R1@1.0.0`。

| 坐标 | 当前规则 | 来源索引 |
| --- | --- | --- |
| 胎元 | 月干顺一位、月支顺三位 | `S11:YHZP-ROOT-020-0003`、`S11:YHZP-ROOT-020-0004` |
| 命宫 | 子上起正月逆排至出生月，将出生时支落在月位，顺数至卯；宫干按年干五虎遁 | `S12:SMTH-SEG-01154`、`S12:SMTH-SEG-01155`、`S11:YHZP-ROOT-023-0003` |
| 身宫 | 与命宫采用同一出生月时坐标，顺数至酉；宫干按年干五虎遁 | `S11:SHFTK-CL-001-原-001-001`、`...003`、`...006` |

月份采用八字内核已经确定的节令月支，固定换算为寅月一、卯月二，依次至丑月十二；它不读取或覆盖紫微历法日期，也不改变紫微换日规则。

来源算例被固化为回归门：己巳月胎元为庚申；甲子年三月戌时命宫为丁卯，同坐标下身宫为癸酉。

## 异本保留

`S12:SMTH-SEG-01138` 所载“生日前三百日”胎元法作为 `SMTH-CONCEPTION-DATE-MINUS-300-DAYS-R1` 保留，状态为 `PRESERVED_NOT_SELECTED`。该法需要独立选择受胎日期学说，当前不静默混入默认结果；后续启用时必须形成单独 profile 或候选盘。

## 输出与语义隔离

每个坐标输出干支、六十甲子序号、规则 ID、来源索引和计算基据，并标记 `DERIVED_COORDINATE_IDENTITY_ONLY_NO_INTERPRETATION`。汇总对象标记 `DERIVED_COORDINATES_ONLY_NO_INTERPRETATION`。

“星运”继续表示以日主天干为基准的十二长生；新增“自坐”表示每柱本干在本支的十二长生。两者只是不同基准下的阶段身份，不能直接推导强弱或吉凶。
