## 1. 上海图书馆公开馆目：正式入口存在 ≠ 该扫描文件已绑定馆藏实物

- 上海图书馆官网“数字人文”列出中文古籍联合目录及循证平台；其官方帮助说明提供 `gj.library.sh.cn/gjxz/index`，公开高校图书馆资源指引提供 `gj.library.sh.cn/org/shl`。上述均是可公开核对的**入口定位**，不是 `dGJ2312912` 具体原件的馆藏证据。
- GitHub Actions [12QD 官方访问探针](https://github.com/chinaneedM/ziwei-bazi-model/actions/runs/38044509548) 的可再现 artifact 为 `11667052185`。在公开匿名、未猜测任何物品 ID、未登录或绕过权限的前提下，两项上图古籍站点入口分别返回 **HTTP 412**；上图 `www.library.sh.cn/service/service/11` 和 `opendata.library.sh.cn` 首页均返回 **HTTP 200**；官方帮助博客存在执行环境 TLS 证书校验错误。
- 上图公开的《中文古籍开放数据接口说明》为部分比赛用 WebAPI 示例明确记录 API Key，另列 SPARQL 端点。这不等于全部古籍目录查询必须付费、全部数字图片受限，亦不授权尝试登录或猜测馆藏编号。
- **裁决：** 当前第一方精确目录项、物理副本编号、抄本／刻本年代、扫描与实体的交叉引用均 **UNBOUND**。HTTP 412 是本次执行环境的访问边界，不是全馆无此书的反证；次级“清初抄本”目录不能自动赋予本份 Commons 影像精确年代。
