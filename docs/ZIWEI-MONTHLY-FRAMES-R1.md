# 紫微流月确定性坐标 R1

本阶段只发布紫微斗数自身规则链中的流月事实，不复用或覆盖四柱八字的月柱、换日与晚子时规则。

## 已发布坐标

- 每个流年以该年斗君所在宫作为正月宫，二月至十二月顺行十二宫。
- 流月干支按五虎遁生成；流月命宫地址与流月干支分别存储，互不混淆。
- 每个流月绑定唯一父流年，并以流月天干激活该层四化；星曜本体位置不移动。
- 每个常规流月以流月天干生成独立的禄存、擎羊、陀罗动态实例；它们不与原局、大限或流年同名星曜合并。
- 对调用方明确请求的流年完整生成十二个常规农历月坐标，并进入事实哈希、计算哈希和完整性验证；未选择流年时不导出无用月帧。

## 闰月边界

古籍与流派对闰月安置存在分歧。R1 不把任一争议方案伪装成唯一事实，也不将闰月简单复制为常规月份。所有流月帧均携带：

- `calendar_scope=REGULAR_LUNAR_MONTH_COORDINATE`
- `leap_month_policy_status=UNRESOLVED_NOT_GENERATED`

后续只有在来源、规则身份和候选并存机制完整后，才会加入闰月候选帧。
