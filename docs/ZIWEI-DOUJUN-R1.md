# 紫微流年斗君确定性坐标 R1

## 范围

本轮将流年斗君（该流年农历正月宫位）纳入紫微时限状态、事实哈希、完整性复算、视图模型和 SVG 排盘。它只生成坐标，不生成流月吉凶或事件断语。

## 冻结公式

规则 ID 为 `S10-SUIJIAN-REVERSE-BIRTH-MONTH-FORWARD-BIRTH-HOUR-R1`：

1. 以目标流年地支宫为岁建并起正月；
2. 从该宫逆数至命主紫微盘采用的农历生月；
3. 在所得宫位起子时，顺数至命主紫微盘采用的出生时支；
4. 最终宫位即该流年的斗君／正月宫。

实现直接读取紫微本命结构的 `natal_month_coordinate` 与 `birth_hour_branch`。它不读取八字节令月、日柱或换日结果，因此不会把八字规则强加到紫微轨。

来源索引：`S01:ZZQS-A-1935`、`S10:ZZZA-A-1127`、`S10:ZZZA-A-1128`。时限规则集与算法版本由 `1.0.0` 提升为 `1.1.0`，使新增坐标进入计算凭证。

## 回归

- 古籍例：甲午年三月辰时，壬寅年斗君在辰；
- 文墨兼容案例：1994 年农历四月未时，子年斗君在辰；
- 每个流年帧均携带斗君地址与规则 ID；
- 篡改斗君地址会触发 `ANNUAL_DOUJUN_ADDRESS_MISMATCH`，并改变时限事实哈希；
- 选择流年时，十二宫视图及 SVG 只在一个宫位显示对应斗君标记。
