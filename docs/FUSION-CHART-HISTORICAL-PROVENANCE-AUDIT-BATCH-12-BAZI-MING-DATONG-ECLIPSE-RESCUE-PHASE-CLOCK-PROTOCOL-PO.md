# Fusion Chart Historical Provenance Audit R1 — Batch 12PO

## Ming eclipse rescue protocol: phase and actual-clock semantics

Status: **RESCUE REPORTING PROTOCOL CLOSED / DIRECT-OBSERVATION IDENTITY REJECTED / JINGTAI-1 PHASE + CLOCK STILL OPEN / MD-G03 OPEN**

12PN established the Jingtai-1 `卯正三刻` vs `辰初初刻` discrepancy at the Ming Shilu layer. 12PO tests whether the rescue protocol itself supplies the missing phase and clock semantics.

### 1. The official rescue workflow is forecast-driven

(萬曆)《大明會典》卷223 says Qintianjian first computes and submits eclipse `分秒時刻` together with `起復方位`. During the rescue rite a bureau official `專報時候`.

Crucially, when cloud/rain makes the eclipse invisible, the same protocol still has the bureau officer wait until `復完時` and report completion. Therefore ritual time reporting is not, by definition, direct visual phase detection.

### 2. The Jingtai-1 bare time still has no phase word

The 1450 Shilu says `月食當在卯正三刻` and that officials had predicted `辰初初刻`. It does not say `初虧`, `食甚` or `復圓`, nor does it state how the actual label was established.

Rescue failure proves the prediction mattered operationally. It does not prove that `卯正三刻` was read from the tower clepsydra or that it is the initial-contact instant.

### 3. Late-Ming positive control: explicit measurement language exists when intended

In the Chongzhen-5 eclipse discussion preserved in 《新法算書》, the text explicitly distinguishes:

- `初虧` predictions from three methods;
- `至期測候`;
- ancient clepsydra and newer wheel-clock timing;
- preferred time determination from Sun/star observations and instruments;
- `平晷` / `立晷` and `至期徵驗`.

This is a positive control for vocabulary and conceptual separation only. It must not be projected backward as the 1450 clock system.

### 4. Adjudication

Closed:
- Qintianjian rescue timing is precomputed and officially reported;
- direct visual observation is not a universal prerequisite for ritual reporting;
- Ming sources can explicitly name phase and time-acquisition method when documented.

Still open for Jingtai-1:
- whether `卯正三刻` means 初虧;
- who/what established the actual label;
- clepsydra vs astronomical timing vs another convention;
- explicit capital/locality and solar-time identity.

Therefore the Jingtai-1 event remains **NOT_YET_ADMISSIBLE** as an independent absolute-time anchor. MD-G03 remains **OPEN_BLOCKING_GENERAL_ADAPTER**; HPA-DAYUN-CAL-002 remains **MISSING_FROM_PRODUCT**; runtime and modern meridian fitting remain fail-closed.
