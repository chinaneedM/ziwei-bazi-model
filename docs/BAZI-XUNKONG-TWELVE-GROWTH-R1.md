# 八字旬空与十二长生事实注记 R1

## 范围

本轮只补充确定性排盘事实：

- 每柱干支所属旬及该旬的两个空亡地支；
- 以日主天干为基准，标记四柱地支对应的十二长生阶段。

这些字段属于应用展示层，并写入候选视图哈希。它们不进入旺衰、格局、用神、喜忌或吉凶判断。

## 冻结口径

旬空采用六旬表，profile 为 `BAZI-XUNKONG-YHZP-R1`：

| 旬首 | 旬空 |
| --- | --- |
| 甲子 | 戌亥 |
| 甲戌 | 申酉 |
| 甲申 | 午未 |
| 甲午 | 辰巳 |
| 甲辰 | 寅卯 |
| 甲寅 | 子丑 |

十二长生采用 `BAZI-TWELVE-GROWTH-YIN-YANG-R1`：阳干顺行、阴干逆行；十干长生起点为甲亥、乙午、丙寅、丁酉、戊寅、己酉、庚巳、辛子、壬申、癸卯。

十二阶段固定为：长生、沐浴、冠带、临官、帝旺、衰、病、死、墓、绝、胎、养。

## 语义隔离

输出分别带有：

- `IDENTITY_ONLY_NO_AUSPICIOUSNESS`
- `PHASE_IDENTITY_ONLY_NO_STRENGTH_CONCLUSION`

因此“空亡”只表示表中的旬空身份，“十二长生”只表示阶段身份。调用者不得据此直接生成吉凶、旺衰、寿夭或事件结论。若未来支持异本，必须新增 profile 并保留候选，不能静默覆盖本口径。

## 权威与回归

实现引用仓库权威资料索引 `S14:YHZP-CH-047`、`S14:7.7`、`S12:YHZP-CH-016`、`S12:ZPZQ-CH-05` 及语义限制 `S12:ZPZQ-R-0006`。

回归测试覆盖全部 60 甲子旬空映射、全部 10×12 个十二长生单元、非法输入闭锁，以及联合工作台展示。
