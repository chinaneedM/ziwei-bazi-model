# 天问：紫微斗数与四柱八字历史源流、传承研究广度优先路线 R1

生效：2026-11-16。此文件是研究执行顺序的长期约束，不是对任何古籍、流派或规则的历史真实性裁决。

## 总目标

分别重建紫微斗数和四柱八字从**可证的早期文献**至现代的历史发展、版本流变、规则形成、人物／流派、地域传播与传承关系，形成可阅读、可复核、可扩充的双体系历史知识框架。保留证据边界和未决问题；不得把传说的起源年份伪装成史实，也不得把两个系统强行拼成同一传承链。

## 阶段顺序：先广度、后深度

### 第一阶段（当前最高层执行重点）：建立完整历史骨架

1. **两门术数分线梳理**：分别建立有证据的时代分期、重要历史节点、著作与版本、人物与流派、术法／规则变化、地域传播。年代缺环应显式标注，而非填入传说。
2. **按时代顺序推进**：最早可考材料、前史与术语来源，继而逐时代推进至近现代；同一阶段并行比较中国不同地区及日本、朝鲜／韩国、台湾等能够证实的传播路径。不能因后世著作自称古法而倒置年代。
3. **建立文献目录骨架**：每部重要著作至少区分作品层、具体版本、馆藏实物和数字替身；作者、成书时间、刊印时间、馆藏副本、后世影印须分别记录，目录线索不等于核读原页。
4. **建立规则演变骨架**：紫微斗数优先整理命盘结构、星曜、宫位、四化、运限、历法时间及其分支；四柱八字优先整理早期禄命与后世子平的关系、四柱构造、十神、格局、神煞、岁运和历法时间等。只写有证据支持的产生、传播和变化，不预设单一正统。
5. **建立传承关系骨架**：把重要作品、实物版本、人物、地域、学校／流派和规则连接为证据作用域的图谱。必须区别直接承袭、可能关联、平行同源、未证关系、明确反证。
6. **每一时段留下可阅读成果**：持续形成紫微史纲、八字史纲、关键古籍目录及待补证清单；研究成果不能只停留在批次 JSON、CI 与零散异文数字中。

### 第一阶段的验收门槛（不是假装全史已经无争议）

- 两套按时间展开的**可阅读历史纲要 R1**，重要判断可回溯到登记的来源，且分别包含前史、可考早期、发展、分化、传播、近现代。
- 两套时代 × 核心知识领域 × 主要地域的覆盖清单：每格注明“已有直接证据／仅目录或后出资料／争议未决／尚未调查”，不制造虚假的完成百分比。
- 关键著作和主要规则家族已有可索引的**版本与规则源流骨架**；传承图谱能表达证据支持与未证连接。
- 空白、矛盾和获取障碍公开保留为未决事项。**框架完成**意味着主要问题和证据边界已系统布局，**不等于**原始古籍逐字校定、历史争议均已结束。
- 先审视已有来源、Matrix、图谱和历史批次，复用现有成果；只补真实缺失的覆盖面，禁止重新从头登记同一古籍。

### 第二阶段：沿完整骨架深入专题

第一阶段门槛达成后，按影响力和可获取证据深入早期源流争议、独立版本系谱、原页逐字校勘、具体机械运算、历史单位与进位、断代分歧。证据积累可以改写旧结论，但必须 forward-only 留下修订与反证。

## 研究选题与停止规则

- **默认选题**：完成协议和遗漏台账检查后，从两门历史纲要中最重要、最空白的时代／文献／规则／地域覆盖单元入手；避免在一个数表、单一残损字或已受阻馆藏路径长期循环。
- **例外**：若确切证据表明现有核心历史叙述存在重大错误、发现真实实现缺陷、证据安全性问题或关键时段无法继续铺开，可进行有明确边界的深入调查；完成本轮必要判断后回到骨架。
- **P0 的含义不变**：现有 P0 事项仍在风险台账中保持原状态和优先风险等级；它们不自动成为“必须逐项裁决才可开展其他历史研究”的全局阻塞。任何状态变化均按台账协议追加，不许静默降级、关闭或删除。
- **历史证据标准不变**：重要结论必须注明原页／影印／转录／目录／现代解释的证据等级；不能因为采用广度优先而把无据推测升级为历史事实。对尚不能核实的内容写“未明”。
- **研究期限**：按证据收益而不是无穷寻找某一残字决定投入。若零成本合规公开来源已经排查完毕且无关键新证据，把未决事项入账，转向下一历史阶段／主题。
- **不重开现有产品**：确定性融合排盘 CLOSED，预测与 AI 解读仍不属于本阶段；历史新候选不能自动进入运行时算法。
