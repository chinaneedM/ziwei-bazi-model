# 天问 12QG：旧二十卷卷二十卷首逐字记录的前向校正

本记录发现并纠正 12QE 九页取证中的一处**来源原文字串字段混淆**。这是原页训诂/书目对象作用域校正，不是排盘算法更改，也不是独立史料的增加。

- 原仓库此前已在 12PZ 的 NLC 411999003250 卷首原图定位将 PDF 第137页逐字读作「**萬曆肆拾伍丁巳卷二十**」，而新版 12QE 九页记录却误写「萬曆野獲編卷二十」并将其标为 `heading_start_exact`。
- 本次重开第137页影像核读，原页左页末印书眉/旁题「野獲編」与正文日期标题「萬曆肆拾伍丁巳卷二十」不是一条连续原文字串。「萬曆野獲編卷二十」可用于概括书目层书名+卷数，**不能当成原图的 exact heading**。
- 第145页「萬曆野獲編二十卷紀事畢」为卷末题记，不能倒写成卷首。
- 原始 PDF 的 SHA-256 为 `8e746faaadcd961c7983981d419862d97fdc2a1f3ec33ecb02046e9e79a6376c`；12PZ/12QE 对第137页不同渲染来源的图像哈希均在 `docs/research/MING-DATONG-YEHUOBIAN-12QG-NLC-OLD20-V20-HEADING-FORWARD-CORRECTION-R1.json` 内；不会因为双JPEG哈希不同而计为两份古籍原件。

**修复方式**：新增不可抵消的纠错 JSON/MD 文件，带原错值、准确字形、差错原因、源页定位及作用域；12QE 九页 JSON 保留旧值于 `forward_only_revision_history`，更新有效 `heading_start_exact`，将规范化书名另存单独字段；相关原研究 MD 加更正记录；单测增加卷首/卷末/书目规范化分离断言。原始错误版本仍可在 Git 先前提交复核。

不改旧二十卷第137–145页观察范围、不声称旧二十卷其它19卷查毕、不裁定〈改造漏刻〉原始篇位、不重开钟表模型及产品。12QE 继续开放。
