## 2. 觀象監活字 is a category, not a unique 1434 event

The Academy of Korean Studies entry `인력자(印曆字)` directly defines `印曆字` as the movable type used by the Gwansanggam to print calendrical books and gives `觀象監活字` as an alternate name.

The same bibliographic discussion states that:

- the exact beginning of Gwansanggam type ownership/use is not known;
- extant and documentary evidence reaches before the Imjin War;
- the iron type was **frequently recast**;
- different forms existed;
- wooden type was often mixed in;
- surviving impressions are diverse.

Therefore:

```text
catalog label 觀象監活字
!= unique identifier for the 1434 甲寅字 casting
!= exact impression year
```

This does not prove GK02538 is late. It proves only that the category label is not a copy-specific dating operator.

## 3. Kyujanggak direct control: later copy retaining earlier 原刊記

Kyujanggak `GC00509_00 / 奎中509-v.1-12` is a decisive edition/copy control.

The catalog identifies the current object as:

```text
刊年      肅宗 33 (1707)
版種      金屬活字本(戊申字)
```

but the same physical/bibliographic record retains:

```text
宣德九年(1434)十月日印出
```

and explicitly labels that line:

```text
甲寅字本 原刊記
```

while separately stating that the current object is the **1707 戊申字本**.

This is direct proof that:

```text
earlier 原刊記 can survive inside a much later physical reprint
```

Therefore even an explicit `印出` statement must be bound to its edition/copy layer before it is used as the date of the surviving object.
