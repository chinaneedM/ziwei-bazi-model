# 天问12QJ：国图编年型二十卷抄本卷首身份核验（非原编等同裁决）

**结论：312页原图采集完成，卷首结构有直接证据；不认定整书已逐页校勘，也不认定它是沈德符1606年前后作者定稿的逐卷等同物。**

复用已成功的 [12QI Actions](https://github.com/chinaneedM/ziwei-bazi-model/actions/runs/38063610452)：中国国家图书馆标注的 NLC 411999003250 一份馆藏，公开分册1（119页）、2（72页）、3（121页）合计 **312页、40张联络表**，每册源PDF及每页衍生JPEG由产物 `status.json` 记录哈希；只取证一个馆藏，不增加独立抄本数量。

本轮**直接人工核对仅3页**：第1册p1、p2，第2册p1；其余309页仅完成机器渲染，尚未逐字读。第1册p1–p2直接可见书名/纪目「萬曆野獲編紀目」，时间范围「戊戌二十六年起至丁巳四十五年六月止」，将一至二十卷按戊戌、己亥直至丁巳逐年编号。卷末二十标注丁巳六月止。另可见「遼陽州學正王元輔抄錄」字样，但**题署不证明抄写时间及底本传承**。第2册PDF第1页文字「萬曆三十年壬寅卷五」直接独立印证卷五的壬寅纪年。以上干支公历换算1598—1617只是检索坐标，不是抄本生产日期。
