## 景泰元年“月食當在卯正三刻”相位训诂对照

Status: **BARE 當在 PHASE IDENTITY NOT CLOSED / 當在→初虧 NORMALIZATION FORBIDDEN / JINGTAI-1 PHASE STILL UNRESOLVED / MD-G03 OPEN**

Batch 12PR physically closed the 1450 target wording as `月食當在卯正三刻`, but the sentence contains no explicit `初虧 / 食甚 / 復圓` phase term. 12PS therefore asks a narrow philological question: may bare `當在 + 時刻` be mechanically normalized to `初虧 + 時刻`?

A near-contemporary control only fourteen years later, 《明憲宗純皇帝實錄》卷4 (天順八年, 1464), explicitly records one Qintianjian forecast as `酉正二刻初虧` and a competing forecast as `酉初初刻初虧`. When initial contact is intended, the received annal can state `初虧` directly.

《明孝宗敬皇帝實錄》卷162 (弘治十三年, 1500) likewise records `寅虧卯圓`, then says the event actually `虧於卯而復圓於辰`. Start and recovery are lexically distinguished in a forecast-versus-observation error adjudication.

A later positive control, 《明神宗顯皇帝實錄》卷477 (萬曆三十八年, 1610), explicitly enumerates `初虧 / 食甚 / 復圓` and separately discusses `壺漏 / 簡儀` measurement. This proves that phase and acquisition vocabulary can be explicit, but the 1610 clock practice is **not** back-projected to 1450.

Adjudication: `當在` is a timing predicate, not an attested phase lexeme. Therefore `月食當在卯正三刻 -> 初虧卯正三刻` is forbidden as silent normalization. The evidence also does not prove that the target is *not* 初虧, and it does not authorize selecting 食甚、復圓 or any other hidden phase.

Jingtai-1 phase identity remains **UNRESOLVED** and the record remains **NOT_YET_ADMISSIBLE** as an absolute-time anchor. MD-G03 remains **OPEN_BLOCKING_GENERAL_ADAPTER**; HPA-DAYUN-CAL-002 remains **MISSING_FROM_PRODUCT**; runtime and modern meridian fitting remain fail-closed.
