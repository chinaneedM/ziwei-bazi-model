# 紫微大限／流年／流月禄羊陀事实 R1

本阶段只发布动态层的禄存、擎羊、陀罗位置，不输出庙旺、吉凶、力量比较、事件或预测结论。

## 分层身份

- 大限：以大限命宫宫干为来源干，生成 `DAXIAN` 层禄存、擎羊、陀罗。
- 流年：以流年天干为来源干，生成 `ANNUAL` 层禄存、擎羊、陀罗。
- 常规流月：以五虎遁所得流月天干为来源干，生成 `MONTH` 层禄存、擎羊、陀罗。

每一颗动态星都带有独立 `activation_id`、`source_layer`、`source_stem`、父帧 `context_id`、规则身份、算法版本和来源。原局、大限、流年、流月的同名星曜不会合并成一颗星，也不会在事实层计算谁强谁弱。

## 完整性边界

时限完整性验证会从每层来源干独立复算三颗动态星，并验证层级、父帧、位置、规则身份与来源。事实哈希包含位置和层级；计算哈希另包含完整来源链。选择大限、流年或流月时，视图和 SVG 以独立的“流曜”标记显示对应层实例，不改写本命星曜。

S10 还列出流魁、流钺、流昌、流曲等动态星。由于本阶段尚未为各层完成同等强度的安星表与交叉验证，它们不在 R1 中补猜。
