# 紫微分层动态辅助事实与候选 R1

本阶段发布动态层的禄存、擎羊、陀罗、流文昌、流文曲确定位置，并保存流天魁、流天钺未选择方法候选；不输出庙旺、吉凶、力量比较、事件或预测结论。

## 分层身份

- 大限：以大限命宫宫干为来源干，生成 `DAXIAN` 层禄存、擎羊、陀罗。
- 流年：以流年天干为来源干，生成 `ANNUAL` 层禄存、擎羊、陀罗。
- 常规流月：以五虎遁所得流月天干为来源干，生成 `MONTH` 层禄存、擎羊、陀罗。

每一颗动态星都带有独立 `activation_id`、`source_layer`、`source_stem`、父帧 `context_id`、规则身份、算法版本和来源。原局、大限、流年、流月、流日和流时候选的同名星曜不会合并成一颗星，也不会在事实层计算谁强谁弱。

流魁钺另设 `CANDIDATES_PRESERVED_NO_SELECTION` 候选集，同时保存严格 S01 表和文墨兼容案例法。每种方法都有独立方法 ID、activation、来源链和事实／计算哈希；非辛干即使位置相同，也不按结果去重。辛干严格表为魁午／钺寅，兼容案例法为魁寅／钺午。

## 完整性边界

时限完整性验证会从每层来源干独立复算三颗动态星，并验证层级、父帧、位置、规则身份与来源。事实哈希包含位置和层级；计算哈希另包含完整来源链。选择大限、流年或流月时，视图和 SVG 以独立的“流曜”标记显示对应层实例，不改写本命星曜。

流昌曲依据 S10 完整十干表发布确定事实；流魁钺依据 S10 对 S01 原局安法的指向和既有兼容证据发布候选，但不选择门派。其他动态星仍须同时具备完整安星表、明确时间层基准与稳定来源才可进入运行时，不从常识补猜。
