# Fusion Chart Historical Provenance Audit R1 — Batch 12PF

## 1294 revised-應 observation-site provenance

Status: **YUAN MULTI-SITE OBSERVATION NETWORK CLOSED / DADU-ONLY DEFAULT REJECTED / EXACT 1294 REVISION SITE UNRESOLVED / MD-G03 STILL OPEN / RUNTIME FAIL-CLOSED**

12PE showed that the 1281 epoch cannot supply qishuo geography. 12PF therefore follows the later historical claim that the response constants were revised after a Zhiyuan-31 fifth-month full-moon eclipse discrepancy and asks where that observation occurred.

### Later revision-trigger tradition

《明史稿》 preserves the explicit trigger: 至元三十一年甲午五月望，月食不效，差天二刻；守敬於是取諸應損益之. It gives the revised 閏/轉/交應 values but names no observation site. This is a later received historical witness, not a contemporaneous Yuan observation log.

### Yuan official observing infrastructure

《元史》卷10 records that in 1279 the court established 司天臺 at Dadu and simultaneously placed instruments at Shangdu, Luoyang and other sites, each with observing officials. Guo Shoujing was also ordered to measure from Shangdu through Dadu and southward. The Shoushi observation system was therefore multi-site, not Dadu-only.

### The trigger month was not a Dadu-only court context

《元史》卷18 places Emperor Chengzong at Shangdu from the fourth month of 1294 and records astronomy-related rites at 司天臺 and 雲仙臺 in the fifth month; the imperial carriage did not return to Dadu until the tenth month. This proves active Shangdu court-astronomy context in the target month, but court location is not automatically the eclipse observation site.

### Guo Shoujing's 1294 office

《元史》郭守敬傳 and the Yuan-period 《元朝名臣事略》 both record that in Zhiyuan 31 Guo became 昭文館大學士、知太史院事. Neither text binds him, the eclipse observation, or the revised constants to Dadu or Shangdu.

### Adjudication

The system-level assumption DADU_IS_THE_UNIQUE_YUAN_OBSERVATION_SITE is rejected. The stronger claim DADU_IS_THE_1294_REVISED_YING_SITE remains unresolved, and so does the Shangdu alternative.

Thus:

- Dadu qishuo reference = unresolved;
- Shangdu qishuo/revision reference = unresolved;
- court location -> observation site inference = forbidden;
- office-holder location -> observation site inference = forbidden;
- MD-G03 remains open;
- historical runtime remains fail-closed.
