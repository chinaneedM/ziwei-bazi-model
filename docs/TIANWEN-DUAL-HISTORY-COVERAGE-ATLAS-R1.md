## 双系统共有但不能直接合并的横向问题

1. **共同历法知识**不等于紫微与四柱具有同一晚子时处理；`TW-OPEN-0005`、`TW-OPEN-0006`、`TW-OPEN-0007` 持续开放。
2. **同名神煞、十神、星曜**不自动构成跨学科直接抄袭关系。先记录字面、输入对象、输出、规则发生时代和版本。
3. **藏于日本／韩国**不是**由日本／韩国创立、当地流派已持续传承**的证据。目录对象、原始物件、出版、人物活动分开。
4. **古籍作者题署**、书局刊印、序跋日期与原书成书年代分离；传统陈抟、李虚中、徐子平归属保留为待核命题。
5. 现有图谱 **264节点／247边** 以其记录的事实范围为限，不能以图形连线取代缺失的跨代原始证据。

## 第一阶段后续工作顺序

1. **历史起点补证**：两系统分别列出明前／宋元重要作品，核其具体馆目、最早印本／抄本、作品年代与题署可信度；从时间上完成“前史→可考印本”的桥，不推定不存在的年代。

3. **民国传播空白**：按时间及大陆／台湾／日本／韩国分列出版社、师承出版证明、读者社群和馆藏，而非重复只读清代旧本。
4. **当代流派传播空白**：现代出版物、校注本、数字再现和学校／社群做异层记录，寻找有据地缘传播，不由现代法推古法。
5. 主要时段的作品、规则、人物、地域覆盖框架具备证据索引后，进入第二阶段逐叶校勘和深度裁决。
