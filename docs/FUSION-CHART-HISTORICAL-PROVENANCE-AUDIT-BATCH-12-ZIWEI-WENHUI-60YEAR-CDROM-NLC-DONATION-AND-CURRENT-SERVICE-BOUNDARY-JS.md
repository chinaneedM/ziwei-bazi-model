### 1. 新路线

控制探针直接取得 2003 年同时代网络转载页。页面标注来源为《文汇报》，并记录向国家图书馆赠送《文汇报60年报纸光盘》13张；声明内容覆盖 1938年1月至1998年12月全部文字及图片，并可按日期、姓名查阅。

该网页不是文汇报第一方域名，因此本批把它定级为 CONTEMPORARY REPRINT，而不是 primary newspaper page。其价值在于建立一个此前未进入项目的历史数字对象与 NLC 受赠路线。

### 2. 日期覆盖与目标页防火墙

1938-01..1998-12 的声明覆盖期包含 1951-08-18。但 coverage inclusion 只证明日期位于宣称的产品覆盖范围，不证明赵万里文章确实收入、不证明该日具体页已经打开，也不证明光盘仍以同一产品形态可用。

### 3. 国家图书馆当前服务面

NLC 当前首页和服务页均直接取得。首页暴露馆藏目录/数字资源入口；服务页同时出现数字资源与光盘服务语境。但两张已审页面都没有直接出现《文汇报60年报纸光盘》题名，也没有 source-emitted item ID。

因此 CURRENT_NLC_ITEM_IDENTITY = NOT_OBSERVED_ON_REVIEWED_SURFACES；不得改写为 NLC_NOT_HOLDING。

### 4. IFLA 2005 与 60/61 年对象分离

控制 runner 对 IFLA 2005 旧档案 PDF 的首路返回 HTTP 503，其余测试的官方旧路径为 connection error；本批没有直接取得 PDF。因此此前发现的“文汇报61年全文数据光盘”不能在 12JS 中升级为直接 PDF 证据，更不能与 2003 的“60年报纸光盘”直接合并。
