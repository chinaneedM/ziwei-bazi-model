# 天问 13CQ｜台湾国图《高丽史》复合钞本：缺卷朱记与1905年补钞的证据分层

本批沿接13CP，继续处理TW-OPEN-0005。**尚未读到书首红笔缺卷清单，也没有取得卷五十二目标原叶**，不把目录转录当作物理原件。

## 从馆藏说明中提取新的取证坐标

Wikimedia Commons对台湾国图`208 03130`《高丽史》转录吴重熹题记，保留「缺卷朱記于首」这一精确坐标。该句话提示馆藏书首有红笔记述缺卷范围，但**它不是我们已核读的原始红字页**。同一题记转录记述光绪甲辰取得旧钞、乙巳夏钱塘丁和甫补齐全书。东京大学东洋文化研究所历年表将甲辰、乙巳分别标为1904、1905。

在研究模型中，必须分开四层：**《高丽史》作品形成（1451）、清初叶旧钞说法（书目元数据层）、1904年购入事件、1905年补钞完成事件**。不能把“清初叶（1644–1735）”普遍套在卷五十二每一叶；也不能因为全书1905年补齐就声称卷五十二一定是后补本。

## 前向工作的五项门禁

1. 获取国家图书馆一方`208 03130`精确物品记录，查书首“缺卷朱记”原影像，保存原页位置及SHA-256。
2. 在原红笔清单中独立裁决作品卷五十二**列缺、不列缺、不可读**三种状态，不允许先验判断。
3. 将《授时历立成》目标原叶绑定至物理册和旧钞或丁氏补钞层，保存卷题、笔迹、纸张、藏印和缺卷清单的同本证据。
4. 在第三步之后再核读D15–D18 **日差/盈缩加分/盈缩积**原图，并保存字段—日次几何映射和字形哈希。
5. 按实际叶片年代和所据底本处理传承关系，不凭复合册题名直接计算第三独立历史票。
