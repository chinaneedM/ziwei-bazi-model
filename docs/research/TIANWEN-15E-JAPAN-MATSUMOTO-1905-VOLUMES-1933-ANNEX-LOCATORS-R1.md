# 天问15E｜松本義亮四柱书 1905 单卷与 1933 历法别册数字入口交叉核验

核验日：2026-11-20。承接 15D 的日本近代四柱出版史广度优先研究。本批仅新增可复核的**第一方馆目 B 级证据与数字对象定位**，**未审读任何 1905、未定年卷一或 1933 别册原始图像/奥付**。没有二进制文件下载及图像 SHA-256；目录信息、数字文件和物理印本不得混作独立校勘证据。

## 1. 1906 以前的单卷书目层及年代冲突

- [NDL 000009251785 / pid1083859](https://ndlsearch.ndl.go.jp/books/R100000002-I000009251785)：《四柱推命奥義秘傳録》**卷2**，著者松本義亮；NDL著录 **1905 年**、**大阪：松本義亮**、64页、NDL请求号**特21-934**。数字对象标示2010-03-31制作、互联网公开、IIIF manifest `https://dl.ndl.go.jp/api/iiif/1083859/manifest.json`。这证明一个早于15D所列1906锚点的**馆目所指单卷和公开扫描路线**，但尚**不能证明四卷套书在1905年整体出版、1905就是第一版，或1905卷2与1906各卷原刻同版**。
- [NDL 000009251771 / pid1083858](https://ndlsearch.ndl.go.jp/books/R100000002-I000009251771)：同题**卷1**被著录为**长崎：天祥舘、[18--] 年、51页**，亦用请求号**特21-934**；扫描对象互联网公开，数字化2010-03-31。这里的 **[18--] 只是一项不确定年代目录标记**；不可断言已经取得十九世纪原刻或据其改写著作首版年。长崎出版地、年代层与1905卷2和1906大阪四册馆目存在书目范围差异，等待原页版权/奥付对照。
- 15D [NDL 000000423349](https://ndlsearch.ndl.go.jp/books/R100000002-I000000423349)仍明确把**1906年4月／大阪天祥館／卷1–4四册**作为另一书目入口，并与上述卷1、卷2共享**特21-934**请求号。这种共享请求号**不支持把三条记录计作三个独立实物**；可能是同一馆藏系列的分卷著录，必须在页图和馆内装订/条码层再审。
- Commons 的 [pid1083858 卷1](https://commons.wikimedia.org/wiki/File:NDL1083858_四柱推命奥義秘傳録_卷1.pdf)提供同一 NDL 数字对象的备份文件页面；没有新实体票数，且本批未逐页读取。

**限域结论：** 本批把日本松本四柱著作已知**书目年份线索**前推至1905卷2，1905是否为整体版本年、另一个卷1的 [18--] 来源、1906四册与这两条分卷馆目是否共享版片均为OPEN。禁止将目录[18--]扩写成确定十九世纪出版史。

## 2. 1933 增补改订版的正确历法别册定位

- [NDL pid1104880](https://ndlsearch.ndl.go.jp/books/R100000039-I1104880)明确标示**《四柱推命奥義秘伝録》别册，1933（昭和8）大阪天祥館出版部，增补改订版，别册105页《陰陽暦対照干支一覧》**，请求号**特261-415**。其数字对象2010-03-31制作、网络公开，IIIF manifest `https://dl.ndl.go.jp/api/iiif/1104880/manifest.json`。
- 15D 所述 [pid1104866](https://ndlsearch.ndl.go.jp/books/R100000039-I1104866)是**同套书的第四册**而不是这份历法**别册**；本批仅对“取历法附件原图”的后续目标**定位更正**，不是宣称15D曾将第四册判为别册。两者请号与同套书目有关，不能投为独立出版/独立物理见证。
- [Commons 1104880 别册 PDF](https://commons.wikimedia.org/wiki/File:NDL1104880_四柱推命奥義秘伝録_別冊.pdf)列56数字页面；**56个扫描跨页不等于实体书105页**，也不等于已逐页核读。目标文件元数据/备份入口已定位，原叶版心、版权/奥付、历表图像和1935京都107页本差异**尚未审读**。

## 3. 结论、传承约束和下一步

1. 新增三个第一方 NDL 书目/数字入口，分别为 1905卷2、[18--]未定年卷1、1933历法别册；这三条是**数字/目录定位记录**，不能按三份彼此独立的历史物理副本计算。
2. 传承图仅可新增限域的卷2目录版次节点与1933独立数字对象节点，**无可证直接传承边**。仍须区分 1905单卷、1906四册、1912九版、1933六册、1935京都附件。
3. 下一轮按合法免费公开影像入口读取：先核1905卷2、未定年卷1、1906第一卷及1912九版第一卷的原印本奥付/序末、版框与同异；再审1933别册 pid1104880 的原页页码/题签，与1935京都107页馆藏比对。必须记录实际页码、所阅对象、图片哈希、可重复的读法；不能利用OCR代替原字。
