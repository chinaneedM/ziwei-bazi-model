# 12WE：柏林国家图书馆1827《野獲編》对象号的第一方IIIF/METS验证

## 一、资料起点

12VL已有书目来源：[Deutsche Digitale Bibliothek](https://www.deutsche-digitale-bibliothek.de/item/WBXTVCN6VMFVV7ESZ7QLCGP4GFJ22IA7) 明列柏林 Staatsbibliothek 馆藏号 `Libri sin. 365/372`、书名《野獲編30卷補遺4卷》（但标记 **Beispielseiten／示例页**）、扶茘山房1827书目年份，并由平台的原创馆方对象链接明确发出 `PPN334378186X`，对应第一方 [SBB数字馆](https://digital.staatsbibliothek-berlin.de/werkansicht/?PPN=PPN334378186X)。这个PPN来自**书目链接**，不来自猜测或者枚举对象ID。

[柏林国家图书馆官方技术文档](https://lab.sbb.berlin/dc/?lang=en) 正式说明数字馆可按已经得到的对象PPN读取 `/dc/{PPN}/manifest`（IIIF）与 `/dc/{PPN}.mets.xml`（馆藏对象METS）。本次仅使用上述两条**公开有据、已获对象号**的API格式；每条最多12MB、读取一次、50秒超时，不枚举下游单页图像编号，不自动下载图像，不做OCR。

## 二、可验证与不可验证的层级

第一方可取得的IIIF/METS元数据能够**为数字资源是否完整及结构标签定位提供线索**，但绝不能把 **Beispielseiten** 解释成整套卷二十已开放。必须取得原图字节，并检查实际卷二十〈改造漏刻〉篇首、全文页码、四处目标字形、古籍版权状态、1827原刻与1869重校实物关系，才可提高证据等级。柏林一个数字对象的影像即使完整也不自动得到一本独立于东京京都的刻本印次票。

工作流上传 `probe-report.json` 和能够成功读取的原始响应字节，包含 HTTP 访问边界、SHA256、已知可解析结构标签；成功运行仅表示**探针执行完毕**，不等于原叶采集成功。如 API 未开放或受访问阻挡，记录受限且不声称馆藏不存在。
