# 天问 13CK｜《高麗史》卷52日18「盈縮積」电子校录尾字异文（受限比勘）

**本批为现代在线转录的复核，不是新发现的一种古刊本。** 2026-10-22 对读韩国国史编纂委员会（KRDB）《高麗史》卷五十二“授時曆立成”公开汉文表（已经在项目 root registry 登记）和维基文库同卷同表（亦为既有来源），发现唯一在 D16..D19 此目标栏范围内显出的 D18 末字差异：

| 层级 | D18「盈縮積」字形 |
|---|---|
| KRDB 当前公开在线汉文校录 | `八千四百二十四六四〇八三` |
| 维基文库当前转录 | `八千四百二十四六四〇八` |
| 早稻田 book33 p23 原图（既有13BO所记原生ROI） | `八千四百二十四六四〇八` |

韩国数据库 D18 比另外两处记录末尾多出 `三`。这只证明**本次可访问的现代电子文本差异**；未获取网页原始字节 SHA，未见 KRDB 注释指定底本的原刊页影像，也未查明该字是在机构转录、排版、数字转换、还是某具体历史版刻中形成，故不能按“古籍版次异文”定论。早稻田古籍原图字形是前批13BO已封存可追溯证据，本轮不再次声称读取其原图像素。

两网站对同一表的栏目**展示顺序不同**：韩国公开汉文页面依序「積日 / 日差 / 盈縮加分 / 盈縮積 / 行度」，维基文库展示「積日 / 日差 / 盈縮積 / 盈縮加分 / 行度」。比较必须**以栏目名称而非第几列**对齐；不能因此造出虚假的数值栏异文。

D16两种电子转录都继续记录「五分一三六二」，与早稻田和NAJ两份原图在13CI封存的短栏一致；差分所得5.2362仍不可自动改定原文。D17、D19两电子文本在目标字段一致；D18的机构末尾「三」不容许自动纳入四位小数历算或当作一份独立古籍版刻。13BO 已录原图 D17 C8000.2697、D18 C8424.6408，相差424.3711，恰合该来源D17长栏，但该局部对应并不推演全表、不重开算法。
