# 天问13J｜国图清抄《高丽史》99数字分册、早稻田1848《国朝宝鉴》与同本镜像的证据边界

**结论：本批新登记三条来源路由，但没有取得卷52太阳盈缩表D16/D18原字；零数值投票、零算法重开。**

1. 早稻田大学[《国朝寳鑑》馆目](https://www.wul.waseda.ac.jp/kotenseki/html/ri06/ri06_03059/index.html)登记书号`リ06 03059`、卷1–82及别编1–7、28册。其「憲宗14（1848）跋」是后跋年代而非本件原版印制年代，版式著录为丁酉字覆刻、印记奎章之宝。此本既非1782年68卷本的当然同本，也不能充当1454年刊印命令或印成事实的物理证据；卷9原叶尚未核读。

2. [国图《高丽史》另套清抄本数字首册](https://commons.wikimedia.org/wiki/File:NLC892-411999022809-48736_%E9%AB%98%E9%BA%97%E5%8F%B2_%E7%AC%AC1%E5%86%8A.pdf)：Commons转储代号`411999022809`，善本书号`13494`，描述清抄、11行20字无格，存作品卷1–117、120–125、127–137，其中作品卷52被覆盖。[转储索引](https://commons.wikimedia.org/wiki/Commons:Library_back_up_project/file_list/NLC/%E6%95%B8%E5%AD%97%E5%8F%A4%E7%B1%8D/10)列数字分册1–99，但不能用99个PDF推断99份独立古籍或实体册数。国图第一方同号馆目、卷52具体分册/页和D16/D18仍未绑定。该路线须与台湾NCL03130及早稻田馆目区别。

3. [Commons WUL 第47组PDF](https://commons.wikimedia.org/wiki/File:WUL-ri06_02809_%E9%AB%98%E9%BA%97%E5%8F%B2_47.pdf)标示相同早稻田书号`リ06 02809`，52个PDF图页，只是13I已登记藏本的镜像传播路线，不能当独立原件再投一票。Commons所谓Publication date 1451只足以提示作品年代层面，[馆方原目录](https://www.wul.waseda.ac.jp/kotenseki/html/ri06/ri06_02809/index.html)却明确出版年不明；数字组号47不得等同作品卷47或卷52。

4. 溯源严守作品成书、版印、物理藏本、数字替身四层区分。根目录647 + 扩展87 = 734来源定位符。本批3条均无目标原字资格。历史Matrix222/222、修复45/45、传承图252节点238边不变；11研究遗漏保留，G893同本直读5/6与跨独立原件0/6不变，确定性排盘R1仍CLOSED。下一步先确认NLC 411999022809作品卷52对应的真实页图，以及早稻田80册馆藏的卷52数字组，再记录原图SHA-256、页号、字形与邻表。
