# 天问15R｜越南胜严寺民间术数藏书：安星手抄文本 TN 208 与命盘实例 TN 213

核验日期：2026-11-21。本批按广度优先路线从日本1731/1754书目转入越南的**实际地方保存与使用痕迹**，对13ZV已有国家图书馆R.293、汉喃研究院4992目录及学者Volkov的来源严格去重。所用材料是越南喃字保存基金会（VNPF）公开馆目、书群说明及有限在线图像浏览入口；没有下载完整原稿或计算图像SHA，不声称逐叶识字或术式机械重放。

## 1. 独立文献群的物理／数字身份

[VNPF馆藏分组页](https://lib.nomfoundation.org/collection/4/)标为 **Chùa Thắng Nghiêm Shaman / Thắng Nghiêm II**：机构说明2013年10月一名去世民间巫师/灵媒家属将藏书群捐入胜严寺，报告79项，其中汉文、喃文及混合文字均有。这个**近代移交时间**不等于任一作品的写成或刻印时间，也不能直接证明该藏书群全部由同一人亲手起例、授徒或使用。分组页所指保存群与13ZV所登记的**越南国家图书馆R.293 / NLVNPF-0508**为不同目录及数字对象，绝不作一个人、一版本或一个同源馆藏的合并。

### A. TN 208 / TNVNPF-110《安星紫㣲錦宅》

[具体馆目](https://lib.nomfoundation.org/collection/4/volume/1510/)将原标题著录「**安星紫㣲錦宅**」（保留异体㣲；可检索作“安星紫微锦宅”），编号 **TN 208 / TNVNPF-110**，匿名、[无刊者／无地点／无年代]、**汉文手写**、57页、27×14厘米、影像制作2013年。内容说明称以年、月、日、时为资料，涉及田宅、子息、父母、兄弟、夫妻、福德、财帛、奴仆等事项；这只是馆员描述，尚不能推定采用某一明刻十四主星安星表或星曜四化版本。[第一页浏览页](https://lib.nomfoundation.org/collection/4/volume/1510/page/1)显示“Page 1 of 57”，公开图像可见手写纸叶外观；但本轮没有逐页图像SHA、卷端年代校勘或完整规则重放，因此只登记**B：馆藏/目录、有限浏览入口**，不赋予A类原字权威。

### B. TN 213 / TNVNPF-115《蘿𢼂紫㣲个人》〔目录越文释名：个人紫微命盘〕

[具体馆目](https://lib.nomfoundation.org/collection/4/volume/1515/)原标题按原网站保留难字：**蘿𢼂紫㣲个人**，越文释名 **Lá số tử vi cá nhân**，编号 **TN 213 / TNVNPF-115**。著录匿名、未断年、27×14厘米、汉喃文字、2013年数字化。机构介绍记有具体出生时日资料、人物的手绘命盘，属于**可检索的实践例图/命盘材料描述**，与上述安星类文本的文献角色不同。本文不转录涉及个人的姓名或完整生辰。

**馆目分页冲突须保留：** TN213元数据写 **90页**、材料类型一栏写 **Woodblock text / Khắc in**；同一数字[浏览入口](https://lib.nomfoundation.org/collection/4/volume/1515/page/1)却显示“**Page 1 of 61**”。这可能反映原件页数与公开影像页数的统计基准不同，也可能是目录录入或数字缺页；当前没有逐页核对，绝不能静默选择61或90，更不能说已经拿到90页全卷、知道印版制作年代或量化全部绘图案例。首页有TN.213物件标签与图式的公开图像入口，尚无字形哈希绑定。

### C. 两件对象是平行藏书，不是已证书籍谱系

[机构索引](https://lib.nomfoundation.org/collection/4/subject/12)将 **TN 208** 与 **TN 213** 在同一79项分组中分别列名。可实证的是**同一2013年移交、数字著录的地方馆藏群，含独立安星文本与命盘记录**。尚未证实：TN213使用TN208的安星算法、二者原件同一成书时期、同一抄手/刻工、具体术师传承、越南自生术式、对中国《全书》《全集》或日本/朝鲜的直接抄本关系。2013藏书入寺不是两书的“2013版”。

## 2. 和13ZV已有越南材料的不同

13ZV已登记：
- 国家图书馆 **R.293 / NLVNPF-0508《安紫微國語歌》**：54页喃文手抄、2008.8.15数字化，[另一个收藏和数字号](https://lib.nomfoundation.org/collection/1/volume/666/)。
- 越南汉喃研究院 **4992《紫微斗數》十个索书号**、AB.316/552《解音》、AB.424十二宫喃歌等；其原页、抄本年代与版次/规则关系全部开放。

本批**不再注册上述同源旧来源**。TN208为另一藏书群的汉文安星抄本；TN213为另一物件的命盘/图式记录，未能做内容匹配。若要验证越南实际运用的技术，应从TN213选取不含可识别个人生辰的机械结构字段，与TN208逐页安宫/安星公式分开对比。
