# 天问 13JY：G893／《高丽史》三组异文的五行差分检验（仅作候选计算）
 
## 方法与文献边界

本批从仓库已经保存并核验过的奎章阁 G893 源影像逐字记录**引用** L8、L124、L132 目标字形，配合公开《高丽史》卷五十二连续五行记录，执行十进制一阶差分、二阶差分。特别说明：**两侧四行取自《高丽史》传世表，不是新核读的 G893 原表相邻行**。将 G893 数值代入只是跨见证的反事实计算；本批没有新取得原图，也没有将不同版本混成“同一个原本”。

- 《高丽史》卷五十二公开传世表：https://zh.wikisource.org/zh-hant/高麗史/卷五十二
- G893 以前已完成的源页及 SHA256：L8 `019b`（`05d6a6...`），L124 `035b`（`06b5a0...`），L132 `036b`（`8acb0c...`）。完整 SHA 见本批 JSON / 12XU / 12XX。
- 《高丽史》所见 L124=`一度〇八二一` 既有 CADAL 原影像第120页校勘；L8 原影像第81页、L132 第123页也已在历史证据台账读到对应字形。这些不是新发现的独立物理见证。

## 关键防误判

1. L124 传世本的 1.0821 并非只有网页转录如此写：此前 CADAL 源影像也直接读出 `一度〇八二一`，所以算术突变不构成“网页错字”的证明。
2. L132 的 `七分八八六七五` 涉及传统位值切分，不能仅凭数字长度就断言它等于十进制 7.88675。原台账还对照同一本《高丽史》L35 的显式〇，继续保留单位和缺字解释问题。
3. G893 原本六项**完整跨版本机械终裁仍为0**。此检验不取得新物理见证、不增加传承边、不变更系统算法，也不为任一候选选获胜者。
