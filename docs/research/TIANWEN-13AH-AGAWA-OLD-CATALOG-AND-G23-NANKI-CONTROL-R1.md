# 天问13AH｜阿川早期旧目录九州藏本 + 东大 G23 非独占来源反证

## 原始藏目分层再推进

**一、找到1998年吉田《阿川文库列表》以外的一项独立书目工作。** NII [CiNii BA63404722](https://ci.nii.ac.jp/ncid/BA63404722) 登记《阿川文庫目録 : 朝鮮本》，古關吉雄编，96丁，25cm，「私家複製版」，出版年代为 `[1---]`，**无法据此推定准确年份、原稿写作年代、晚于或早于1998年，或两清单之间的实物承袭关系**。馆目摘录包含「同君別有清書」字句，提示还有清写本的叙述，但尚无原目录叶直接查阅、书页 SHA 或作品条目核对。

CiNii 仅列**九州大学中央图书馆**的一件：`石崎文庫/029-ア-1/1 / 003132003022182`。九州大学自身 [OPAC实体条目](https://catalog.lib.kyushu-u.ac.jp/opac_openurl/?ncid=BA63404722) 再次核实 `bibid=1001068157`、**中央图闭架准贵重书室57**。这是两个馆方/联合目录对**同一件九州实物书目**的相互佐证，不是两个版本或原《高丽史》数值见证；现无数字原目录影像或公开授权下载证据。

**二、同一G23索书前缀并不具有阿川文库专属意义。** 东京大学官方 [数字档案《朝鮮記》G23236-01](https://da.dl.itc.u-tokyo.ac.jp/portal/assets/08e4ffa0-1546-a20e-9ba5-b5c8e3af59da) 列出：
- 准确索书号 `G23:236`，本体为大河内秀元相关《朝鲜记》；
- **南葵文库**来源，并明写「東京帝国大学図書印，南葵文庫の印記あり」；
- 独立公开的、专属于这件《朝鲜记》的 IIIF manifest。

这构成**G23家族中至少存在南葵文库实物的官方反例**，因而不能仅凭 `G23` 标签将目标 `G23:12`、`G23:194` 锁定为阿川文库。反过来，也不能把同族G23其他书的南葵归属套给两个目标本。所述藏印目前是东大官方元数据的文字记载，**未声明本次已亲眼核验藏印原图**。
