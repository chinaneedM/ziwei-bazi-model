# 12VW — 哥伦比亚大学第一方 CLIO 开放馆藏数据的分片搜寻路径

沿12VU未绑定馆目线索，核读哥伦比亚大学图书馆官方开放数据说明：https://library.columbia.edu/about/lib-ops/clio-data.html，可通过其链接进入https://lito.cul.columbia.edu/extracts/ColumbiaLibraryCatalog/full/。2026-10-14公共目录页展示 **extract-001.xml.gz 至 extract-111.xml.gz，共111份**；其中大多约58–59MB，末片约17MB，目录显示更新于2026-10-11。馆方说明数据是开放MARCXML，包含馆藏字段、按月更新，排除部分供应商、ReCAP及法学院目录记录，质量参差且并非所有实体与影像逐件核定。来源可用于检索准确书目号；**网页受Anubis保护的CLIO交互界面无法直接证明某条目的缺席**。

工程前向增加一个通用gzip MARCXML 流式、只针对书名字段的解析器和合成正反例；限定每次最多下载一个、80MB以内、官方固定主机的源压缩片，原文件SHA256写入回执。工作流在精确HEAD上执行结构门禁后，对末片111做一次公开取样，保存原始执行结果artifact。末片没有检出时，只能声称**该片**未检出指定书名，绝不能升级成哥大无1827藏本；即使检出也需机构单件馆藏架号、印次与卷20叶号的第二阶段核实。

与早期12VU的两条来源不同，本轮增加的是**哥大馆方开放MARC原始数据的第一方发布入口**，计数 root647 + extension54 =701；没有新的1827/1869古书原页、印次证明、原字票或传承关系，Matrix222/222、修复45/45、正式487和产品CLOSED不变。
