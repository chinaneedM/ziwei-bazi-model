# 天问 15BV｜《三命通会》卷七的子平源流追述，与南宋—元代书证的年代分层

研究日：2026-11-23。第一阶段广度优先，接续[15BM南宋《桯史》起例](./TIANWEN-15BM-TINGSHI-PKU-OLD-WITNESS-AND-HOUR-STEM-REPLAY-R1.md)与[13ZX宋元命书目录](./TIANWEN-13ZX-SONG-YUAN-NATAL-METHODS-AND-CATALOGS-R1.md)。目标不是再从头整理一遍子平源流，而是**区分可读算法、同时代作品的现存后印页、元代序跋经清代书目转述、明代传承故事**。不对这条传承增添未经验证的谱系关系。

## 一、关键新对读：明人说的「子平」并不等同于已经找到五代原法

[《三命通會》四庫本卷七〈子平說辯〉现代受读页](https://zh.wikisource.org/wiki/三命通會_(四庫全書本)/卷07)列出四类有不同证据资格的话：

1. **讨论本篇当时的技术框架**：论八字「以日为主」，年、月、日、时各有比喻，财官印食、旺衰和大运结合日干分析。这是**明代作品经清四库接受文本保存的日干核心命理叙述 C**，不是五代或唐代有相同完整十神规则的证明。
2. **辨名**：文中说子平系**徐君易（徐居易）的字**；后段却另称**徐大升**，并归属《三命渊源》《定真论》等。二者是不同的受读人物标签，不能因都写徐氏或同涉子平而自动合为一人；姓名、字号与真实时代仍须分别查。
3. **后出传承叙述**：文内讲述珞琭子→李泌、李虚中→徐子平→淳熙冲虚子→僧道洪→徐大升，属于**1578年作品体系内追述更早事件的故事链**，其早期环节缺对应同期原书、题记、师徒记录，现不能在图谱中写成 CONFIRMED edge。
4. **作者自身限制**：文中先提术法「其法不知经几变」，后又以「或谓」引徐大升获子平真传之说；有这种承认变化和转述的句法，不应取其中人物的排列就宣称从唐到元**规则从未变过、字句自始一贯**。

另阅[识典《三命通会》卷七 SK1610](https://www.shidianguji.com/book/SK1610/chapter/1kf5v7mmjmxvu)的现代标点文本作为局部受读对照。它与四库本互见并不能当成两个**独立明代原本**；两边暂未对绑定的纸本版叶逐字校勘。识典另有 HY1521 版本数字层，局部 OCR 用字与其他受读存在差异，本批不依 OCR 断 Ming 原字。

## 三、历史初步判断及后续最小闭合任务

可确认的广度成果：宋代及南宋编纂传统里**年本、日主、纳音、四组干支、月时干支**是需要分别研究且可并存的知识组件；元代《子平三命淵源注》**有清人保存的书末与序年款叙述**；明代作者既有**日主型理论叙述**又尝试解释子平术源流，但作者自己承认历史上术法改变。这三个层次足以扩充史纲，**不足以把「日主/十神」发明年定为五代或某一宋人**。

最重要的下一步不在不同网站间反复搜同句，而是取得：**元李钦夫书末1307年及王瓒中1326年序的原页**，以及它们与《三命通變淵源》/《淵海子平》实际篇章的相同误字或明确引用；优先免费无登录馆藏图像。若不可取，保存该缺口，转回明前紫微安星原始操作文本。
