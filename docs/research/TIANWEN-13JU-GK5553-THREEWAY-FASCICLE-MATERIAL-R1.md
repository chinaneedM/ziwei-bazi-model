# 天问 13JU：奎5553的册次与补配介质争议

2021年研究文章的2024年转载称奎5553补配第8、26、28册，卷81–83归于第28册，并称木板补写；首尔大学奎章阁馆藏研究表称第8、26、29册，其中第29册含卷81–83，注明部分抄本；国家遗产厅2114-1官方现代说明为第8、12、26册。以上均属于现代描述，尚无经认证的古装实物封面册号对应证明。
