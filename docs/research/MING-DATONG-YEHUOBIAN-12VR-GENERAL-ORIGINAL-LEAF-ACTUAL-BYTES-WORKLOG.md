# 12VR — 六馆原叶进入 IMAGE_CAPTURED 时必须核对实际字节
12UK 是适用于京大、北海道、东大、筑波、国立国会图书馆、内阁文库六个实体线索的通用接收入口。原入口 IMAGE_CAPTURED 接受形式为64位十六进制的来源/页图 SHA256 字符串、URL 和叶号，但不必提供原始下载二进制，因而可以让伪造或误抄的摘要获得“captured_images=1”的结构性承认。已有12VK给东京两项独立古本读字票增加实际二进制校验，但未覆盖此通用入口。此处是证据接收工程缺陷，不是确定性排盘算法缺陷。

本轮前向修复：
- 只有纯目录/数字化计划仍可无文件通过；实际采集必须显式提供 --artifact-root、source_local_file 与 pages[*].local_file。
- 在指定根目录内按流读取文件，SHA-256与声明全值比较。不可仅有64位占位值；目录穿越、绝对路径与外部符号链接均拒绝。
- 同一接收单内两个馆藏对象不能靠相同源PDF或页图字节装作两份新原始图；同一本内重复页图摘要拒绝。
- 版刻状态候选的引文字段增加 source_page_label，并要求和实际哈希通过的其中一页同名同哈希，避免“漂浮的跋语摘要”。
- 结构通过仍然不构成实体印次、原刻字形、版刻修订或文献传承投票；所有测试正样本都明确为合成二进制，仅为验证工程逻辑。

保留旧12UK、12SM队列、古籍Matrix与传承谱原状态；原字票0，新增实物来源0，R1排盘产品CLOSED、正式考据批次487/latest12QD。既有来源697、Matrix222/222、元数据修复45/45、传承谱252节点238边。下一步仍优先取得1827/1869原刻主题卷二十《改造漏刻》实体页与来源导出的真实二进制。
