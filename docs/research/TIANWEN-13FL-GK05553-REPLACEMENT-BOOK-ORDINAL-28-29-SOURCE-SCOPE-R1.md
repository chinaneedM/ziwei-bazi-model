# 天问 13FL｜《高丽史》奎貴5553 第28／29册补写标记冲突

## 本轮核验边界

在 `TW-OPEN-0005` 的奎貴5553《高麗史》卷52物理叶定位工作中发现**书目补写册次记载不一致**。此批次属于书目、版本和二手学术文献层，不是新增的古籍原叶校勘。

**馆藏机构一手目录**：[首尔大学奎章阁 GK05553_00](https://kyudb.snu.ac.kr/book/view.do?book_cd=GK05553_00)。书目列 `奎貴5553-v.1-46`、`乙亥字`、`139卷、卷首、合46册`，明确记补写为 **第8、26、29册**。其列出的卷50至52属曆志，但没有在公开纯文本中提供「作品卷52 → 实物第几册 → 叶号 → NIKH 图像1056」的认证映射。

**二手学术论述**：魏志江、陈卓《高丽史》版本源流与编纂体例考，机构[论文著录](https://sir.sysu.edu.cn/zh-hans/content/435)指向《史学史研究》2020年第1期。[在线转录／转载](https://www.haijiaoshi.com/archives/11423)记 **第8、26、28册**，并将第28册联系于卷81、82、83。原期刊PDF虽然可从机构页面发现，但本轮直接获取受限，**没有完成原刊逐页影像核对**。因此只能把「28」记作**已见于二手转录的具体待校线索**，不能倒推奎章阁馆藏记载“29”已经错讹。

## 非等价性与裁决

- 第一手馆藏目录的 **29** 和二手转载的 **28** 属于书目册次冲突；不能仅凭二手说明将「卷81—83」硬绑定到官方第29册，也不能断言两套书册计数相同。
- 两者都没有提供直接可审查的 **奎貴5553 卷52 目标叶原图**；「是否补写的第28／29册」和「卷52四分栏原字」属于两个不同待查问题。
- 13FK 国图NLC p74 第5日原字 `四分〇一七二`、NIKH 图中的 `四分五一七二` 继续相反；NLC 第9日书缝仍为 `null`。**不可用目录异文消除原图异文，也不可用数学补字认证古字。**
- 不产生新传承边，不新增历史独立实物见证，不重复计算来源数量；保留 G893 六组、卷52实物定位和四分/初度单位争议为 OPEN。
