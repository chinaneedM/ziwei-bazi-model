# 天问 13JM｜GK05553 第8／26册与相邻印刷册的六张原影像对读

由 13JK 的首尔大学第一方数字册目录 46 条与六份明确来源目录 HTML（run 40674164409、artifact 12809168697）选取原站实际输出的 `fn_originalImg` 页码，13JL 按官网脚本提交官方 POST 并从源页面给出的 `ImageServlet` 原链接取得六张有效 JPEG（run 40674394497，artifact 12809334156）。无 OCR。JPEG、原生 RGB 和双裁剪区哈希保存在同名 JSON。

与前批 13JJ 对照，在 SNU 同一馆藏数字书中直接观测到 0008、0026、0029 为手写形态，0011、0012、0013、0025、0027 为有印刷版框的字形。该结果在**此数字来源范围内**明确支持 SNU 8/26/29 补写叙述的版式特征，且能以源图哈希重放；它不是证明 8/26/29 与古装实体册序一一对应，更不能断言国家遗产部门登记的 8/12/26 是错误。

尚缺：实物装订和书背原页、修补史与馆方卷号转换表，指定古籍对象和现扫描对象是否同一实物的第一方确认，以及不同物理副本的精确刊印/抄配年代。旧 13IO 物理册第29→卷81–83 的过度断言继续标识 `RETRACTED_UNBOUND`，13JJ 新的数字册0029直摄卷81–83不回溯替换该错误。六张原页不计六份独立物理见证。G893 六数、GK3467 冬至 D1–D7、国图 NLC03130 太阳 D30／夏至 D14、四分与初度仍未获原字裁决，不重开排盘算法。
