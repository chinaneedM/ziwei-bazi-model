# 天问 13AI｜阿川书目增补关系的馆方证词与东京大学双目录 OPAC 入口

## 新增的证据边界

东京大学附属图书馆自己的 [阿川文库介绍](https://www.lib.u-tokyo.ac.jp/ja/library/general/collectionall/agawa) 在「目録」栏并列两条目录：

- 《阿川文庫目録 : 朝鮮本》，网页原生 OPAC 链接含 `bibid=2003433569`；
- 吉田光男作成、1998年3月《東京大学附属図書館蔵阿川文庫リスト》，另一原生 OPAC 链接含 `bibid=2003433575`。

这两个 **bibid 是网页给出的书目详情入口**，不能推断东京大学另藏了一件可供阅览的古关目录实体。该入口在本轮匿名网络访问返回 HTTP 403，带会话参数的链接不适合作永久原件索引；其馆藏位置、独立实物册数及原页都没有核实。

东京大学馆员于 **2014-12-18** 作成、经国立国会图书馆参考协同数据库存档的 [ASK0000025540 答复](https://crd.ndl.go.jp/reference/entry/reference/show?id=1000178954) 称 1998 年吉田目录为「**書写目録を増補した**」的列表，给出《朝鮮文化研究》第5号（1998年3月）pp.139–202、`総合図・書庫 ZG:257`。这是比泛泛书目并列更强的 **编纂关系证词**：可以说存在馆员所述的「原书写目录 → 增补列表」关联；**但这并非早期古关目录的逐条原页，也没有证明具体哪一条被直接抄录、改订，或两个目录存本的实物传承关系**。

## 承接 13AH 的纠偏

13AH 对古关吉雄《阿川文庫目録 : 朝鮮本》（CiNii `BA63404722`，九大石崎文库实物）的说明保持有效：九大与 CiNii 对**同一件九大实体**的核对，不是两份古籍数值见证；目录完整内容未见。13AI 只新增上述官方**编纂关系描述**，不回写篡改 13AH 的原始批次，更不能以目录名相同断言东京大学存在第二本可阅古关实物。

同样，13AH 的 G23:236《朝鮮記》南葵来源反例持续生效，**G23 前缀既不专属阿川，也不专属南葵**。两本需要直接阅页的《高麗史》卷52 仍然分别是：

- 钞本：`BC15670118 / G23:12 / 0008535809`；
- 刊本：`BC15973641 / G23:194 / 0008542011`。

两者不因书目增补关系获得阿川所属、具体版刻或原书 D16 数值任何认证。1998 列表原文和古关早期目录原文都没有在本轮逐叶取得；不能肯定其中有《高麗史》目标条目，也不能依据公开目录搜索未命中而断言缺载。
