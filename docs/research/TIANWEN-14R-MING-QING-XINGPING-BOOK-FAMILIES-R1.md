# 天问 14R｜明清《星平會海》与《星平總會》的书名、版本及馆藏分层

日期：2026-11-18。阶段：双体系历史源流广度优先；本批聚焦四柱命书与相邻星命书籍的出版、汇编及存世馆藏，不把书名邻近当作同书、同版或同一机械规则。

## 一、明清文献的并列短题

《千頃堂書目》卷十三[传本文字](https://ctext.org/wiki.pl?chapter=651896&if=gb)并列「星平會海十卷」「星平總會十卷」。[识典另一本来源层的转录](https://www.shidianguji.com/zh/book/NGJ892411999007626100720/chapter/1lwqbdkfi7h23)供交叉检索，不当作独立古物投票。两书在书目中有两个独立条目，是 C 级**传文/编目事实**；短题对应的原书及初刊年、两者是否同书，皆未证。该书目与《渊海子平》同列不能导出作品间传承。

## 二、1611年《新刻星平總會命海全編》不同长题

台湾国图[中文古籍联合目录](https://rbook.ncl.edu.tw/NCLSearch/Search/SearchDetail?HasImage=&SourceID=1&item=ec7c6e87db3e450682730b956929836cfDkzNzYy0.iNUyTPtdmCRvYQ3Zuup7vvP8dhcjbhMJtIukIkRL8uc_&page=80843&sourceWhereString=&whereString=IChOVUxMSUYoRGF0ZV9DcmVhdGVkLCAnICcpIGlzIE5VTEwgYW5kIE5VTExJRihEb2N1bWVudF9ZZWFyLCAnICcpIGlzIE5VTEwgKSA1.uQrV5XxqrHh4fOCXMwOuuzssvPVRwJbumFyT4mFEUCA_)记正题《新刻星平總會命海全編》，薛承愛遗稿、夏从仁编汇，十卷首一卷，明万历三十九年辛亥（1611），现藏美国哈佛燕京图书馆，登记号 tracy30002881，等级 B（第一方联目）。1611是目录标示的出版年，不是此作品初创年；遗稿题署仍待原始序跋牌记鉴定。与《星平會海》十卷或《千頃堂書目》短题之间不能仅凭相似名称合并。现代[识典收本文字](https://www.shidianguji.com/zh/book/HY1442/chapter/1koboy2q7bbws)只作 C 级章节查找，不代表1611原刻逐字核读。

## 三、1877年《增補星平會海》两组馆藏线索

日本 [CiNii NCID BA53550615](https://ci.nii.ac.jp/ncid/BA53550615)记《增補星平會海命學全書》十卷首一卷，水中龍编辑、未會龍校正、汪淇重订，光绪丁丑（1877）刻本，部分朱印，封面「增補星平會海全書」，版心「星平會海全書」，明载「墨潤堂藏板」「還讀齋原本」。筑波大学图书馆记录六册，列册为首、卷1、卷3–4、卷5–6、卷7–8、卷9–10。**馆目没有单列卷2**，只构成书目描述疑点，不等于原书确实缺卷。

台湾[国家文化记忆库对象 107000002293](https://tcmb.culture.tw/zh-tw/detail?id=107000002293&indexCode=MOCCOLLECTIONS)单独登记国史馆台湾文献馆所藏、同标1877和墨润堂/还读斋的一份《增補星平會海全書》，馆方介绍红字序、目录、本文图页。两组机构条目支持分别记录**馆藏对象**，不能据相同刻印语认定为**同一实物、同板、同印或同一数值字形**。台湾网页提示有限度公开浏览，本批未复制或发布受限制图片。

## 四、历史判断、待补及传承影响

这一组材料将晚明书目、1611年独立长题刊本，以及1877年版本/跨地域藏本纳入四柱史纲的**星命与子平混合文献环境**。作品编排上的并载并不意味着星度、四柱、十神、十二宫算法同源或可直接互借。《四庫全書總目》[卷111收文](https://www.shidianguji.com/zh/book/SK0000A/chapter/1kgsnqwe3a1an)对《星平會海》内容组合及讹舛提出批评，属清代编者的 C 级接受与评价，绝非历史精度或预测效力的现代实证。

下一证据目标：（1）可核《千頃堂書目》原页及二短题边界；（2）1611哈佛本卷端、序跋、目录与正文的独立图像；（3）筑波馆目卷2展示缺位的实物/合订复核；（4）台湾与筑波1877藏本版式印记、正文页对读；（5）只在同一具体机械规则有足量原页证据时才追加传承图谱关系。现不建立直接继承边。
