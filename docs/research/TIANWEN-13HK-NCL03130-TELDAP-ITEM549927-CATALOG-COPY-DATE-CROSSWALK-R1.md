# 天問 13HK — 數位典藏聯合目錄 549927 的 NCL 03130 物品號交叉綁定與抄補年代防火牆

本批發現並直接核對臺灣「數位典藏與學習聯合目錄」的 [《高麗史》549927 條目](https://catalog.digitalarchives.tw/item/00/08/64/27.html)，不再只沿 Commons 個別 PDF 的上傳備註判定書目身分。此為**機構級聚合書目**正例，不是國圖目前原生物品詳目、古籍原葉或新物理見證。

## 一、可核對的書目層原文與標識

聚合條目明列「書號:03130」、「善本書-原件」、鄭麟趾、線裝、40冊、全幅25.7 x 16.9公分。站內館藏機構與專案路徑為「國家圖書館／古籍文獻典藏數位化計畫／善本古籍典藏數位化子計畫」，出版平台尾端署「中央研究院數位文化中心」。該記錄另載「手書題記者:(清)吳騫;(清)吳重熹;(清)唐翰題」。這比 Wikimedia 上傳檔案標籤多了一層館方來源指向，對 **03130=該《高麗史》聚合館藏身份**有支持；不構成另一個獨立抄本或新增原葉字形投票。

直接沿條目標為「連結到原始資料」的來源連結，現抵達 [國圖古籍影像檢索通用頁](https://rbook.ncl.edu.tw/NCLSearch/Search/Index/1)，未直接取得 03130 的來源原生逐件物品頁、物理葉號或高清第十四日。此為**當前 URL 導引作用域**，不能判定國圖不持有原書、無掃描或不能申請重製。

## 二、複合抄本年代的文字位置不可混讀

聚合目錄將版本欄寫作「清初葉舊鈔光緒間(1644-1735)錢塘丁氏補鈔本」，日期欄另外標「製作時間:1644-1735」。括號的年段接續在「光緒間」之後造成表面年代歧義；**1644–1735 不能被當作光緒間的年代，更不等於所有補鈔部分或卷52第74數字頁的紙墨年代**。這應視作彙整 metadata 的作用域/格式疑點；既不能靠這個混合欄為原葉精確斷年，也不能據此推定館方書目整體失真。第一方原件的缺卷朱記、卷52是否丁氏補抄、頁紙墨仍須獨立查證。

## 三、沿用已取的直接影像而不偽補缺字

13HE 已封存的 NCL-03130_09 第74頁與其 PDF 哈希不改，NCL 原件 D14「四分」後完整串及末字仍 **NULL**。NIKH 官方來源照片單獨直接讀出的「夏表十四日／四分六六三〇」僅見證**該 NIKH 圖片**。D5「〇／五」、G893 六控制、「四分／初度」技術同一性、古單位及卷52複合舊鈔層次均繼續 OPEN；13EI 撤回保持。

## 四、下一步

先由館方來源自身發出 03130 詳目和卷52 原葉識別，再依合法研究高清服務取得帶 SHA256 的正式圖像，綁定日期、欄、原葉和補抄層後逐字核讀；只憑聚合書目和 Commons 24 個數位分件，不可推導 40 冊物理裝訂映射。
