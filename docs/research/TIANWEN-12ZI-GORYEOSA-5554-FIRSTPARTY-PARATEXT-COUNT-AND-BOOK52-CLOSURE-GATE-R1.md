# 天问 12ZI｜奎貴5554 卷首／目录计数与卷52实物门槛

## 结论

在12ZH的**95（现代遗产说明二级复载）／100（学术文章）项编号正文卷**逐段算术基础上，本轮引入奎章阁**第一方馆藏总目中另外一件奎貴5553**的独立“卷首1、目录2、正文137卷”拆分，建立仅作**假设检验**的计量模型，而不把5553的实物内容移植给5554。

## 新复核的第一方记录与层级

- [首尔大学奎章阁馆藏总目](https://kyudb.snu.ac.kr/brd/viewBrd.do?book_cate=HEJ23&focus=d11sd114&listChk=tree&menuId=10022&mid=HEJ&postSeq=10775&siteCd=DBSP) 表1直接列：**奎5553：卷首1、目录2、137卷、46册**；但**奎5554：残存32册乙亥字本**，没有5554的逐卷、逐册明细（不等于否认它有卷首/目录）。该表另有**奎3467第6册对应作品卷52**，这是**另一馆藏物品**，绝不据此称“5554第6册=卷52”。

- [国家遗产门户第一方摘要](https://heritage.go.kr/heri/cul/culSelectDetail.do?ccbaAsno=0021140000200&ccbaCpno=1121121140200&pageNo=1_1_1_1&sngl=Y)为98卷32册，时代归类1482；此年份不覆盖馆方“刊年未详”。

## 数量推演：条件式，不是裁决

| 计算项 | 现代遗产复载范围 | 学术文章范围 |
|---|---:|---:|
| 逐项列举的不同编号正文卷 | 95 | 100 |
| 各自宣称总卷数 | 98 | 105 |
| 未解释差额 | 3 | 5 |
| **假设**两目录卷与一个卷首单位均额外计入 | 95＋2＋1＝98 | 100＋2＋1＝103 |
| 在上述假设下仍差 | 0 | 2 |

这表明**98可以被一套条件式计数模型算术解释**，但没有证明5554的各项卷首、目录实物形态及馆方使用这一口径。更重要的是，同一书“总139卷”可由“137正文＋2目录”形成，但“卷首1”可能被另列；不可随意在139、98、105之间反复增减。
