# 天问12ZO｜《高丽史》初刊年代争议与馆藏实物印次防火墙

## 新增独立书目史证据

本轮将具体官修史记载、韩国国史编纂委员会的历史说明、韩国学术期刊论文摘要和首尔大学馆藏目录放在**四种不同的证据等级**中比较。

1. [《端宗实录》1452年11月28日原文](https://sillok.history.go.kr/id/kfa_10011028_002)明确记“春秋館啓請印《高麗史》, 從之”。其机械事实是**奏请印书、获准**，没有在该条直接记载完成印刷、分发或证明现存某份书的印次。
2. [韩国国史编纂委员会《高丽史节要》历史说明](https://contents.history.go.kr/mobile/kc/view.do?levelId=kc_r300225)将《高丽史》刊印置于**1452年11月**，将《高丽史节要》置于**1453年4月**。这是现代史学解释，不能偷换为该条奏准诏令本身即完成印刷的原件证据。
3. [KCI登记：김광철（2014），《『고려사』 판본과 그 간행 시기》，《석당논총》第59期，145–174页，DOI 10.17842/jsa.2014..59.145](https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART001898033)，官方摘要称两部书于**1453年4月**首次刊印，并把最初的甲寅字 / 10行17字明确表达为推测；又将乙亥字版刊印置于**1475年末—1476年初**、以乙亥字为依据的木刻翻刊置于**1610年末—1613年9月前**。**本轮直接核对的是KCI公开的署名摘要与书目，不是论文全文、初刊原页或任何具体乙亥字印本。**

由此发现真实而有限的**现代史学时间解释差异**：国史编纂委员会历史说明的1452/1453二书分期，与KCI 2014摘要的1453同月初刊表述并不一致。此差异不能仅凭更有名的机构或更晚的发表时间决定谁对；须找到完成印刷与分发的同时代明文再裁决，也不能把“命令印刷”等同于“已经印成”。

## 后续版本年代不得倒灌到物理原件

- [SNU奎贵5554](https://kyudb.snu.ac.kr/book/view.do?book_cd=GK05554_00)的馆方书目具体写**乙亥字、零本32册、[刊年未详]**。1475—1476只是2014学者给出的**版系刊印研究年代**，不是此馆藏实物的刊年证明。
- [SNU奎贵3579](https://kyudb.snu.ac.kr/book/view.do?book_cd=GK03579_00)另为**木版本、馆录[光海君5年(1613)]**；不能因为木刻系据乙亥字本翻刻，就视为其卷52太阳盈缩表D16/D18数字必与早一版一致，也不能反推奎3467第6册属于哪份子书目。
- 《高丽史》1451年成书日期、1452/1453初印事件、1475/76乙亥字版系、1610–1613木刻翻刊、现存实册印次与现代数字替身时间必须六层分开。**相同版系不等于同一实物，木刻翻版也不等于目标数值全同。**

## 本批裁决

本批只补充**初刊争议与版系年代的学术来源范围**，不增加物理原叶或数表异文证据。奎3467整组第6册对应卷52仍只成立于馆方组级解释；子号映射未决；奎5554卷52原叶未得。G893原来源控数仍**5/6**，跨独立实物逐值裁决**0/6**；全部11项遗漏风险保持开放；Matrix **222/222**、修复**45/45**、来源总数**647+59=706**、传承谱**252节点/238边**、排盘R1 **CLOSED**，算法重开数**0**。不新增谱系边，不以现代学者论述冒充古代物理原件。

下一证据门槛为：1452—1453年**印成/分赐**同时代记录，以及SNU提供的具体实物号、卷页、原图SHA与D16/D18行字；两条证据链分别完成，不得互相代偿。
