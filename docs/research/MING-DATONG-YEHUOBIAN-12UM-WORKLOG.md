# 12UM — 京都《野獲編》卷首与卷20源发馆藏件分离及取得门禁

## 直接馆藏事实与缺口

[CiNii BB18578034](https://ci.nii.ac.jp/ncid/BB18578034) 明示 **卷首/卷1** 的京都馆藏号为 `B||VIb||9-1 188987`，**卷19–20** 的独立馆藏项目号为 `B||VIb||9-1 188987L`。一个 NCID 的书目聚合不使两个具体分册等于同一张原叶，卷首日期不应直接覆盖〈改造漏刻〉文字印次。12UL 已确认书目「康熙30年[1700]」的纪年矛盾，但京都该件卷首原页**未取得**，无法决定该馆实物如何印写年份。

## 图像及正规取得渠道

[京都大学贵重资料数字档案官方说明](https://rmda.kulib.kyoto-u.ac.jp/about) 明确介绍公开影像与 IIIF 的一般机制；在本轮所审公开路线，**没有绑定到 188987 或 188987L 的源发影像/manifest**。这只是尚未定位到，并不等于证明该馆藏未数字化、不得复制或馆方无影像。

[京都大学文学研究科图书馆官方服务资料](https://www.kulib.kyoto-u.ac.jp/newdb/12109) 对和汉籍等特殊资料提醒部分不可普通复印；[馆方图书馆间复制指引](https://ceschi.bun.kyoto-u.ac.jp/archive/bun_archive/lib/external/ill-2.html) 描述经所在地机构的付费复制申请路线。**这两项均是一般政策，不是对 188987/188987L 个件的许可、报价或可复制性确认**。没有对馆方发送消息、下单、付款或取得图片。

本批以新机器记录 `docs/research/MING-DATONG-YEHUOBIAN-12UM-KYOTO-DUAL-ITEM-ACQUISITION-GATE-R1.json` 将两个所需件的证据用途、图像门禁、申请前核实步骤和印次边界独立列出；保留历史 12UK **六个原叶候选**数据原样，新增卷首采集前置账本，不重写先前记录。回归测试 `tests/test_yehuobian_kyoto_two_item_acquisition_12um.py` 阻止把卷首当卷20异文证据，也阻止一般复制政策直接转换成实物印次支持。
