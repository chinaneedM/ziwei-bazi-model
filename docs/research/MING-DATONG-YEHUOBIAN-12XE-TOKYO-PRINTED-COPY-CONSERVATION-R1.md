# 12XE — 东京《野获编》两藏本的保藏状态与独立印版边界

本轮检验 NII/CiNii 两个实物书目。1827 年大木文库本（物品6403767830）全套34册4帙，目录写虫損甚だし、シミ、破損、カスレ多し；并非特指卷20目标叶破损。原目录为 https://ci.nii.ac.jp/ncid/BC0492354X 。

1869 年仓石文库本（物品6403148395）全套20册2帙，注明重複: 卷30第12葉；不能倒推卷20叶损。目录 https://ci.nii.ac.jp/ncid/BB23196128.amp?l=en 。

两者目录均记十行二十一字，版框分别18.4×13.2厘米与18.2×13.1厘米。此类尺寸与用语差别不足以证明不同木版，也不能证明共版。只有分别取得两件原本《改造漏刻》同一目标叶的源图、馆方绑定证据、页码及明确印次，才能判断四处字形与版片关系。无原叶、无申请、无古字投票、无算法重开。来源647+59=706，Matrix222/222，修复45/45，图谱252/238，正式批次487，产品R1 CLOSED。
