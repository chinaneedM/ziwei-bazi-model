# 天问12ZH｜奎貴5554《高麗史》98卷／105卷目录逐项算术核验

本批**只校对现代目录陈述的卷数、列举范围与馆藏定位**，未取得奎貴5554卷52原叶；因此没有新增古籍影像、字形裁决、独立传承证人、算法重开或史料来源注册表条目。

## 四层证据不可混同

- **馆方第一方目录**：首尔大学奎章阁 [GK05554_00](https://kyudb.snu.ac.kr/book/view.do?book_cd=GK05554_00) 明记 **奎貴5554 / 零本32冊 / 乙亥字 / [刊年未詳] / 宝物2114-2**。网页通行目录把卷50—52列为曆志，但这属于《高麗史》全书目录，并非5554号具体残存原叶及册号验证。
- **国家遗产第一方总览**：[高麗史(2021-2)](https://heritage.go.kr/heri/cul/culSelectDetail.do?ccbaAsno=0021140000200&ccbaCpno=1121121140200&pageNo=1_1_1_1&sngl=Y)标注 **98卷32册、1482年时代**；原物可证印次年仍未获标记。该网页详述文本本轮无法逐行获取，因此以下逐项存卷表只按二级复载核算，**不升级为直接读取国家遗产原页**。
- **二级复载并注明来源于文化财厅的说明**：[2114号复载](https://7390882.tistory.com/entry/보물-2114호) 明列 **卷29及卷35两卷**（第5册），并列卷40—52位于**第6—10册范围**，没有给出卷52独占哪一册。逐项范围展开合计 **95个不同的编号正文卷**，而该复载总称98卷，差 **3**；卷首材料是否计入总数、计量口径如何均待官方原表和实物核查。
- **二级学术论文叙述**：[魏志江、陈卓](https://www.aisixiang.com/data/121297.html)称 **105卷32册**，其列举范围写作 **卷29—35**、卷40—52；逐项范围展开仅得 **100个不同的编号正文卷**，距宣称105还差 **5**。两份列举在卷29与35之间的卷30—34恰有 **5卷**差异，仍不能解释两套宣称总数的 **7卷**差异。
