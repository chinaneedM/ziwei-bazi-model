# 天问12ZJ｜奎貴5554：卷制139－41与逐项95卷计数的冲突

本批前瞻记录 **12ZI 后继续开放的一卷差额**，未取得卷52古印原叶。

- [韩国学中央研究院《高麗史》总论](https://encykorea.aks.ac.kr/Article/E0003456)列世家46、志39、表2、列传50、目录2，构成**137正文＋2目录＝139标准编号卷**，卷首不在该139之内。
- [奎章阁第一方GK05554_00目录](https://kyudb.snu.ac.kr/book/view.do?book_cd=GK05554_00)明记卷首《进高丽史笺》《高丽世系》和《目录》，但仍是目录字段，并非本轮逐叶图像；具体卷52在哪册、D16/D18印字、物理印年皆未证。
- [国家遗产门户](https://heritage.go.kr/heri/cul/culSelectDetail.do?ccbaAsno=0021140000200&ccbaCpno=1121121140200&pageNo=1_1_1_1&sngl=Y)显示98卷32册，本轮详情原页打开报HTTP403；[二级复载](https://7390882.tistory.com/entry/보물-2114호)说全139缺41剩98，列举的编号正文卷只有95。这些不同来源**不能充当多个古籍实物证人**。
- 若复载95正文卷完整，正文未列出137－95＝42卷；假设两卷目录仍存，标准编号卷现存95＋2＝97，标准卷缺139－97＝42。与现代遗产宣称**98、缺41**仍差1。另把一个未编号卷首也计入，97＋1＝98算术成立，但改变了分母口径；**139－41＝98本身不能独立证明实际缺41原卷**。
- 二级复载所述5554封脊“日／共四十三”与现存32册相减为11，但**数字差≠证实遗失11册**。另一个5553物品有46册、3册抄补；所谓43册印刷余本＋3抄补＝46也仅为相容候选，并无此处原图证实。不得把5553、5554、3467册次相互替换。
