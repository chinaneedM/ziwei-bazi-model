# 13ZQ｜《滴天髓》明末原刻锚点与《神峰通考》清代版次、现代接受史

核验日：2026-11-16。研究阶段：天问双史纲**广度优先**。本轮先核具体馆目与现代书目责任层，不把传统作者归属、印本年代、纸本文本、影印数字页和后人书名合为单一古本。**未逐叶核读原刻，不作规则正文原字或机械规则首证。**

## 一、明末《滴天髓》可定位实体物件

台湾国家图书馆古籍联合目录的[原生条目](https://rbook.ncl.edu.tw/NCLSearch/Search/SearchDetail?HasImage=&SourceID=1&item=f8f392c465d94bb6a34e379e56a64e86fDQwMDU0OA2.adXuAD1rRRBqx1zYDBkl59_U_ZMpoT3a1iPPpgnG2fQ_&page=3&sourceWhereString=&whereString=IChDcmVhdGVyX05hbWUgbGlrZSAnJeWKieWfuiUnIG9yIERvY3VtZW50X1dyaXRlciBsaWtlICcl5YqJ5Z-6JScgb3IgSm91cm5hbF9Xcml0ZXIgbGlrZSAnJeWKieWfuiUnICkg0.o5sFVpPceVgdNFF_uld5uOi4Ih6_so95gM3SoDe1yFA_)：

- 书名：《**新鍥誠意伯秘授玄徹通旨滴天髓**》**二卷**；书号 **06619**，登录号 **rarecatx0306713**；线装**一册**，版本栏明确写**「明末長庚館刊本」**。
- 目录责任说明为「(明)劉基（撰）；(明)窺豹生（序）」。这是**馆目题署 B**，并非刘基生前撰书、京图原作者或二者具体著述传承的直接史证。
- 同一馆藏件的[Commons 69页公开扫描登记](https://commons.wikimedia.org/wiki/File:NCL-06619_%E6%96%B0%E9%8D%A5%E8%AA%A0%E6%84%8F%E4%BC%AF%E7%A7%98%E6%8E%88%E7%8E%84%E5%BE%B9%E9%80%9A%E6%97%A8%E6%BB%B4%E5%A4%A9%E9%AB%93.pdf)标注**同为 NCL-06619 的数字替身**、尺寸 2062×1481、13.2MB；其元数据另录序跋「龍飛乙丑菊月窺豹生題于長庚館 詹顯宇梓」。**本轮网页仅核到文件说明，原PDF未成功载入做逐页视觉判字**，不能将传写元数据伪装成直接原图核读，也不能把Commons和NCL计为两件物理印本。
- [2020年现代校订者的凡例](https://www.xinyi.hk/article-513.html)明确把长庚馆本细定为**天启五年1625**、周抚金校订、詹显宇刻。它属于**现代版本研究的待原件复核说法 C**；第一方馆目只写「明末」，目前不把1625直接标成原书已核刻印年。序文「乙丑」即使能定位明代1625也须与刻印发生的日期分开。

**历史意义（有界）**：至少有明末具体刻本馆藏锚点，而不是只能从任铁樵／徐乐吾及现代网文倒推《滴天髓》的历史。**未解决**：早于此物件的文本源头、所谓宋京图与明刘基实际作者、序与正文是否同次刊刻、明刻和清民国诸本的段落和图表差异。

## 二、清代《神峰通考》的物件锚点

台湾国家图书馆[中文古籍联合目录](https://rbook.ncl.edu.tw/NCLSearch/Search/SearchDetail?HasImage=&SourceID=3&item=ca8c06e2f15348e1af7383df2ad7498ffDE5NzUyMQ2.Fh1ynpfmvYMuwBKjGnRKx3kFsez0_wFNzG5vlhkP2bQ_&page=1795&sourceWhereString=&whereString=IChOVUxMSUYoRGF0ZV9DcmVhdGVkLCAnICcpIGlzIE5VTEwgYW5kIE5VTExJRihEb2N1bWVudF9ZZWFyLCAnICcpIGlzIE5VTEwgKSA1.uQrV5XxqrHh4fOCXMwOuuzssvPVRwJbumFyT4mFEUCA_)著录《**重鐫神峯通考命理正宗**》**六卷**，题「(明)張楠撰」，明确为**道光十年庚寅（1830）楊氏四知館書坊刊本**，登录号 **rarecatx0509886**。

该条是可定位的**清代重刊版 B**。书名中的「重鐫」只提供本书自我命名的再刻线索，**未取得明代先刻本原叶及其刊印日期**，不能直接说「张楠明末所撰六卷已经由1830本原样存续」。《神峰通考》的起八字、格局、病药等规则主题，仓库根来源已有 `EXT-CTEXT-SHENFENG-TONGKAO` 与 `EXT-CTEXT-SHENFENG-TONGKAO-QIBAZI`，**仍是文本接受层**，不能将其逐字等同1830原刻。

## 三、现代再版登记属于另一个时代层

- [CiNii BA57765395](https://ci.nii.ac.jp/ncid/BA57765395?l=ja)著录香港**上海印书馆 1981年10月再版**《神峰通考辟谬：命理正宗》，张楠编著、韦千里与尤达人校订，**上下二册**；日本大学馆藏属于**出版与保藏实证 B**，不证明其具体底本就是杨氏四知馆1830本，亦不凭作者并列推导师承。
- [CiNii BA4749028X](https://ci.nii.ac.jp/ncid/BA4749028X)著录台北集文书局**1990年9月**《订正滴天髓征义》，刘伯温原著（署名）、任铁樵注、徐乐吾订正增注；书目**482页**。这是**现代接受及责任标注 B**，不能证明所题刘伯温原作、任氏清代确切注年或其与明末长庚馆本同一正文。
- [2020年校订者凡例](https://www.xinyi.hk/article-513.html)另按版本表述1658陈素庵辑要、《星平大成》所称「嘉庆九年／1796」的内部矛盾年份、1807刘元奇校本、1824程芝云本、1933袁树珊阐微、1935徐乐吾征义、1937补注、1947李雨田阐微；其中「嘉庆九年」应对应**1804年**而非文中所写的1796年，必须保留为**现代书目内部年代冲突**，不得以1796替代清原版刊印日期。本次一律标为**现代整理者列出的 C级待核物件清单**，不伪装成本轮逐项取得的清民国原书。特别是「任铁樵」与「任其昌」身份合一，以及不同阐微／征义／真解本的正文关系，需要物理原页。

## 四、修正双史纲的时间与知识范围

| 时段 | 《滴天髓》家族 | 《神峰通考》家族 | 不可越界 |
|---|---|---|---|
| 宋／明前 | 京图等归属为后世题署 D | 张楠明人题署 B 的作品层，明刊原件 D | 不把题署当作品最早年代 |
| 明末 | NCL-06619 **明末长庚馆本 B**；1625校订者说 C | 明刊先本 D | 不能认定两书互相引用或直接承袭 |
| 清代 | 1658–1824系列由现代校订者列为 **C待核** | **1830四知馆六卷 B** | 有文本与刊本不等于确定修订关系 |
| 民国 | 1933–1947后出注校版本现代回顾 C | 民国其他重排本待审 | 不把民国注解倒填明刻 |
| 1980年代及之后 | **1990集文《订正征义》B** | **1981香港再版本 B** | 日本馆藏只是现代出版物保存，非当地古法直传 |

## 五、风险、来源与停止条件

1. 新增五项**目录／编辑来源记录**，不新增同一 NCL 实物的第二来源投票；图谱本轮无可靠新直接承袭关系，不强行加边。
2. 原始明刊《滴天髓》NCL 06619 与 1830《神峰通考》具体原叶尚未人工校读；Commons 69页只确认存在与身份，**不是已核69页**。
3. 下一阶段在这两作品的原刻卷端、序、牌记及关键规则条之间做**具体样页级**比对，再调查清、民国注校版本；在全史覆盖完成前不过度固着于某一字句。
4. 保持 **11项未决（其中5项P0）**、TW-OPEN-0005 G893 **5/6原控制／0/6终裁**、Matrix222/222、确定性排盘 CLOSED。本批不解决 TW-OPEN-0005、0006、0007，不更改原版研究结论。
