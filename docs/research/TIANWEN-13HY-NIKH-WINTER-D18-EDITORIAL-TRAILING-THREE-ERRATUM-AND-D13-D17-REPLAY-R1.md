# 天问 13HY：第十八日尾字「三」前向勘误与十三至十七日重放

## 纠正 13HX 的不当数字归一化

韩国国史编纂委员会（NIKH）[《高麗史》卷52《授時曆立成》](https://db.history.go.kr/goryeo/level.do?levelId=kr_052_0010_0010_0020_0010&types=o) 冬表第十八日「盈縮積」现代校录为 **八千四百二十四六四〇八三**。13HX 在 JSON 里保留此字串，却将其错误编码成 **84246408**，等于擅自略去了末尾「三」，并据此声称 D17→D18「盈縮積」递推可成立。该一项断言现正式**撤销**；旧档案及 Git blob SHA 原样保留，以便审计。

[维基文库《高麗史》卷五十二](https://zh.wikisource.org/wiki/高麗史/卷五十二) 的二级收本为 **八千四百二十四六四〇八**，确实没有末尾「三」。两个现代文本层的异文并非两份原书，不能决定原叶字形；目前仍无获核验的源原页可裁决。

## 不使用第十八日：重放十三至十七日

只使用 NIKH 同一官方现代校录的四组安全跨日转移。定义 A 为日差，B 为盈缩加分，C 为盈缩积。将数字字串临时拼接成无量纲比较整数，并不命名历史单位。

| 日期 | A(n) 原文整数 | B(n) − B(n+1) | A−差值 | C(n+1) − C(n) 等于 B(n) |
|---|---:|---:|---:|---|
| 十三日 | 51804 | 51804 | 0 | 是 |
| 十四日 | 51990 | 51990 | 0 | 是 |
| 十五日 | 52176 | 52176 | 0 | 是 |
| 十六日 | **51362** | **52362** | **−1000** | 是 |

四组 C 差分与 B 一致；四组 B 差分与 A 有三组一致，唯一异常是十六日。此前 NAJ、早稻田、NDL1909 三馆原像第十六日均见 **五分一三六二**；**五分二三六二**只作为数学反事实，不可覆盖原本。
