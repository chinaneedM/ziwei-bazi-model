# 天問15BH｜朝鮮《唐四柱》十二星法：從「四柱」同名劃出異質機械分支，重新定位中日文本關係

日期：2026-11-22。研究階段：**兩系歷史骨架廣度優先**；補朝鮮、近代日本館藏與中國《三世相》的術語/版本入口。新增六個**文書/館藏描述/學術摘要/现代受读对象**，不是六個新古代實體或六份直接校勘原頁。

## 1. 「四柱」是一個生辰語彙，不保證「子平八字」同一機械系統

[韓國學中央研究院百科《당사주（唐四柱）》方法條](https://encykorea.aks.ac.kr/Article/E0013895)（1995初撰、2022-09-23修訂）**明言其與一般四柱方法不同**：
- **常見子平/八字**：年、月、日、時各有天干地支，常用日主、五行生克、月令、十神與歲運；這只是現代定義概括，每一歷史家族仍需原文別核。
- **朝鮮唐四柱（당사주）**：受讀方法先將十二星按地支順序排列，以生年定第一星；從所得年位數生月，再由月位數生日、由日位數生時，得到所謂初年、中年、晚年、平生四段星象標記。百科列天貴、天厄、天權、天破、天奸、天文、天福、天驛、天孤、天刃、天藝、天壽。**本輪只核百科對方法的說明，沒有核某一實物寫本精確步距或起例**。

這是出生年/月/日/時四個時間條件*共同進入*兩種方法，但由此不能推「韓國唐四柱＝中國子平四柱（八字）」；同样不能把「四柱」當作四套星的詞義普遍結論，或拿唐四柱十二星替代紫微星系。

該百科接著宣稱唐李虛中開創、宋徐子平編著《淵海子平》。**這些是1995/2022百科作者的歷史敘述**，不是唐代原本、宋版自序、原件印年或演算法原稿。更不能由題名「唐」跳到「唐代製成的《唐四柱》」。

## 3. 2011書誌學假說：圖像相似是重要線索，不等於古書直傳

[김시덕 Kim Shiduck, 2011，《書誌學報》37，75–103](https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART001567227)（公開韓文/英文摘要可核）將唐四柱圖像本分為**A型**和**B型**：比較構圖、色彩，提出A型比通行B型可能更早的觀察；同時推測二型或許與中國宋明期《演禽斗數三世相》有關，並比較16世紀末到17世紀初日本抄錄的另一中國文獻圖示，猜測更早共同祖本。

本輪**未取得全文、單幅對照圖及兩個被比物件的確定葉號/版刻身份**；摘要也明言A、B兩型是單一連續系譜還是分支仍待研究。證據層級：
- **直接成立**：2011年學界存在一個可引用、有明確論題與刊期的圖像比較假說；朝鮮唐四柱受到嚴格文本與圖像史檢討。
- **目前未證**：宋明某原卷必是兩型共同祖本；日本那份抄本就來自韓國；傳播路線一定「中國→日本→韓國」或逆向；兩種十二星、演禽與子平十神起法相同。

更重要的反誤讀：「斗數」在《演禽斗數三世相》題名中**不能自動視為紫微斗數十四主星/十八飛星盤的來源**，即便都用生辰、十二宫、星辰等廣泛詞彙。兩系圖譜不連邊。

## 4. 15BH歷史框架定位與待辦

這批補充**朝鮮時期—近現代韓國民俗命理**的另一個書名/方法分支，並添加**中國明代受讀文本索引、朝鮮圖解寫本與東京館藏見證、現代比較學術立論**。它不替代此前13ZU/15AV《紫微數》或15BA/15BC朝鮮《筆苑雜記》所見不同的紫微/四柱證據，不能從書名互換兩部著作。
