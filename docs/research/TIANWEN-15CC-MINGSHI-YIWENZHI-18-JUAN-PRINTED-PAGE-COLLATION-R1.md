# 天问 15CC｜《明史藝文志》卷三十八卷書目歸屬的直接印頁核對

日期：2026-11-23。承接15CB《星學大成》五／十／十八／三十卷書誌分層，廣度優先補一條**可定位的20世紀排印書頁**，不作歷史作者或星曜規則定論。

## 一、可重放的頁面定位

- 數字對象：[Commons/NLC416-06jh006731-3045《明史藝文志》PDF](https://upload.wikimedia.org/wikipedia/commons/8/81/NLC416-06jh006731-3045_%E6%98%8E%E5%8F%B2%E8%97%9D%E6%96%87%E5%BF%97.pdf)。
- **PDF第56頁（0-based index 55）＝書內印頁「五二」**。此頁直接目視見「萬民育三命會通十二卷」之後接「陸位星學綱目正傳二十卷 星學大成十八卷 張果星宗命格十卷」。原頁無現代句讀；按陸位後兩題相接的排印次序，**十八卷在這一見證中靠近陸位，而非位於萬民育與陸位之間**。
- **PDF第2頁（index 1）**版權／封面見「叢書集成初編」「王雲五主編」「商務印書館發行」；**PDF第3頁（index 2）**題作《明史藝文志》、張廷玉等修；**PDF第4頁（index 3）**說明「本館據八史經籍志本排印」「初編各書僅有此本」。
- 因而被直接核到的是**商務印書館《叢書集成初編》系排印本的紙面**，不是《明史》清代原刻、黃虞稷《千頃堂書目》原刻，更不是萬民英或陸位親撰《星學大成》原本。PDF未見完整可靠印刷年份；不可由叢書名自行指定印年。

## 二、與15CB受讀文字的差別和證據權重

15CB登記的《明史》卷九十八受讀本把「星學大成十八卷」放在萬民英《三命會通》十二卷之後、陸位《星學綱目正傳》二十卷之前。此次**目視排印頁的列位相反**，更貼近《千頃堂書目》卷十三的陸位串列。這是**可精確定位的書目受傳／排印頁差異**，並未建立兩者都是同一古刻本的證據，也不應把「各有一個文本網頁」當作兩個獨立古代作者權威。

在缺原古刻版面的階段，本文保留三個問題：
1. 《明史》卷九十八不同紙本、影印本或電子轉錄的**版次與句讀位置**是否確實存在作者編排差異？
2. 本《叢書集成初編》的底本《八史經籍志》對應哪一具體刊本，其《明史藝文志》是原史志抽出重排還是編輯合併？
3. 即便歷史目錄把十八卷置於陸位下，這一**書目歸屬**與《星學大成》十／三十卷自序題署、以及俄藏五卷清抄本的**真實正文／著者**之間，是否有同卷端、刊記、序跋的對應？

此新增定位不更改15CB已保存的受讀來源，不靜默改寫「萬民英串列」的原敘述；新增頁面作**同書名異列次的矛盾見證**，交付後續跨印本再校。

## 三、對紫微／四柱雙史綱的作用與下一步

此頁另直接並列「萬民育三命會通十二卷」「陸位星學綱目正傳二十卷」「星學大成十八卷」，證明該印頁把這些星命／術數著述納入同一書目範圍。**同頁並列不證明同作者、抄襲、四柱與紫微機械共祖，也不證《星學大成》十干變曜直傳1581《捷覽》四化。**

免費優先：尋獨立可定位的清刊《明史》卷九十八原頁、較早《八史經籍志》底本書目、澹生堂書目原頁；俄圖 Ф.274/224 如無公開逐件頁則保持開放。不得付費或把載體同名直接合併。
