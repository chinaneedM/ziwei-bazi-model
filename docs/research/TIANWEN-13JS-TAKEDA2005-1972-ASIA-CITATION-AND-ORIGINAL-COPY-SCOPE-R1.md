# 天问 13JS｜2005 年《高麗史日本伝》对 1972 年亚细亚文化社本的底本引注

## 本轮新增的具体证据

日本 CiNii [BA71855261](https://ci.nii.ac.jp/ncid/BA71855261) 和[帝京大学图书馆的同书记录](https://opac.teikyo-u.ac.jp/iwjs0016opc/catdbl.do?hidden_return_link=true&pkey=BB05019894)明确将武田幸男编译、岩波书店2005年出版的《高麗史日本伝》（上下两册）所据底本，登记为**亚细亚文化社1972年在首尔刊行的《高麗史》三册缩刷影印乙亥字印本**。日本国会图书馆进一步为2005年上册（`000007771747`）及下册（`000007856539`）提供独立的现行图书书目身份。

这比单纯“1972年有三册本”的目录条目多出一层**后世编者的引用关系**：2005年另一部日文整理本把特定1972年三册影印本作为所据材料。它可作为查找1972年原版具体实物、版次和重排历史的线索。

## 禁止的证据跃迁

- **2005年编校本在图书馆目录中的底本注记，不是1972年实体影印本的原页、奥付或卷52图像。** 两家图书馆转录同一个后来出版物的注记，不是两件独立古籍实物投票。
- 注记只限定1972年出版者、地点、三册及乙亥字影印体系；**尚未给出**该份编校本实际所借原件的 NCID、馆藏条码、奥付或细分篇页。
- 先前 CiNii [BA63617326](https://ci.nii.ac.jp/ncid/BA63617326) 与 [BB04922175](https://ci.nii.ac.jp/ncid/BB04922175) 同年不同系列、尺寸记录仍可能是不同书目变体，也不能据此自动认定哪条就是2005年编译者引用的具体原件。
- 一份现代缩刷影印本被称作乙亥字印本，不等于每页都具有同一底本；**更不能替代**2020年专题论文所声称奎5554与木板补版之间的逐页核查。
- 《高麗史日本伝》侧重日本相关段落，不能拿其“底本”注记证明《高丽史》卷52历志的字形、历数与 G893 六组数值。
