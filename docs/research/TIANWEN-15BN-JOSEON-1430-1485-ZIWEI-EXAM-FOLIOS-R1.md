# 天问 15BN｜《世宗实录》与《经国大典》所见《紫微數》取才书目

2026-11-23。对照 1430 年奏准书目和 1485 年定本系统的命课学条文，核读三件公开书影。两种制度文献均见《紫微數》题名。韩国国图所定的早期乙巳大典印本相关页写明命课学的试书方式。所列术书的实际应试版次与《紫微數》起例仍待核。

## 一、1430 年取才奏请的书名在 28b

台大藏京城帝国大学影印《世宗莊憲大王實錄》v.4 no.14，馆方电子书编号 `NTUL-9910004971`，PDF `NTUL-9910004971F02` p109 刊记写明底本为「景李朝實錄太白山本」，昭和五年（1930）九月十五日印刷、二十日发行。奏请所记事件是 1430 年，所见版面由太白山史库本影印传下。目标叶的原版片和具体刷印日期未作独立鉴定。[台大来源书目](https://taiwanebook.ncl.edu.tw/zh-tw/book/NTUL-9910004971) · [影印及馆藏号](https://commons.wikimedia.org/wiki/File:NTUL-9910004971F02_世宗莊憲大王實錄_一百六十三卷_v.4_no.14.pdf)

| 卷四十七页位 | 照片所见 |
| --- | --- |
| 28a，PDF p101 | 「戊午」日条在页中。「詳定所啓諸學取才經書諸藝數目」开出清单，接儒、武、译等各学用书。 |
| 28b，PDF p102 | 奏请续列「陰陽學」，见「星命卜課」及「範圍數紫微數皇極數」，后有「袁天綱五行精紀」和「三車一覽」。奏文末记「從之」。|

[13ZU](./TIANWEN-13ZU-JOSEON-ZIWEI-BAZI-EXAM-INSTITUTIONS-R1.md) 的 28a 是国史编纂委员会标出的条目起始面。核图把具体书名定在背面 28b。[14Z](./TIANWEN-14Z-JOSEON-1430-1466-EXAM-TITLES-AND-INSTITUTION-R1.md) 已记录数字汉文把「袁天綱」「五行精紀」各加书名号、韩译连读的差别。28b 上七字相接，没有可据以裁定题名边界的标识。连写如实保留，断为两项或一项仍须独立文献。其余两项短题可以直接复读，1430 年用过的哪一版《紫微數》或《三車一覽》，仍缺书身或考试原件。[官方对照条目](https://sillok.history.go.kr/id/kda_11203018_002)

两图均可读出命课学所列「袁天綱」旁小字「背講」，另列《五行精記》《剋擇通書》《紫微數》《應天歌》《徐子平》等，末有小字「已上臨文」。其后规定各学诸书轮次试之。这里可确认法典对背讲与临文的不同要求，以及《紫微數》在临文项目中的位置。太白山本影印的「五行精紀」与两件法典书影的「五行精記」分别照录。法典分开《袁天綱》与《五行精記》，其分类可用于解读法典本身，1430 年连写的原义仍待证。[国史编纂委员会校勘条文](https://db.history.go.kr/id/jlawa_103_0200_0010)

另经韩国国家遗产部门核得，现存 1471 年实行的辛卯大典卷三礼典也保存〈取才〉。其命课学具体书名的目标叶尚未取得。1485 年定本系统的这两件书影不可用于回填辛卯本缺口。[辛卯大典卷三解题](https://www.heritage.go.kr/heri/mem/selectHaejeDetail.do?listGubun=text&pageIndex=1&pageNo=2_1_1_0&query=%EB%8C%80%EC%A0%84&s_asno=01660000&s_cnum=&s_code1=00&s_code2=00&s_code3=00&s_ctcd=11&s_dcd=00&s_from_asno=&s_kdcd=21&s_mnm=&s_page=&s_pcd=00&s_to_asno=&searchDisp=0&searchPage=1&searchPageSize=5)

## 三、史纲补入制度证据

《紫微數》作为书名，可在 1430 年奏准的阴阳学书目与后来的法典命课学临文规则中直接核字。1430 年的《三車一覽》与法典的《徐子平》分别记录，现存同题术书的对应关系保持开放。早期术式仍需另找乙亥字残本的〈定十二宮〉〈起天數〉〈起地數〉或可断代的独立文本，与《玄藪》原页和已核盘例比对。三件书影及已核页图的哈希见[来源分片](./TIANWEN-15BN-JOSEON-EXAM-FOLIOS-SOURCE-SHARD-R1.json)。

传承图只增加三件数字影像到两段制度文本的见证关系。书目与版次的对应继续记在 TW-OPEN-0013、TW-OPEN-0014，历史规则审计 222/222，确定性融合排盘状态为 CLOSED。
