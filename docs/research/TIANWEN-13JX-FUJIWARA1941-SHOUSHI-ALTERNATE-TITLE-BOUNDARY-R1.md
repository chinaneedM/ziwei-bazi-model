# 天问 13JX：藤原松三郎 1941 原论文扫描与《授時曆捷法立成》同名阻断

P0 风险 `TW-OPEN-0005` 的传承资料外扩找到**可直接阅读的1941年出版原论文扫描**，而不是靠新转载或搜索摘要推断。

## 1. 已核实的现代原论文

日本 J-STAGE 的出版元数据直接列出藤原松三郎《支那數學史ノ研究, IV》，*Tohoku Mathematical Journal, First Series* **48 (1941), 78–88**；电子公开日期为2010-03-19。

- 出版信息原页：https://www.jstage.jst.go.jp/article/tmj1911/48/0/48_0_78/_article/-char/ja
- 可公开查看的现代原扫描：https://www.jstage.jst.go.jp/article/tmj1911/48/0/48_0_78/_pdf

本轮直接查看PDF印刷第78–79页对应的前两张图片，1941论文第78页第1小节陈述京城帝国大学图书馆书目所记的《授時暦捷法立成》、姜保编及忠烈王二十四年（1298）等**1941作者转引的目录命题**。第79页续录文句，**但不是研究者直接核读1298年古装原叶**。未成功获取原PDF字节，故没有PDF SHA256，本批不得虚报原PDF哈希绑定。

## 2. 书名与实物身份不能混同

当前项目已有独立登记的奎章阁 `GK00893_00 / 奎貴893`《授時曆立成》，馆方仅标为世宗时期十五世纪前半的甲寅字本。1941论文的《授時曆捷法立成》**包含额外的「捷法」两字**，并记录另一编者和1298目录年代。仓库历史登记还指出另一书目号奎20981候选，但1941此次已查看页面并未独立确认这一现代号，因此它也不构成实物号正证。

- 奎章阁馆方现行 G893：https://kyudb.snu.ac.kr/book/view.do?book_cd=GK00893_00

**特别阻断**：1941印本原扫描 ≠ 1298古籍原叶；相近书名 ≠ 同一书籍、版本或数表；1941目录复述 ≠ 独立第二古装见证；馆方时代范围 ≠ 确认1434或1444精确印年。这条外部研究资料可用于后续追索「捷法」独立文献，但不能直接投票 G893 六项原数。
