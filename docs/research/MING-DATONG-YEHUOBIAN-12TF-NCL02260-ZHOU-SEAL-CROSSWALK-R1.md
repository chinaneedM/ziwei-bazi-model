# 天问 12TF｜周星诒旧钞本：两件台湾馆藏的证据级别分离

本批围绕 12TE 的2019年杜学林《〈万历野获编〉明刊本说释疑》进行**对象身份对照**，不是补造1619年原稿校勘或1827／1869古刻原叶。

## 可核的具体对象

1. [Wikimedia Commons 对台湾国图 NCL 02260 第一数字部分的书目描述](https://commons.wikimedia.org/wiki/File:NCL-02260_1_%E8%90%AC%E6%9B%86%E9%87%8E%E7%8D%B2%E7%B7%A8.pdf)：旧钞本，索书号 **204.26 02260**，原二十卷、补遗一卷、续编十二卷，16册，9行21字；收藏印记栏登记「周印／星詒」「祥符周／氏瑞瓜／堂圖書」。这个**公开元数据转录**使杜学林所述「周星诒原藏、现藏台湾旧钞本」取得具体可能的馆藏编号，但尚未亲眼校读原件收藏印，也未证明李慈铭见过这件特定实物。
2. [台湾国家图书馆第一方 NCL 02261 详细书目](https://rbook.ncl.edu.tw/NCLSearch/Search/SearchDetail?HasImage=&SourceID=1&item=8309070387b74580b62eace95f539ec8fDUyMDAx0.YwN8suWf1WSOdjfsUz6WsqPWjZhoFsmXFoxW6nD_QX8_&page=&sourceWhereString=&whereString=)：**204.26 02261** 是另一件「綠格鈔本」二十卷、六册，11行21字；不能把它与 02260 混作同一本或同一个影像底本。
3. 02260 的书目转录序文干支作「萬曆三十四年丙午」，02261 一方目录作「萬曆三十四年丙辰」。只登记**目录文字差异**，不据此判定印刷讹误、抄手误写或 02261 原页究竟如何，须待直接影像校读。

## 严格证据裁决

- 已确认：一种2019年的学者**版本鉴别论点**与02260公开**馆藏目录转录**中周星诒印记相呼应。
- 未确认：李慈铭是否手阅现存的该一件02260；1619原稿〈改造漏刻〉是否存在、在何卷何叶；任何1827未修本或1869补修本的目标字形。
- 02260 第一部分 1000 页、第二部分 35 页属于**同一馆藏一件旧钞本的两份数字文件**，不能算作两件见证。
- NCL 02260 与 NCL 02261 是**两个不同馆藏对象**；它们是否在〈改造漏刻〉上有相同文字仍须逐叶核对。不得据二者同名或同卷数画传承直系箭头。
- 本批引用仓库已登记的两条旧钞本来源以及12TE论文来源，**新来源0、影像直接投票0、传承谱增边0、算法重开0**；来源继续661，矩阵222/222，图248节点235边，正式批次487。
