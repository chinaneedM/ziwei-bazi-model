# 天问 12SO — 东京1827／1869《野獲編》实物目录指纹与2005年数字化制度史校核

本检查点仍从属于 **12QE_OPEN**，不是一个新的正式审计批次。**新增证据类别是馆藏分册与图书形制的可复核指纹，以及东京东文研2005年资料保护/数字化流程；没有取得《改造漏刻》一张新的原叶，也没有发现可据以调整时间刻度的历史数字。**

## 两件同书不同实物的量化目录对照

- [大木文库 CiNii BC0492354X](https://ci.nii.ac.jp/ncid/BC0492354X)：馆方著录为**道光七年1827《野獲編》30卷首1卷補遺4卷、34册**；其中卷20实物为 `大木;子部:雜家類:16-20 / 6403767830`。四周双边、10行21字、白口单黑鱼尾、内匡廓18.4×13.2 cm、外形25.6×17.3 cm。全藏本有严重虫损、污渍、破损、漫漶；乱丁明确只著录**补遗卷4第31–32叶**，不能移植到卷20。目录对字形可读性有保存风险提示，却不等于目标原叶缺损已证。
- [仓石文库 CiNii BB23196128](https://ci.nii.ac.jp/ncid/BB23196128.amp?l=en)：**同治八年1869重校刊補、20册**，目标卷19–20合订，实物 `倉石文庫:20128:11 / 6403148395`。四周双边、10行21字、单鱼尾、内匡郭18.2×13.1 cm、外形25.7×15.6 cm。书目明确保存道光1827姚祖恩弁言与1869季男德恆重校刊補弁言；**卷30第12叶重复**只影响其本叶坐标，不是卷20异文证明。
- 跨本共同的10行21字只是粗形制相似；**34册≠20册，1827旧序≠1869刊印时间，更不等于版片/字形继承**。两书目的錢枋朝代标签还有「明」与「清」不一致，只作为目录属性冲突记录，不由此裁决人物生平。

## 东文研2005年历史文献提供了为什么“馆内有藏”不代表“网上可见”的直接制度证据

[东京大学东洋文化研究所官方PDF](https://www.ioc.u-tokyo.ac.jp/~library/kouenkai/report/1_okayama.pdf)，《漢籍目録データベースと善本全文書影資料庫 参考資料》，PDF第11–12页、印页57–58、末署**平成17年12月15日（2005-12-15）**，直接写明：

1. 数字化优先特別貴重書，不是全馆所有汉籍都同步上网；馆方历史访谈中另将1735年前列入当时“特別貴重書”优先标准，1735–1911年线装书仍可能入珍本范围，但**并非全都已扫描**。
2. 抢救流程分为**35毫米微缩胶卷 → 微缩制作复制本 → 400dpi保存用TIFF → 面向网页的120dpi JPEG**。不同载体不能无源对象身份和哈希就混成一个“原版扫描”。
3. 该2005年附件列出当时**537种**可浏览书目；A类全文开放，B类从规定地点以外当时只可浏览前10页；该附件特意写明A/B类**并不直接出现在清单上**。这些规则仅是2005年制度快照，不能按其判定2026年页面权限，更不能把早期2005年537数与2009年4630数解释为独立实体见证。

因此，1827/1869目标卷尚未得到具体的公开原叶链接，**只得记为影像取得资格未验证**。东京大学图书室独立[预约及复制表](https://www.ioc.u-tokyo.ac.jp/~library/guide/form.html)应按**每件馆藏对象**确认可访问原叶、缩微/复制品类型、特藏资格与许可范围；本站点OPAC两条源页面链接本次网页访问均返回HTTP403，只描述执行环境/路由边界，不能推断图书不存在或院方拒绝服务。
