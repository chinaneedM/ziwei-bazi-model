# 天问 13CM｜早稻田与日本国立公文书馆原图：第15日短／长栏与第18日短栏原生逐字校勘

本批与仅使用现代电子转录的13CL不同，**实际重新提取并目视复查已归档的三张古籍原图**。来源为早稻田《高麗史》book33 的图像页23，及日本国立公文书馆282-0006 第51册图像17、18。所取的是**原已登记的两份物理实物**，不是三个新的版本，也不能多计传承票数。

- 早稻田 source ZIP: `41863a3d931122d53cce3bcdd59af1828eb41cc7efbab53b32ec738273a9306c`，归档 artifact `12340588249`；原JPEG SHA `388f3d5dd9e9861f8ce90c304b154edaeaee98614bb12cd3468f957dcde6fc66`。
- NAJ source ZIP: `dd7e35494898f5a3dae1c9cff1a05627c2fe4ca530ebea0434c67f8f356320f4`，归档 artifact `12258234108`；图像17/18原JPEG SHA及全部采样坐标见本批JSON。原图片本轮经SHA校验并以**Pillow RGB crop 原始像素**计算裁剪区 SHA-256；不进行OCR，不把PNG压缩字节冒充像素哈希。
- 六个新增 native ROI：两藏本各有 D15 原书「五分二一七六」=5.2176 和「四百三十四八二四九」=434.8249；两藏本各有 D18 原书「五分二七三四」=5.2734。每个ROI的 JPEG、照片编号、原图栏目日次、矩形边界、RGB哈希与13CH同页日次题字相连。

### 由原图直接支持的新增局部控制

把上述D15、D18**原本所印**的新增字形，与13CI先前两藏本原图已经实录的 D16 SHORT=5.1362 和 D17 SHORT=5.2548 连起来：

| 原刊日次 | 短栏实录 | 长栏实录 |
|---|---:|---:|
| D15（本批原图正证） | 5.2176 | 434.8249 |
| D16（13CI原图旧证） | 5.1362 | 429.6073 |
| D17（13CI原图旧证） | 5.2548 | 424.3711 |
| D18（本批短栏新证；13CI长栏旧证） | 5.2734 | 419.1163 |

因此 **原图短栏相邻差分** 为 -0.0814、+0.1186、+0.0186。**原图长栏差分** 为5.2176、5.2362、5.2548。D16长栏差分及S15/S17二值中点均是5.2362，但两份实物**确实印5.1362**。此双重算术候选较13CL增加原图正证，仍绝不授权改写古籍文本、断言印刷讹误源自祖本、推演全表算法，亦不准据此宣布G893 少微量纲与明代1569相同。

### 重放与证据限制

CI 可直接重放本批冻结Git blob、日次题字、数据与开放问题不变量，无法内置原图片，因为原图片**只在既有Actions原始证据归档中**。如取回上述归档并解出三张原JPEG，则可运行：

```bash
python scripts/verify-goryeosa-native-d15-d18-13cm.py \
  --w23-jpeg /path/to/original-source.jpg \
  --n17-jpeg /path/to/book51-full-leaf-017.jpg \
  --n18-jpeg /path/to/book51-full-leaf-018.jpg
```

该模式不仅比对文件 SHA-256，还逐个重算六个原生裁剪区的 RGB 字节 SHA-256；不提供图像则明确打印 `PIXEL_REPLAY=METADATA_ONLY` 而不是谎称重读原件。
