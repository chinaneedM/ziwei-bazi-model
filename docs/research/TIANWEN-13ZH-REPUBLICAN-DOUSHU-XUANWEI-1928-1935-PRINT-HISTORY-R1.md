# 天问 13ZH — 民国《斗数宣微》1928／1935版次与术数出版史覆盖格

日期：2026-11-16。阶段：双史纲广度优先。对象：民国王裁珊（亦见王栽珊）的《斗数宣微》及相关出版社、藏本叙述。**本批为后出出版书目与馆藏转述的边界校核；未取得1928或1935年原版扉页、版权页、刊记、校勘原叶。**

## 1. 已有登记不可重复算新来源

仓库根来源登记 `EXT-DOUSHUXUANWEI-1935` 早已记录王裁珊、《斗数宣微》（初集）、民国二十四年（1935）及现代书目再版入口，当前字段 `first_edition: 民国二十四年（1935）刊本`。这足以说明**项目原先收录了1935版本的书目线索**，不等于证明该年是作品的真正初版。此次不删除、改写根来源登记的历史值，也不把同一现代复刻文案反复计数。

## 2. 1928初版与1935增订的后出出版说明

- 心一堂2010年的[出版社第一方介绍](https://publish.sunyata.hk/archives/20)称《斗数宣微》（初集）为1935年刊本，题王裁珊，虚白庐藏，且描述原书二册、不分卷。是**现代复刻出版商的底本叙述**，不是1935原版扫描。
- 2021年心一堂经销的[《紫微斗数宣微》一集未删改足本](https://store.showwe.tw/books.aspx?b=131715)明确称**1928初版、1935增订再版**，以及1935年北平天华印书馆刊本作现代复刻底本；现代ISBN 9789888583836仅识别2021出版物。1928之说为**后来编辑／出版文案的回溯性主张（C）**，尚无1928印本原件、刊记或同期出版广告佐证。1935版的实际刊行可从现代书目互相定位，但原刻字形、改订范围未核（C／B候选，未升A）。
- 同经销方的[二集](https://store.showwe.tw/books.aspx?b=131716)称1935年铅印本，且书名附《相宅小言》《子平新理解》及勘误表。**二集不得与一集合并为同一篇章或同一册**；其中的“子平新理解”仅说明民国作者跨涉四柱议题，不证明明清《渊海子平》直接传授或二门共用唯一规则。
- 转述馆藏书目[中国人民大学藏本](https://www.guoxuedashi.com/shumu/2882889vl.html)列1935“天华印书馆”、一册；[北京师范大学藏本](https://www.guoxuedashi.com/shumu/gj-3135462jj.html)列1935“天花印书馆”、二册，且文字写“王栽珊／紫薇”。两条是第三方**目录转载线索**，原馆目录未在本批直接打开，不得断定馆藏两份已经独立验证、天花与天华一定同一或异厂，也不得把一册／二册差异断定为独立印次；可能涉及集数、装订、转录或数字化范围。

## 3. 对民国史纲的确定增量与界限

- **时间轴：**1935年北平出版节点可作为可追索的民国印本叙述；1928更早初版仅是待验证候选。仓库原先把1935标为 `first_edition` 的语义应在此**前向补注为“已知1935出版见证，是否第一版未裁决”**；不直接覆盖根来源历史记录。
- **规则史：**现代出版方称其整理安星法、星曜及“十二宫假借拆用”。这是后出编辑对作品内容的评价／摘要（C），尚非原版具体算法对照，不得声称这些规则1935年首创、古今完全一致或已经进入现行排盘核心。
- **人物与地域：**王裁珊／王栽珊字形差异与观云号属书目身份候选；北平刊行、香港2010／2015／2021再版可分别定位，但“北平出版→台湾、香港某学派师徒直传”没有独立证据链。现代发行地不能充作民国原版传播地。

## 4. 后续最小证据缺口

1. 找1928初版原扉／版权页、同期发行广告或馆藏实物记录，以判定1928是否真实首次刊行；若无证据，保留候选。
2. 比对1935初集、二集具体扉页、馆藏原始书目与勘误表；核“天华／天花”“王裁／王栽”“一／二册”属字形差异还是版本／实物差异。
3. 在现有民国出版线继续补广益书局《紫微斗数全书》及其他书局独立刊行，区分出版与实际师承实践。若没有原页，先保留B/C/D界限，不从现代复刻倒推民国传承。
