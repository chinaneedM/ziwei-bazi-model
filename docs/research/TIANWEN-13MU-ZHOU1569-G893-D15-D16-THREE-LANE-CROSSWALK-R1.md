**严格原字说明**：周相 D15 中栏可见「三十四分八二四九」，其左邻／右邻整表数值上位承前，在上述表格按同一数栏补作 `434.8249`；D16 中栏见「二十九分六〇七三」，候选规范作 `429.6073`。周相 D15 下栏原字「七千一百三十五分八三七五」完整可读，D16 下栏「五百七十〇分六六二四」的上位「七千」承前，规范作 `7570.6624`。不能把规范补齐的位数字伪称为每列逐字全部印出。

源内两个十进制校验：
```
7570.6624 − 7135.8375 = 434.8249
 434.8249 −    5.2176 = 429.6073
```

这为 p15 同表**下栏相邻日差—中栏递减—上栏短值**建立有界局部算术对应，与 G893 同日短值及递减值形成数字级别的对应。

## 对 13MQ 的前向勘误（保留旧证据）

13MQ 对 G893 D15 `四百三十四分八二四九` 与周相 D15 `七千一百三十五分八三七五` 的**字面不相同**判断成立，两个都是真实原图中的不同字符串。但将它们视作可候选的「同字段第二栏」是不充分的：本批确认它们分别落在 G893 的**递减栏**与周相的**下部累计栏**；真正对应 G893 D15 递减数 `434.8249` 的，是周相 p15 **中栏** `434.8249`，且周相累计下栏日差也核算为该数。

**历史裁决仍受限**：这不证明两书原始单位制／日序历元／全表首字段定义全部同一，更不能证明实物印次独立性或直接抄传。局部数字相等也不裁定古代历史谁抄谁、某版必错。原状态 13MQ 保留，不改写旧批；本文件是 forward-only 的字段范围收窄和新证据。
