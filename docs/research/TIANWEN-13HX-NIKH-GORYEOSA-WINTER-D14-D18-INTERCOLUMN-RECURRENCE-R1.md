# 天问 13HX｜《高麗史》冬至表十四至十八日跨栏递推与第十六日局部冲突

## 新增证据及来源等级

韩国国史编纂委员会 [《高麗史》卷52〈授時曆立成〉](https://db.history.go.kr/goryeo/level.do?levelId=kr_052_0010_0010_0020_0010&types=o) 官方现代校录在「大陽冬至前後二象盈初縮末限」表十四至十八日同时发布「日差加一秒八十六少」「盈縮加分」「盈縮積」三栏。

此处只复核五日范围的**官方校录文字**，并非新取得五页原图，更不是新认定独立古本。13HV 的 NAJ／早稻田／NDL1909 三馆第十六日原图「五分一三六二」继续原样保留。

## 双递推约束

暂将印刷数字字串拼接为**无量纲比较整数**，不假定「秒」「少」「微」之古单位机械同一：

```text
A(n) = 日差加一秒八十六少（本行字面）
B(n) = 盈縮加分
C(n) = 盈縮積
检验1：B(n) - B(n+1) == A(n)
检验2：C(n+1) - C(n) == B(n)
```

| 日次 | A(n) 校录原字数值 | B(n)−B(n+1) | A 残差 | C(n+1)−C(n) 与 B(n) |
|---|---:|---:|---:|---|
| 十四日 | 51990 | 51990 | 0 | 相等 |
| 十五日 | 52176 | 52176 | 0 | 相等 |
| 十六日 | **51362（一三六二）** | **52362（二三六二）** | **−1000** | 相等 |
| 十七日 | 52548 | 52548 | 0 | 相等 |

十四至十七日 **4/4 组跨日累加吻合**，而首列递推 **3/4 吻合**；唯一偏差仍在十六日。该发现不同于 13HW 的 0–87 日斜率端点校验，是同张表内独立列之间的局部机械重放，但使用的仍是**同一现代校录来源**，不能增加古本见证票数。
