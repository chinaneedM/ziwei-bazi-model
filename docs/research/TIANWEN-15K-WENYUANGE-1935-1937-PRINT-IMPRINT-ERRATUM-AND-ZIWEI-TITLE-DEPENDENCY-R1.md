# 天问 15K｜《文淵閣書目》1935／1937 版次依存与初版月份勘误：不能把后排印算作1441独立原本

研究日期：2026-11-21。继续先广度、后深度的双史纲。主要新增的是**已存在的1430／1441术书题名见证的版本链辨认和一处旧来源元数据修正**，没有发现或核读明代实际原书，未裁定《紫微照膽經》与《續道藏》是否同作品。根据仓库协议保留旧记录并发布向前勘误，不静默覆盖。

## 一、发现并核实旧来源描述里的1937初版月份错误

仓库已登记根来源 `EXT-NLC-WENYUANGE-SHUMU-1937-BUSINESS-PRESS-ZHUNZHAI-JIULOU`。其 `edition` 字段**原来写「中華民國二十六年二月初版」**。本轮通过同一来源 [NLC511 PDF](https://upload.wikimedia.org/wikipedia/commons/5/5d/NLC511-023031404016761-25273_%E6%96%87%E6%B7%B5%E9%96%A3%E6%9B%B8%E7%9B%AE.pdf) 的 **PDF索引2（0起，用户一般阅读器第3页）**，直接目视版权页印的是：

> 中華民國二十六年三月初版

同页注明 `國學基本叢書 文淵閣書目 一冊`、商务印书馆和杨士奇等。日本国立信息学研究所 [CiNii NCID BA53351131](https://ci.nii.ac.jp/ncid/BA53351131) 对同书名、同社、同丛书的书目亦记 `1937.3`，提供独立**书目月份**交叉核对。[台湾国家图书馆华文电子书库 NCCULIB-9900006152](https://taiwanebook.ncl.edu.tw/zh-tw/book/NCCULIB-9900006152)另将上海商务印书馆1937本绑定为政治大学图书馆来源影像、注册号 C141565；该馆目只给**年**不单独给三月，也不证明与中国国图数码对象为同一实物。

同题 [SSID-12074551扫描](https://commons.wikimedia.org/wiki/File:SSID-12074551_%E6%96%87%E6%B7%B5%E9%96%A3%E6%9B%B8%E7%9B%AE.pdf) 的 PDF索引3亦见「二十六年三月初版」，但它可能属于**同一版式甚至同一数字化物件谱系**；无物理副本指纹与字节哈希对照前不得把它充作第二份独立同版版本证据，更不得作为第二份**1441明代原目**。

### 向前勘误（保留原断言）

- **旧出处及旧文字**：上述根来源 `edition` 的「二月初版」；原来源 blob与过往12EW记录保留，不把先前文档悄然替换。
- **新证据**：上述 NLC511 物理印本版权页 PDF索引2 的「三月初版」；CiNii BA53351131 `1937.3`；NCL所列1937仅年级。
- **新判断**：对**已核版权页的这一1937本**，初版月份应以**1937年3月**记录；「二月」应视为此前根来源元数据错误，**不是1935／1937版次冲突，更不能用作两种1937印次的正证**。
- **未决**：相同书名的各馆具体物理副本同一性、国图与SSID镜像二进制/版心是否逐页同源、1937相较1935的具体删改与版片。错误性质为新增的**书目来源记录月份勘误**，不是排盘 Matrix 算法或已统计的45/45历史规则 provenance 修复数值之重新计数。

## 二、1935另一商务排印本：确切来源路线和性质

[CiNii NCID BA62463511](https://ci.nii.ac.jp/ncid/BA62463511)确认上海商务印书馆1935年12月《文淵閣書目及其他一種》，《叢書集成初編》编号0029—0031，三册。馆目明确写：

> 文淵閣書目: 據讀畫齋叢書本排印

这**明确确立**1935这一**出版记录自述**以《读画斋丛书》本为排印基础；但本轮未逐页取得1935实体版权页、文本校勘记录，故还不能从馆目直接证明一字未改、特定《读画斋》印次/藏本、同一版片，或与1937本文字同一。既有[13ZZ《读画斋》卷十五影像 p46—48](./TIANWEN-13ZZ-WENYUANGE-NANYANGTANG-FOLIO-COLLATION-R1.md)对《紫微眞數》《紫微千金賦》《紫微數》及《紫微照膽經》等标题的具体位置有边界性目验；1935后出排印**不是**新的1441年物理见证。此新证只建立**读画斋传本→1935排印本的目录级候选文本依存**，不将之升级为原刻文字直接抄传的已证结论。

1937国图已登源记录 `EXT-NLC-WENYUANGE-SHUMU-1937-BUSINESS-PRESS-ZHUNZHAI-JIULOU` 与同一NLC的历史时间刻制书目研究，因而本批**不重复增加其一个新来源ID**；添加三条可明确区分的第一方元数据：1935 CiNii版源、1937 CiNii印次月、1937台湾NCL馆藏来源。新来源数是**书目记录数**，不是三部早期书或三份十四主星斗数见证。

## 三、对紫微、四柱两条历史史纲的实际影响

1. **紫微的1441条目**只能从后出抄印本证明「编纂事件与传递的书目题名」，它仍无法证明《紫微照膽經》当时存在可复算的十八飞星规则、是1607《續道藏》卷一原本，或与《捷覽》《全書》是单链。TW-OPEN-0012保持P1/OPEN；1430朝鲜《紫微數》与后世同名文本的TW-OPEN-0013也不变。
2. **四柱的相邻条目**如《子平淵源》《通變淵源》《五行精紀》在同一后出书目中出现，是同一目录的**并列项**，不能由1935或1937年的又一次排印延伸为三个新明代原刻、完整同一命理教学课程或术法相互传承。
3. 1935与1937**是两个独立的近代出版事件**；1935“据读画斋本排印”属于出版者/书目层来源关系，不证明1937是1935直接再版。1937三月修正是**现存印本目视直证**，不回写1441古书的失传、法度或著作年代。
4. 后续仍优先寻找**1430/1441书名对应实物原篇、初始原书规则、1581《捷覽》及明刊《全書》的完全起例/星集原页**；这次可裁决的月份误差已经收口，不在重复馆目上继续无界工作。
