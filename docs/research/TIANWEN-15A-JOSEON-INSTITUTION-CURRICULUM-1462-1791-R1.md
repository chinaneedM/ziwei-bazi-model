# 天问 15A：朝鲜命课学 1462—1791 的制度、课程与术书分层

核验日：2026-11-19。承接14Z历史框架。以下是韩国国史编纂委员会《朝鲜王朝实录》官网的数字汉文受读文本，不是同年代刻本原叶或直接字形证据。

## 按时代核读

- **1462（《世祖实录》卷28，三月二十一日）**：官方汉文以「書雲觀則陰陽學」描述机构与学科关系，奏请「以陰陽學提調改稱書雲觀提調兼治」，结尾「從之」。可证一项1466年正式改名之前的行政调整，不可认定任何具体斗数、子平书籍已用。见 https://sillok.history.go.kr/id/kga_10803021_002
- **1466（14Z既核，不重复来源）**：《世祖实录》卷38「書雲觀改稱觀象監」「陰陽學改稱命課學，置訓導二」。这是官署名称的记录，不是传承的直证。
- **1474（《成宗实录》卷49，十一月二十七日）**：观象监官员报告命课学初设「遞兒職二、訓導二、生徒十八」，当时「所業成就者鮮少，又無新屬者，將至廢絶」，建议调归地理学等，结尾「從之」。官员观察、建议、获准不能直接推成全朝鲜永久废除命课学；后见1791同名机构记载。见 https://sillok.history.go.kr/id/kia_10511027_002
- **1791（《正祖实录》卷33，十月二十七日）**：观象监进三学厘正节目，汉文指出命课学「今掌諏吉，而專講祿命」，认为学用失配，提议以后考试、训课改用「協紀辨方」「象吉通書」。这是当时官方课程与职能的改革**呈案**，没有逐条证明执行，也不把这些简称自动绑定特定版本和物理副本。见 https://sillok.history.go.kr/id/kva_11510027_003

## 对紫微、四柱源流史的约束

1430年《世宗实录》的《紫微數》《三車一覽》《五行精紀》等**短题**、1462与1466的阴阳学官制、1474的人员/生徒危机及1791的择吉课程议案，构成不同时期的史料坐标，**不是**从1430到1791的一部同版教材、一条门派师承或某一可重放算法的无缝连续历史。

1791官方汉文同时写「祿命」和「諏吉」并指出二者在该机构的课程角色有差异，足以阻止把后世命课学名称等同于一成不变的四柱推命教学。今后应先核后续实施、人员、科试记录及各书具体版本，再建立制度→教材→术法的关系，不可以机构同名取代证据。
