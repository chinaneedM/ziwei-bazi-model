# 天问12VK：东京1827/1869原叶校验补强——真实字节双哈希与去重

### 缺口和适用范围

旧版 `scripts/verify-yehuobian-physical-leaf-attestation-r1.py` 在 `original_target_leaf` 非空的未来分支中，仅验证 `source_sha256` 和 `page_sha256` 是64位十六进制文本；若填写了URL、页号、人工审核人及四处读字，即可计入 `independent_target_glyph_votes`。这只是**声明结构检查**，不是实际文件哈希证明。仓库现行12SM东京1827/1869队列全部 `original_target_leaf=null`，既有0票不受影响。

### 本轮修复

现在正向记录还必须在验证环境提供 `--artifact-root`，并为每个 `original_target_leaf` 填写根目录内的相对 `source_local_file` 和 `page_local_file`。验证器读取两份实际二进制文件、分块计算 SHA-256，并与声明哈希逐项对比。缺文件、伪哈希、不安全的相对路径、绝对路径或符号链接越界均失败封闭。两项候选若使用同一原图或同一来源二进制哈希，拒绝将其计作两份独立原字票。路径解析不能越过授权取证目录。

人工页字形、书叶、印次和独立纸本身份仍须由研究者用具体实物图像核实：**真实哈希只证明参与核验的文件字节一致，不证明它们真的是该馆那一册，也不能代替原叶人工校勘。** 测试里的正向记录为明显标记的合成字节，不是历史证据。

12SM原始队列与旧研究结论一字不改。无新的馆藏叶次、图像、字形裁决、原文注册或传承边。正式批次487、最新12QD，来源647+43=690，图谱252节点238边，Matrix222/222，算法重新开放0，确定性排盘R1保持 CLOSED。
