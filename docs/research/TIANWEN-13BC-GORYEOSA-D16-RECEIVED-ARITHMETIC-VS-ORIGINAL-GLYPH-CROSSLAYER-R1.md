# 天问 13BC｜D16 数字正文递推与历史实物原字的跨层交叉门禁

**本批不是新的 D16 算术发现。** 六段「盈缩加分／盈缩积」递推已经由 12YZ 独立记录和测试。本批将该已存在的数字正文算术证据，与 13BA/13BB 后来取得的独立馆藏原字证据交叉绑定，防止跨证据层级的误提升。

## 两种证据有各自证明范围

- **12YZ，现代第一方数字正文：** 韩国国史编纂委员会《高麗史》卷52「授時曆立成」，D16 短栏 `5.1362`、长栏 `429.6073`，D17 长栏 `424.3711`，故精确差为 `5.2362`；D17 积 `8000.2697` 减 D16 积 `7570.6624` 为 `429.6073`。该交叉计算已在 12YZ 作出，不再算作新证据或新实物。
- **13BA/13BB，历史原件短栏：** NAJ 清写本物理第51册原画第17幅、早稻田第33册 PDF p23，以及暂未绑定 NLC 第一方实物的 Commons 影像短栏均直接见「五分一三六二」；不同作品 G893 原页002b 短栏为「五分二三六二」。相同读法不意味着独立版系、同底版或历史多数票。
- **本批限制：** 尚未以独立原图 ROI 哈希校勘 NAJ / 早稻田的 D16/17 长栏及累计栏字形。不能把 12YZ 现代数字正文跨栏递推，冒充已经在清写本或早稻田原页完成的原字完整校勘。

## 继续工作的精确目标

优先以 13BA 已归档的 NAJ `canvas17` 来源 JPEG，进行 D16/D17 长栏及累计栏的人工原字核读，记录 bbox/RGB SHA；然后对早稻田物理影像独立重复。需要原件对应栏目确实一致、位阶与单位相符，才能提升到「历史原页内部算术约束」而不仅是数字正文的算术约束。跨作品传承、祖本文字一／二和具体历史误抄时间仍然未决。

本批增加一套机器可重放的证据分层负例测试，但不新增原图、新来源票数、传承边、Matrix 行或排盘算法改动。TW-OPEN-0005 保持 P0/OPEN，另10项遗漏风险不变。
