# 天问 13KV — 《明史》卷三十五十三朔策余数与「迟次／迟疾历」电子收本异文

## 证据范围

本批继续 P0 `TW-OPEN-0005`，只做**两份不同标题的电子收本文字记录**与 13KT 已证实的哈佛《明史》卷35原印P6「朔策」常数之间的精确运算交叉检验，不声称读取了哈佛第7–12页新原图，也不声称两份同站转录等于两份独立物理古本。

- [《明史》卷35 通行电子收本](https://zh.wikisource.org/wiki/明史/卷35)：「有閏，加二十三萬八九七七零九」「十三朔實去紀法」；在「推遲疾限」处为「各置遲次歷」。
- [《明史（四庫全書本）》卷035 电子转录](https://zh.wikisource.org/wiki/明史_(四庫全書本)/卷035)：「有閏加二十八萬八九七七○九」「十三朔實去紀法」；在「推遲疾限」处为「各置遲疾歴」。
- 两电子文本都保留「無閏加五十四萬三六七一一六」与「紀法六十萬」；哈佛原印P6早在13KT有独立 SHA 核对的「朔策二十九萬五千三百○五分九十三秒」。

## 十三朔策严格复核

```text
朔策 M = 295305.93（基本分单位）
纪法 C = 600000
12M = 3543671.16 = 5C + 543671.16
13M = 3838977.09 = 6C + 238977.09
四库电子转录余数 288977.09，偏离内部等式 +50000
```

因此在**两电子收本均标示相同 M、C、十三朔实取余操作**的条件下，通行读数 238977.09 与源数内部一致；四库电子转录的 288977.09 在本条件模型下不一致。差 50000 个基本单位，相当于按日周10000衡量的 5 个日周单位，但**绝不能据此认定古代实际历日错了五天**，因为尚未确认这一电子转录与任何指定古本实物字形的对应。

这是一例**可复算的电子收本数值异文**。它不是已确证的乾隆四库本原刻讹字，更不是已确证的古算法缺陷。仍需检视原书物理影像以判断「二十 *三* 萬」与「二十 *八* 萬」的真实印本分歧。

## 运算对象术语独立核对

通行电子本「各置遲次歷」与四库转录「各置遲疾歴」不同。上下文两本均有「推各月遲疾歷」「求遲疾差」，所以「遲疾」作为运算对象名称在**上下文解释上更顺**，但此语义趋向不是原字证明；也不允许直接据现代软件标签把「遲次」视为已纠正错字。
