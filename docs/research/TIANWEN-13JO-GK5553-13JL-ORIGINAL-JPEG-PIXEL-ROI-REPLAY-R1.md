# 天问 13JO｜SNU GK05553 六张原始 JPEG 像素裁剪重放

## 第一方来源与复算

直接从 GitHub Actions `13JL` 原始图像归档取回六张 JPEG（run `40674394497`，artifact `12809334156`），下载 ZIP SHA-256 `74feace6f761f89ff8eaaf7528618d1a5368e5cbfb5cd5c0f5d961841cafdef5` 与 Actions 对象登记的 digest 完全一致。六张原始 JPEG 文件 SHA-256 与解码 RGB SHA-256 全部匹配 13JM 的六张原图登记值。

本次在原生 2000 像素高 JPEG 上，按每页宽度计算两块具有实质覆盖范围的整数坐标裁剪：右侧 heading_strip 和中左 body_field。12 块 ROI 每一块均独立取 RGB 原始像素字节计算 SHA-256，并登记页宽、坐标、裁剪面积、哈希与源 JPEG 身份。**12/12 裁剪实物像素已由实际图像重新计算并通过重放。**机器证据为同名 JSON。未采用 OCR，也不把印章、版心或局部 ROI 当作古籍刊年、实体册次证明。

离线复算命令：

```bash
python scripts/verify-tianwen-13jo-gk5553-original-roi-replay.py --artifact-zip /path/to/13JL-originals.zip
```

校验包括 ZIP 整包 digest、6 个源 JPEG SHA、6 个原生解码 RGB SHA、全部 ROI 坐标的整数和几何门禁及 12 个裁剪 RGB SHA。该脚本需要 Pillow。已用实际下载的 GitHub artifact 在本轮执行，结果 `PASS / JPEG=6 / ROI=12`。
