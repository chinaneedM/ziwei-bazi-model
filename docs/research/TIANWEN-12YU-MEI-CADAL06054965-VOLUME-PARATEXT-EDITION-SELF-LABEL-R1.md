# 天问12YU｜梅氏《大統歷志》126页扫描原件的册首册尾题署查验

本批不新增数字印字，而针对12YT已认证的 [CADAL06054965同一件DjVu原书影](https://commons.wikimedia.org/wiki/File:CADAL06054965_大統歷志·卷三~卷四.djvu) 核查“**四库本标签 ≠ 经验证的四库实物印次**”这道版本学界限。来源总 SHA-256 `195c3ff35ae297b43fad6bb597d46dd046b109bee4c8eae8732fba336adab800`，原件 **4,259,929字节、126张数字页面**。通过 [12YU 原像工作流](https://github.com/chinaneedM/ziwei-bazi-model/actions/runs/39026151896) 高分辨率输出28张指定原页，保留各页 PNG 与 RGB SHA-256；绝未OCR。可重复获取公开原始文件，不依赖20日后过期的Actions artifact。

全部像素页证见 JSON 及 `paratext-manifest.json`（临时动作制品中），其中数字p2与p3是**同一数字书目对象**，不充作另外两份实物版本。

## 二、结果分层

内部题署比上游Commons目录的书名元数据更强，可以把本对象定为「**影像内自题欽定四庫全書的梅氏卷三~四本**」；但仍**不能把“欽定四庫全書”自动升级为实物所在地、阁本名称、抄印年份、影印源底本、梅氏成书年或祖本的证据**。蓝色封面更不能当成历史原叶的年代依据。此次是在全126页中**有界选取28页、人工原图重点核读4页**，不是宣称穷尽全书所有版式、笔迹或牌记。

此前12YT直接古籍文字仍照旧独立保存：梅卷三p26「一秒八十六微」「四分九十三秒八十六微」，卷四p76「○一八六」，与12YN《明史》石印版第一个数相符、和12YM的「一秒三十六微」有50微局部异文；三个字形的*物理印次与文本谱系源流*没有进一步获证。不能把四库自署变为文本谱系边。
