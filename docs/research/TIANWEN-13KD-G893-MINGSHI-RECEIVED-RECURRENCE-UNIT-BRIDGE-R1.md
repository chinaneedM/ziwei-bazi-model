## 严格整数、无浮点位序桥接

按候选百分位的度、分、秒、微、纤，将原文的「十一分零八秒一十五微七十五纤」「五秒八十一微五十纤」「十九微五十纤」转换为以 **微分（10⁻⁶ 分）** 为整数单位：

- 初值 `11081575`
- 初阶差 `58150`
- 差分逐限增量 `1950`

于是原损益分显示量级的候选式为：

`Q(g) = (11081575 - 58150*g - 975*g*(g-1)) / 1000000`（单位：分）。

此式直接由收本叙述推算，**不是先对 G893 五行拟合抛物线再假托古文**。G893 第 6–10 限 `g=n` 精确 **5/5**；第 130–134 限用表行序候选 `g=167-n` 又精确 **5/5**。总计 10/10 为 *同一数字馆藏的十行*，绝非十个独立传承见证。反射常数 167 的行列端点解释暂定，不能将《明史》文句「一百六十八限」未经逐行训诂即等同于零基 167 的直接原文证据。

《明史》现代收文在「五秒八十一微」处与前述加法期望的 50 纤尾数不完全显式一致；《授时历故》收文写出尾数。暂列 **现代收本位序文本差/可能省写**，不强判其为古本笔误或新原创本。

## 疾历行度：明确保留反例

对 13KC 第 122–126 限「疾曆限行度」，另以黄氏现代收文的平限度 `1.0963` 作 *候选*，计算 `V(n)=1.0963 - Q(167-n)/100`，五行重算为：

`1.03095675 / 1.02951725 / 1.02809725 / 1.02669675 / 1.02531575`。

直接原书显示为：`1.0309 / 1.0295 / 1.0281 / 1.0267 / 1.0253`。两者接近，但第 122 限按通常四位十进制四舍五入应得 **1.0310** 而非原书 **1.0309**。因此不能把上式冒充完整的《授时》行度排表算法；需另考量立成层级、截位规程、历史实数来源、版本及原字。
