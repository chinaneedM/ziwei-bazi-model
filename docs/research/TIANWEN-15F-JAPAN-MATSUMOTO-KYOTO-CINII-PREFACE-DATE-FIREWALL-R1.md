# 天问15F｜1905—1906 日本松本四柱出版：京都馆藏、CiNii 年代与1933历法附件缩略图

核验日期：2026-11-20。遵循历史与传承广度优先原则。两项新增独立书目记录均为B级馆目证据，未审读1905/1906原刻奥付、序末及印次，不证明物理版本直传。原有15D/15E事实和不确定性继续保留。

## 1. 京都府立图书馆的不同馆藏对象

第一方馆藏经NDL联目公开：[京都府图书馆 SomokuID B10444987](https://ndlsearch.ndl.go.jp/books/R100000001-I2611B10444987)。题《四柱推命奥義秘伝録》、松本義亮著、卷一和卷二、长崎（长嵜）天祥舘、54页与73页、23cm；馆目以「1906序」表示年代，馆号「ﾖ 174/8/」。

「1906序」是**序文层年份的编目表达**，不能直接读成出版或原刻年份。馆藏机构有别于NDL的「特21-934」，但尚无原页/印次证据证明两地文本相同或不同，不能把两次目录相加为两次独立版片见证。

同一书名另有NDL卷一长崎天祥舘 [18--] 年、51页，以及卷二大阪松本义亮1905年、64页。京都馆目卷一54页、卷二73页不同于NDL单卷目录数字，尚不知计页口径、附页、修订或著录差异，均须留待实物核实。

## 2. CiNii「訂正」书目内部两个年号

[NDL汇聚CiNii书目 NCID BA91379066](https://ndlsearch.ndl.go.jp/books/R100000136-I1971712334769451803)列松本義亮《四柱推命奥義秘伝録》、版次字段「訂正」、出版者「松本義亮」、出版年月「1906.5」，但同条结构化 W3CDTF 年份为「1905」。备注有「見返しに天祥館藏版」和和装/袋缀。这里只能认作**受理馆目转录**，没有直接看到见返实物。

1906年5月与1905是同一来源的两个不同元数据字段，不可任取其一为最终印年。也不能凭「訂正」推定1905卷二→1906四册必有特定机械规则改订，或推定一份全新独立物理副本。

## 3. 1933附册有限网页图像筛查

沿用15E准确定位的NDL [pid1104880](https://ndlsearch.ndl.go.jp/books/R100000039-I1104880)而非第四册pid1104866，借[Commons同pid衍生扫描文件](https://commons.wikimedia.org/wiki/File:NDL1104880_四柱推命奥義秘伝録_別冊.pdf)逐一目验了网页渲染缩略图的第1—3个扫描页面。第1页能见封签「陰陽暦對照干支一覧 全」；第2页见大字内题「陰陽暦對照干支一覧」、署名「松本義亮著」与「天祥館藏版」；第3页出现「季節計算法」「土用入を知る法」等栏目。

此仅是**网页缩略图部分目验**，没有取得原PDF字节、页SHA-256或原生尺寸影像，未核精细字形、历法规则、印次、105页逐行原文，更未与京都1935的107页本逐页比较。附册中出现历法栏目也不能反推它的具体算法来自中国哪个版本或已实际用于日本四柱断命。

## 4. 科学界限与下一步

两条新馆目分别增加京都卷一二的地方馆藏范围和CiNii「訂正」年份张力，均不能提供原页或传承算法的独立证明。图谱仅新增两个馆目范围节点，直接抄传/同版关系边为零。拟继续以零费用公开原始影像核对1905、1906、1912版次奥付与前言，再核1933附册原页与1935京都馆藏；无法取得原页即保留 OPEN，不申请付费服务。
