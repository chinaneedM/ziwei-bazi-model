# 天问 13BR｜《高麗史》原件第16日／第18—19日有界原图取证

本批目标是**取得未决原叶图像并生成明确的待审裁片**，不是再由现有连续数值倒推第16日字形，也不是引入新的跨馆藏投票。

## 一、固定对象与字节门禁

- 早稻田书库 `リ06 02809 / book33`，第一方 PDF 的源 SHA-256 固定为 `28ebfeb34191f45715bc449d27da61fe04fb05eb45e84dd00cf569699f46225f`；只取**PDF 第23页、内嵌 xref70**，原 JPEG SHA-256 固定为 `388f3d5dd9e9861f8ce90c304b154edaeaee98614bb12cd3468f957dcde6fc66`。预设 ROI 范围仅是靠近既有17日表格的**16日候选区**；是否含16日须亲眼复核。
- 日本国立公文书馆 `282-0006 / book51`，只由已知 `item/4898853` 官方 manifest 第18幅所**实际发出的图片 URL**读取。官方 manifest 与 canvas18 JPEG 均锁 SHA-256，不猜测图片 ID。拟截区域对应既有 13BG 第18／19日版面上的早期日标题，但不自动升级为逐字标题证据。
- 两馆图像都是已经登记的实物；下载重放不增加实物或谱系票数。禁 OCR，禁用图像识别自动填数。源图原件、尺寸、裁片 bbox 和 RGB SHA 在每个 artifact `receipt.json` 中逐条记录，另出无文字解释的 PNG 预览。
- 程序设 PDF、manifest、原 JPEG、数量及主机白名单，若访问失败留下可重放的执行环境错误，不能把失败当作史料不存在。

## 二、历史作用域防火墙

直到裁片完成直接视觉校读，本批只交付 `CANDIDATE_ROI_NOT_READ`；`D16` 积数、`D18/D19` 日标题、古代“少／微”单位、跨本祖源关系和全表统一日序仍全部**未裁决**。13BQ 的原数字与原日标题证据等级不变。

## 三、验收

机器测试强制白名单、官方 manifest 精确编号、旧图 SHA、bbox 边界及非 OCR/零票数；GitHub 工作流分别运行早稻田与公文书馆两个隔离采集任务，异常时也保存 `receipt.json`。研究账本按 forward-only 新增取证目标，历史矩阵、已发布排盘及传承谱不动。
