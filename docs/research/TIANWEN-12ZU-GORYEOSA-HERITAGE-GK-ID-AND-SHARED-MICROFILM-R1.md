# 天问12ZU｜国家遗产编号与《高丽史》馆藏 GK 实物号正式对接

韩国国家遗产门户登记的[《高丽史(2021-3)》](https://heritage.go.kr/heri/cul/culSelectDetail.do?ccbaAsno=0021150000100&ccbaCpno=1121121150100&pageNo=1_1_1_1&sngl=Y)其资产编码为 `1121121150100`，对应旧宝物号 **2115-1**；首尔大学奎章阁[GK03539_00／奎贵3539](https://kyudb.snu.ac.kr/book/view.do?book_cd=GK03539_00)在官方书目中也明确写“보물 제2115-1호”，且属**太白山史库**。故12ZT曾保留未决的这一项跨库映射可闭合为：**2021-3 ↔ GK03539**。

相应地，国家遗产门户[《高丽史(2021-4)》](https://www.heritage.go.kr/heri/cul/culSelectDetail.do?ccbaAsno=21150200&ccbaCpno=1121121150200&ccbaCtcd=11&ccbaKdcd=12&pageNo=1_1_1_0)编号 `1121121150200` 对应旧宝物 **2115-2**；奎章阁[GK03579_00／奎贵3579](https://kyudb.snu.ac.kr/book/view.do?book_cd=GK03579_00)官方书目也写“보물 제2115-2호”，属**五台山史库**。故**2021-4 ↔ GK03579**。这是两家第一方机构的**文物旧指定号**桥接，不是从同版同册数推出来的身份，也不修改12ZT封存时的未知状态。

**缩微胶片误绑定风险**：GK03579目录页面重复列有 `M/F74-102-1` 至 `-7`，但是括号内明确标成**“奎3539/v.…”**，其中 `M/F74-102-5` 为3539 **纸本第48—60册**。在没有3579本专属缩微录影物品号及源图之前，这些记录不可被冒认为3579第二套独立原图；“纸本第52册”也不等于“历史文本第52卷”。

经过12ZU，**文物登记号→实物馆藏号**已解决，而**实物册→卷52原页→D16/D18原字**仍未解决。本轮不增加注册来源（仍716条），不新增独立实物古字数值或传承边，G893仍5/6、跨独立实物0/6，11项研究遗漏OPEN，图谱252节点238边、排盘R1 CLOSED。

后续直接依据两条明确馆藏号分别申请/定位卷52的馆方原始影像及SHA，再比较同版片磨损与目标数字。
