# 天问 13JN｜13JM 影像裁剪区元数据可重放性前向勘误

本批是对 **13JM 证据登记方式** 的校验，不是对原图读字、官方馆目、原本年代或排盘算法的重新裁决。

对已登记的六张 SNU `GK05553_00` 原图，逐张检查 `native_rgb_rois` 的坐标四元组和 SHA-256。原记录合计 **12 个 ROI，12 个均无法按登记元数据直接复算**：例如 `0008` 页 `001a` 的 header 坐标包含字符串 `"4"`，`0025` header 含 `null` 与 `"c"`，六张 body 裁剪均无自己的 `sha256`；多个 x 范围仅一至数像素，不能作为语义明确的版心/正文区域。逐项机器检查见同名 JSON。

13JM 原 JSON **原样保留**，其 Git blob SHA-1 为 `40d242fcffc8c45b66961b71d85fb0a8f306ada0`。其登记的源图 JPEG/RGB 哈希仍可用作将来重新取得文件时的匹配目标，但**本轮没有取得原始 JPEG 字节重新计算**，不得凭已有字符串声称裁剪区哈希已被重放。13JM 对 SNU 数字册 0008/0026/0029 手写形态和对照数字册 0011/0012/0013/0025/0027 刻印形态的人工观察保持其原有**单一数字来源**作用域；本勘误不产生新的实物投票、古籍年代和 G893 数值裁决。

**重新升级证据的门槛：** 必须取回 13JL artifact `12809334156` 或官方同一原始 JPEG，核对每页已登记文件哈希，使用整数、在画幅内且有实质宽度的 `xyxy`，把裁剪像素格式和各自 SHA-256 以新的前向记录登记。不能静默修改 13JM；KHS 8/12/26 与 SNU 8/26/29 实物册次争议继续 OPEN，13IO 历史物理册次断言仍为 `RETRACTED_UNBOUND`。

保持：Matrix 222/222、来源 763、图谱 252 节点/238 边、风险 11、排盘 R1 CLOSED、算法重开 0。下一步仍以原始馆藏实物封面/装订/登录簿对照、1972 影印本册次表及 G893 六组原值为主。
