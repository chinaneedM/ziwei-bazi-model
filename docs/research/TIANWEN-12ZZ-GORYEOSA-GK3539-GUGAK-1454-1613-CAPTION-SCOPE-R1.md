# 天问 12ZZ｜国立国乐院《高丽史》影像的1454／1613年代标签冲突与册卷交叉定位

## 证据事实：同一个“奎貴3539”，两种展示年份

- 韩国文化体育观光部所属[国立国乐院图像6426](https://www.gugak.go.kr/ency/multimedia/view/image/6426)（2024-08-08）原生影像目录写「高麗史 樂志 第42册／作品卷70／叶013b」，并在图注列 **1454**。同一官方媒体库[6425](https://www.gugak.go.kr/ency/multimedia/view/image/6425)亦给该馆号、册42/卷70贴1454，证明不是只看了单条误抓摘要。
- 同一国乐院的[图像6545](https://www.gugak.go.kr/ency/multimedia/view/image/6545)（2024-08-09）却写「高麗史 世家 作品卷18／实体第10册／叶072a」，所列年份为 **1613**。两条均明示源馆藏号 **奎貴3539**。
- 原藏馆[首尔大学奎章阁 GK03539_00](https://kyudb.snu.ac.kr/book/view.do?book_cd=GK03539_00)明确将**奎貴3539**登记为太白山史库1613年木刻本（85实体册、139卷），并有1613年9月内赐纪事。由此确认：**国乐院对同一实物所附1454/1613标签不一致**。这里发现的是现代媒体目录的“年代作用域未定义”问题；**尚不能断言1454是编辑录入错误**（也可能误指作品某次较早刊行），更不得将1454反向变成这套现存实物的印次年代。

## 册与卷的具体控制点

- 首次纳入另一官方机构的可核 **实体第42册 ↔ 作品卷70**、**实体第10册 ↔ 作品卷18** 两个“册卷同框图注”正例，分别带叶013b和072a；它们只属于**原生媒体元数据支持**，未从完整原叶影像或实体装订逐页核实。
- 这些序号进一步说明“物理册数”不能和“139卷作品卷数”简单等号；不能按册42/卷70的位置线性内插卷52的册号。**卷52真实物理册号仍为 null**。
- 国乐院6426返回的是有现代红框标注的局部影像，不是完幅原书叶；6545当前未取得原叶位图。图注所述卷70、卷18都不是目标《曆志》卷52，也不含待校核的D16/D18数值。
- 奎貴3539在国乐院重复出现 **不能计作两份独立历史实物**；更不能以数字展示日期替代原实物图像证明。
