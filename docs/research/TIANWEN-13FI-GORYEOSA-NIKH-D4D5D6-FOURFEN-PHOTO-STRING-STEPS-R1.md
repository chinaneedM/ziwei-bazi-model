## 二、独立的“数字串”运算，不替换历史单位

仅为了测试本馆**印成四个字的连续字形**，临时以 `〇=0`、`一=1`、`二=2`、`三=3`、`五=5` 映射为四位字符串整数，不借用任何《大统历》或《授时历》其他版次单位：

- NIKH 图像内部：`5010 → 5172 → 5334`，两次有符号字面差值皆为 `+162`，二阶差为 **0**。
- 先前 NLC p74「四分〇一七二」若**仅在同一串位数/同行涵义的假设下**将其作 `0172`，与 NIKH 两侧字符组成的反事实三值序列 `5010 → 0172 → 5334` 则为 `−4838、+5162`，二阶差 **+10000**。

这支持 NIKH **自身版面**「五一七二」处于一个局部等步长的连续字列；不能仅依数串递推推出 NLC 原照片「〇」必为传抄错误，因两图源册、原版、栏目机械身份及修复层级仍未认证，不能偷换字形为“历史数值的唯一正确答案”。
