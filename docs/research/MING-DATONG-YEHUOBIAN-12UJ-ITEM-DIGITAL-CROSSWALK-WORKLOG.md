# 12UJ — 实物册号与数字替代件不得虚假绑定

## 核心事实

1. [NDL馆藏 184-65 / 000007607208](https://ndlsearch.ndl.go.jp/books/R100000002-I000007607208) 在本轮可公开读取页面显示纸质「萬暦野獲編30卷」、「康煕39序活字印」、16册合8册。**已读取的页面并没有针对该件的数字 PID 或数字书页链接**；底部“互联网阅读／复制”等属于通用站点服务导航，不是该件已电子化的证据。[NDL 官方关于检索范围与网络阅读标识的说明](https://ndlsearch.ndl.go.jp/help/about) 明确区分可在线阅读标签及一般服务。**不能从本次公开页面无数字字段推出此书尚未数字化或微缩。**
2. [CiNii 筑波大学 BA62912433](https://ci.nii.ac.jp/ncid/BA62912433) 源页面明确发出 OPAC 路由与卷20编号10076865665。该 OPAC 路由公开文本在本轮仅呈现检索界面，未给出卷20具体影像/IIIF/缩微号。馆方另有 [Tulips-DC](https://dc.tulips.tsukuba.ac.jp/s/pub_ja/page/top) 数字馆藏检索主页，但**馆级平台存在不等于本册已绑定平台项目**；无法访问或搜索无命中也不能作为无本、无影像或无版本的反证。
3. [NDL 古典籍资料室使用规则](https://www.ndl.go.jp/tokyo/classic) 进一步明确存在数字／缩微副本时先用替代件，原件阅览另有学术用途与许可手续。珍贵或准珍贵品的提前预约仅在具体物件分类适用时成立，**尚未证明 184-65 被具体归入此类**。
4. NDL 说明境外居住者不能使用其**个人数字化资料传送服务**；不等于国际用户均不能访问公开馆藏，也不据此推断用户居住地。用户/研究者可依公开提供方式与具体资料分级继续确认。

## 新行动判断

截至本轮，两个候选实物都没有公开页面中可核验的**item→digital PID/IIIF→原叶**链。因此严格只记录“当前已审读表面未建立关联”，不说“全库不存在”。任何拟申请的复制事先需要判明来源原件/微缩代替件、目标卷叶和版权许可；本轮无申请、无付款。12UF 原有四处异文控制状态保持不变，所有候选版次均未判定。
