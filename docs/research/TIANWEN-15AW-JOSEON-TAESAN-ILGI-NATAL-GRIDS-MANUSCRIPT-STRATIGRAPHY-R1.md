# 天问15AW｜朝鲜《大山日记》手绘命盘：有实物身份的个人使用线索与册历复用年代防火墙

日期：2026-11-22。阶段：紫微斗数／四柱八字双史纲广度优先。对象从前一批15AV的朝鲜官书、术数书籍扩展到**十八世纪个人手稿中的命盘图形**。本批核验韩国机构的原手稿总目、第一册封面公开照片，以及2026年开放获取论文中经馆方授权的两张原稿图像。方法识别仍遵循论文作者的保留语气，不声称已经得到完整原册或原图字节哈希。

## 2. 手稿中具体能看到什么

- 研究者在其称为**Hosang Chapjŏ（1739–1740）**的册历/日记材料**第40–41页**，识别出**三张**命盘式方格图，形制为外围十二格、中心一大格，并有连接四个外格的三条叉状线。出版商 PDF 印页64图3a公开两张。**页40–41是研究者对手稿的页位，印页64是现代论文章页，不可互换。**
- 研究者说三图的出生日期记作**「辛卯正月二十九日」**，与李象靖生辰相合；辛卯在其一生中指向**1711年或1771年**两个日历周期。这是命盘**所写生辰**，不是绘制、刊印或藏本取得日期。图形具体格内星名、时干、时支、安星算法尚未逐宫转录、与同书其他两图机械比较。
- 研究者使用 **“seem to have been drawn according to ... chamidusu 紫微斗數”**一类审慎表述，因此**“属于紫微斗数”目前只是一项有理由的现代研究识别（C，候选）**。十二宫格形似及部分命盘标签并不足以排除其他星命系统，也不能确定属于后世十四主星派／十八飞星派或与15AV乙亥字《紫微數》同一算法。原稿是历史上个人手绘星命盘的**物证线索**，可补朝鲜地方使用覆盖；但其精确流派、公式和出处没有闭合。
- 英文论文用**Hosang Chapjŏ**称其1739–1740材料；韩国机构第一册封面则明列**「湖上雜錄」**。两者处于同一《大山日记》研究范围内，但本项目没有获取两处题名的**逐页物理 crosswalk**，不能默认为完全同一古书原题、同一页码体系。保留书名及时间边界差异。

## 3. 日期与传承防火墙：册历并非每段笔记的完成年份

| 层次 | 本次可证范围 | 禁止的越级推断 |
|---|---|---|
| 生辰（chart input） | 辛卯正月二十九，研究者定位李象靖1711/1771周期 | 等同1739原稿绘制日期，或以此唯一判定出生／命盘干支细节 |
| 载体历书（physical support） | 机构第一册列1739，论文称1739–1740；全套由不同时段册历组成 | 1739历书上的所有后来添写皆作于1739 |
| 手写附加层（inscription layer） | 论文举1755/56历书在1771、1772/73仍有书信稿借页记录，证明册历复用有真实案例 | 自动将这种**已证其他页**的后写日期硬套到本批三张命盘；三图实际墨迹年仍未判 |
| 当前藏本（physical holding） | 韩国国学振兴院现藏12册，第一方UCI统一项 | 推出原始12册装订从1739起一直未变；馆目还说明部分册经后续合装 |
| 现代图版／研究（surrogate / analysis） | 第一方网页与2026 De Gruyter PDF 限定图3a | 把2026公开影像视作独立十八世纪见证，或以现代研究辨识替代古人技术术式 |

论文附录明确其他册历长期复用；其文集中后抄本的篇次、纸面布局和记事层亦有变动，不能拿19世纪整理的《大山先生全书》当作原日记页貌。在传承图谱层应分别建模“原手稿群—论文受让图版—现代术式鉴别”，**尚不建金緻《深谷秘訣》→李象靖个人盘的师承边**。

## 4. 对双史纲的直接增量

**紫微／朝鲜广度**增加的不是新书名，而是**18世纪非官署个人手稿可见生辰星命图**：与1430考试书名、1644案件供词、17世纪金緻著述线索互为**不同类型**的证据，构成“制度目录—个人使用—术数书刊”的社会场景对照。绝不能编出1430官书经金緻传给李象靖的直系路线。

**四柱／相关历史**只可标注同一人物手稿含出生年／月／日的图形线索；目前没有从这些图版读出完整年、月、日、时四柱、日主、十神或格局，也没有紫微与子平公式互抄证据，因此**四柱规则形成史不作进度升级**。

下一有效目标是取得机构第一册完整原扫描图**原件第40–41页**及第三张命盘、确认 Hosang Chapjŏ／湖上雜錄标题和原页对应，逐宫核星名和宫序、辨12格支序与时辰、比对李象靖其他盘的同异；有图像SHA及可重复计算后才做流派判断。此路如受限，继续时间序列上其他可公开核证的朝鲜、日本及越南用盘原物，不为单一障碍无限停留。
