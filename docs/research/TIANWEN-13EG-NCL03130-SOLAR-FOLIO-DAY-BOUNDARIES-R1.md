# 天问 13EG — NCL03130 原太阳夏至表第73—77页跨叶日题连续性

本批复取先前归档的 GitHub Actions [13DY 原图](https://github.com/chinaneedM/ziwei-bazi-model/actions/runs/39938606876) artifact `12494518841`，逐一核验 `original-p073.png` 至 `original-p077.png` 的原始 PNG SHA-256 与 RGB SHA-256，并手工直看各叶首末的十处日题原字。五张原图属于**同一个 Commons 数字镜像，不是五个独立物理见证**；原 PDF SHA-256 `3c2a5621fb3f4eabc593020bcde12a38f6ecdae2842940dec12d5a3a56afd32e`，不使用 OCR。

特别钉定四个跨页连续端点：**3→4、14→15、25→26、36→37**。所有端点的原字均使用盒 `[x0,150,x1,300]` 限定，分别计算 RGB crop SHA-256；每页原图的 PNG/RGB 全页 SHA 亦与 13DZ 原始来源页登记相对照，13EF 的 p73、13EE 的 p75—77 既有档案也作为只读校验基线。全部十个端点的源字、原始坐标和完整 SHA 见同批 JSON，`scripts/verify-ncl03130-solar-folio-boundaries-13eg.py --source-dir <原图目录>` 可在有原图时不通过 OCR 复算各 SHA。

**证据作用域与限制：** 正证是这些特定印刷日题与四个跨页边界连续，**不是**已完整逐字核读中间每一天、已确定整个数表数学规则或与另一个馆藏本统一日次。13EF 直接核读的 `行度`、`盈縮積`、`日差` 仍需逐组对应到 p74—p77 原始数字竖栏，不能从同一像素 x 坐标或印刷日次连续推导任何跨叶相同精度公式。NCL D30 的直接字串 `初度九十六二〇三` 保留，但数值为 `null`；不补其他本 `0.965038`，也不以算术猜测裁决缺字。未知馆藏实物与清旧本/1905补写叶层次、G893 六组及冬至 D16 继续 OPEN。
