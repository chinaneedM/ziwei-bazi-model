# 天问12ZA｜《高麗史》官方汉字正文 D18「三」字前向勘误与三页面区分

## 纠错对象及原记录保护

12YZ 原研究文档和验证脚本把官方 D18 累积数读成「八千四百二十四六四〇八」=8424.6408，并据此宣告累积列六组相邻差全都精确成立。本批**不修改**12YZ 的原始机器证据、不冒称该历史记录从未出现，前向记录上一轮直接数字文本转写遗漏末尾「三」的研究缺陷。

一方官方汉字数字正文： [韩国国史编纂委员会《高麗史》卷52](https://db.history.go.kr/goryeo/level.do?levelId=kr_052_0010_0010_0020_0010&types=o) 原有「十八日」的「盈縮積」为 **八千四百二十四六四〇八三**，机械地将字串映射到十进制是 **8424.64083**（五位末数），不是 12YZ 写入的8424.6408。

同一机构 [韩文译注展示](https://db.history.go.kr/goryeo/itemLevelKrList.do?itemId=&levelType=&parentId=kr_052r_0010_0010_0020&types=r) 对18日作「8424분 64초 08미」；[维基文库收到的全文](https://zh.wikisource.org/wiki/高麗史/卷五十二) 作「八千四百二十四六四〇八」。前者是**同一机构的另一数字编辑层**，后者是不明底本依赖的网络转录；二者都不是独立的纸本古籍投票，不能用它们径自覆盖官方汉字页所显示的末尾三字。

## 正确按官方汉字网络正文原样进行高精度逐格复核

| 日次→下一日 | 「盈縮加分」递减是否吻合「日差」 | 「盈縮積」递增与当日加分之差 |
| --- | --- | ---: |
| 14→15 | 吻合 | 0.00000 |
| 15→16 | 吻合 | 0.00000 |
| 16→17 | 不符（第16日） | 0.00000 |
| 17→18 | 吻合 | 0.00003 |
| 18→19 | 吻合 | -0.00003 |
| 19→20 | 吻合 | 0.00000 |

保留五位后，累积栏只有 **4/6** 次精确吻合，其余两次对应 **17→18：+0.00003**，**18→19：−0.00003**，抵消为零。12YZ「累积栏6/6」必须撤回，先前16日短栏与长栏相差 **−0.1000** 的独立观察则保留。韩文译注页及维基文库的 D18 四位读法若代入则可使六组累积相邻差相符，但只能作为**数字版本差异**，不能反证汉字页对应古纸本一定刻错。
