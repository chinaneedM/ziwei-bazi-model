# 天问 13CP｜台湾国图书号 03117 与 03130：Commons 上传本地名不可替代馆藏实物身份

本批沿接 13CO，但**不以卷五十二原叶已经取得、也不以任一新扫描成为第三个古本作结论**。本批只检验可重放的**数字中介层文件命名—实体馆藏标识冲突**，避免将 Commons 文件命名或者上传机器人文本偷换成馆藏事实。

## 1. 两个来源身份不能合并

台湾国图**第一方**古籍联合目录的《史臠二十五卷》明确列明书号 **03117**、索书号 **207 03117**，余文龙编，明万历戊午（1618）金陵刊本、**32册**。这是《史臠》的书目身份，不是《高麗史》卷52数表的影像见证。

Commons 对《高麗史》的统一说明使用另一个标识：**208 03130**，137卷40册，「清初葉舊鈔光緒間錢塘丁氏補鈔本」。但这是**中介网站所贴标签**，本批仍未取得台湾国图以 208 03130 为对象的可重放第一方精确条目；馆藏与该份具体 PDF 的页内绑定未完成。

## 2. 五份《高麗史》镜像文件具有重复的上传备注错位

下表仅按 Commons 文件详情页可见元数据归纳，尚未逐页打开任何 PDF：

| Commons 文件编号 | 文件页数 | 上传记录所写本地文件名 |
| --- | ---: | --- |
| NCL-03130 02 | 201 | `03117_2.pdf` |
| NCL-03130 07 | 187 | `03117_7.pdf` |
| NCL-03130 08 | 189 | `03117_8.pdf` |
| NCL-03130 20 | 166 | `03117_20.pdf` |
| NCL-03130 21 | 171 | `03117_21.pdf` |

同站另有明确名为《史臠》的 **NCL-03117 1 / 2** 文件，上传备注反而分别写 `10277_1.pdf` 和 `10277_2.pdf`。这些双向例子证明网站中的**上传本地文件名不能可靠地单独识别馆藏书号**。五份备注形式相同，属于持续的名称映射问题，而不是五份独立古本，也不自动证明 03130 文件图像其实来自《史臠》。

不可把 `03117` 上传备注的异常**静默修正为“无异常”**；也不可直接宣布 Commons 的 `03130` 命名一定错误。真正判断须有第一方馆方物件号、文件源哈希、扫描内页卷题、印记与卷52原叶对应关系。
