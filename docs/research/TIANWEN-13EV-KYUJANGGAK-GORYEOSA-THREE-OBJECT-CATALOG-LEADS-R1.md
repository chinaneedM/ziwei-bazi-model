# 天问 13EV｜奎章阁三件《高丽史》物品级馆目与夏至五日异文取证路线

**证据结论：找到三个韩国首尔大学奎章阁馆方第一手物品目录；它们的目标叶像素还没有取回。** 目录证明有这些馆藏与目录报告的版本属性，**不证明**「〇／五」之中的任何一个字，也不能把数据库转录当第三部实物。

| 原始物品代码 | 馆方书架号 | 第一方馆目 | 版刻范围 |
|---|---|---|---|
| `GK03539_00` | 奎貴3539-v.1-85 | <https://kyudb.snu.ac.kr/book/view.do?book_cd=GK03539_00&mid=GDS&target=master> | 1613 年、木版本，139 卷 85 册；太白山史库本 |

馆方把奎貴3539与奎貴3579列为**同版的两个独立藏本**，二者可用于检查各自实物的印刷和后配差异，但不能在取叶之前称作两条独立「五」的古代数表读法。馆目明确将工作卷五十至五十二列为历志。`GK03539` 页面虽列微缩胶卷号，其卷内第52目标叶与单册号尚未绑定；`GK03579` 页存在列举 3539 微缩片的情形，**不可把交叉链接自动推成 3579 的实际胶卷**。

韩国国史编纂委员会官方条目 <https://db.history.go.kr/id/kr_052_0010_0010_0020_0020> 的「原文图像」入口经直接确认存在，但调用需要进一步定位，现阶段没有可校验的图像字节或哈希，也未能把该图像对应到上述三个实物。<https://db.history.go.kr/main/help.do> 明确解释「原文图像」为原资料的图像文件访问功能。此仅可当作**下一步图像检索入口**。

### 下一步一次性校勘目标

逐一查到三部实物内**原书工作卷52**下「大陽夏至前後二象縮初盈末限」，明确页码及图像 SHA-256，独立读取「日差加一秒六十二少」第4、5、6日原字，再做三部之间、国图 NCL03130 第74页与韩国 HTML 转录间的五向核对。若只看到官方 HTML 的「四分五一七二」，仍不能证明馆藏原字就是「五」。

13EU 所记录的 NCL 来源单字「〇」与韩国官方数据库「五」不合仍属 **OPEN 异文候选**，不是已判定的版本异文、数据库错误、修订命理历法的依据。G893 六控、冬至 D16、D30 的数值、清本/1905 实物层、13EI 旧误归因均照原有证据等级保存。产品 CLOSED，算法重开0。
