# 天问13FO｜卷52可取证实物：奎3467第6册乙亥字本与子目录、胶卷边界

## 一、比13FN更精确的版本判断

[奎章阁《高麗史》官方馆藏总表](https://kyudb.snu.ac.kr/brd/viewBrd.do?book_cate=HEJ23&focus=d11sd114&listChk=tree&menuId=10022&mid=HEJ&postSeq=10775&siteCd=DBSP)已将 `奎3467` 第6册对应到**卷52**，并在“部分乙亥字本”栏目明确标注第6册。[同馆独立书目详解](https://kyudb.snu.ac.kr/book/view.do?book_cd=GK03269_00&notes=basic)进一步写：奎3467的**第6册及第26—30册共六册**是乙亥字活字本，其他23册是木板本，第1册是手写本。这样可将卷52的目标版式从模糊的“混合本”收窄为**馆方标为乙亥字本的第6册**。

但这仍是同一机构的**书目层证明**，没有经过特定纸叶/字迹检验。
