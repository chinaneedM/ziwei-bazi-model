# 12VO — 名古屋全文获取与校记范围收束

通过哈佛官方公开API文档构造两次书名查询，执行环境均返回403，未得馆目。只记录访问边界，不撤销国图联合目录线索，不猜tracy号对应的HOLLIS编号。

随后取得名古屋大学官方2019、2020、2021论文PDF，合计56文件页。ZIP与三份PDF均在本地重新计算SHA256，与Actions相符。2019为图像型PDF，未作OCR或全文负面检索；2020/2021可抽取垂直逐字文本，去空白仅用于寻找位置，论断以所核读页图为准。人工选看6页，不声称读完全部56页。

直接核读2020论文81页：首篇只处理主题编排卷1-3及序跋，底本是1959版的1980第二次印本，作者提醒部分问题可能已在1997印本纠正。82页说明校记选择性出校，因此未列异文不能推出各本一致。甲乙丙丁是学者的馆藏与版本标签，近似年代属于学者估定，不据此绑定当前NCL/IHP编号，也不能将故宫抄本补遗等同巾箱刊本。

2021论文99页起4-1、110页止6-36，范围为卷4-6，不能用于卷20《改造漏刻》的四处异文裁决。2019仅选读67-68页的版本讨论，不作全文目标篇有无判断。

2019/2020沿用既有来源，只增加2021论文1条现代学术来源。根647+分片47=694；新古本目标页、原字票及图谱增量皆0，算法不变。原始1827/1869卷20获取仍OPEN。继续寻找后续卷20校记（若有）和来源绑定原页，而不是重试已证明不覆盖目标卷的两篇校记。

全文捕获run38492498852、artifact11862445269；现代学术PDF不是古本原叶。机器记录提供每份文件摘要、页码和人工核读范围。
