# 天问 13JR｜《高丽史》1972 年同社异系列、1983 再版及实物调阅路线防误合

## 结论与证据等级

在 13JQ 已将延世大学1972年四册本和亚细亚文化社1972年三册本区分之后，本批继续核对 **亚细亚文化社同年名义下的两条不同 CiNii 书目身份**、1983年再版本和可调阅的具体馆藏副本。新证据仅属**现代图书馆目录及馆藏定位**；没有取得影印原册的版权页、内页或古籍卷52历表图像。

### 一、两条同社“1972”书目不可直接合并，也不可擅断两个独立印次

- [CiNii BA63617326](https://ci.nii.ac.jp/ncid/BA63617326)：1972，亚细亚文化社，《韓國學古典씨리즈》，上中下三册，21 cm。其九州大学馆藏分别列出 **005132003069246（上）／005132003069258（中）／005132003069261（下）**，索书号 `朝鮮史/20-1/25`；神户大学另外有上册 `020000095215`。
- [CiNii BB04922175](https://ci.nii.ac.jp/ncid/BB04922175)：书目出版栏为1972.9，亚细亚文化社，《古典大學講讀教材》7，上中下三册，22 cm；但同一条书目有 **“刊行辞: 李 昌(1983年2月)”**。滋贺县立大学上中下馆藏 ID 为 **5065076／5065077／5065078**。

**直接校勘逻辑：**两个 NCID 与丛书、尺寸信息不同，表明现代书目区分明确；但没有原始版权页及封面，就不能推出它们分别属于两套不共用版片的底本。标注“1972.9”与“1983年2月刊行辞”的时序张力意味着刊行栏日期不可自动等于每件馆藏实物的印次。也不能凭 1983 年刊行辞直接推断原1972初印本一定不存在。

### 二、1983 再版提供追索路径，不提升1972原件证据

[中央大学图书馆 BA6602288X](https://ufinity.library.chuo-u.ac.jp/iwjs0002opc/ctlsrh.do?locale=ja&ncid=BA6602288X&search_mode=detail&tab_num=0) 明列 **1983.4 再版**，同为《古典大學講讀教材》7、上中下三册，23 cm，并记 **1972年初版**。其东洋史研究室馆藏 ID 为 `00014465009`（上）、`00014464994`（中）、`00014464986`（下）。此目录可用于查对重印版，但不可向1972年特定影印叶反向赋予字形或底本身份。

### 三、韩国馆藏及同时代台湾版本的访问边界

[韩国大田韩밭图书馆公开检索](https://www.daejeon.go.kr/hanbatlibrary/newSearchBriefList.do?q=%EA%B3%A0%EB%A0%A4%EC%82%AC%5B%E9%AB%98%E9%BA%97%E5%8F%B2%5D&si=4&siteCodeGubun=home&vSType=KWRD) 明列1972年亚细亚文化社《高麗史》“上”“中”各一项和1983年一条记录；这些条目的精确详情入口在本次公开网络检查返回“网页找不到”。因此有**公开检索层正面书目证据**，没有条码/版权页绑定，不可将详情页访问失败说成馆中已无藏书。

[CiNii BA73763630](https://ci.nii.ac.jp/ncid/BA73763630) 另有台湾台北文史哲出版社1972.2、三册、22 cm 的《高麗史》；它与上述韩国出版物至少在出版社与出版地上属于不同记录，不能“1972+书名”合票。

## 对历史排盘与《授时历立成》的实际作用

现代同年书目细分只缩小**调阅路径**，不会把扫描页换成古籍版本证据。若有合法调阅许可，优先要求指定九州大学 `BA63617326` 的原册版权页、目录与**卷52历志的真正原页**；再把其实际影印底本、馆藏和页码与 SNU `GK05553`、`GK05554` 及官方 KHS 2114-1 的实物证据交叉核实。未经原页确认，不能预断卷52位于上中下哪一册。
