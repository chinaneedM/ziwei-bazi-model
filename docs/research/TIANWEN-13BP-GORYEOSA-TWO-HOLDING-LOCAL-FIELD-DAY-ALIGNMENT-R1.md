# 天问 13BP｜《高麗史》两馆藏原图已校数栏的日序异同审计

本轮严格重用 13BN 早稻田与 13BK 日本国立公文书馆**已经绑定原图 SHA、独立数字单栏 ROI 与印刷日序**的既有记录，不声称新增图像、原叶读数或新的实物见证。13BO 最新第17/18日已完成直接校勘；本轮专门核查**跨馆藏数栏和日序能否一律平移**。

| 相同原字数值字段 | 早稻田印刷日 | 公文书馆印刷日 | 值 |
|---|---:|---:|---:|
| 积数 C | 19 | 20 | 8843.7571 |
| 积数 C | 20 | 21 | 9257.6000 |
| 长栏 L | 19 | 19 | 413.8429 |

同源内部算术，各按独立印刷日序计算：

- 早稻田：C(20)-C(19) = 413.8429 = L(19)；
- 日本国立公文书馆：C(21)-C(20) = 413.8429 = L(19)。

因此，相同数值的两项积数呈现一日的**局部印刷日差**，而相同值的长栏均标十九日。不能据两项积数便把**全部数栏、整表日序或历法坐标一律平移一天**。这并不证明整表绝无其他日序规律，亦不证明两原本为独立版刻、同版、同物理副本或直接传抄。该证据范围受限于既有原图中已读的三个数值原子；不做重复来源计票。

JSON 逐项绑定 13BN/13BK 的 Git blob SHA、ROI key、字段名、日序与精确四位小数；13BP 测试故意篡改字段／日序／SHA／计票数，必须失败。既有 13BJ 误标日序及混栏历史记录仍原样保存。
