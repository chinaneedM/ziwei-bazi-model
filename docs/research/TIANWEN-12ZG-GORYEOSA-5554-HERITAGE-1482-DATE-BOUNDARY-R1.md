# 天问12ZG｜奎貴5554：1482国家遗产时代标记≠实际物理印次年

本轮检验同一对象两个第一方记录的不同时间口径。韩国[国家遗产门户「고려사(2021-2)」](https://heritage.go.kr/heri/cul/culSelectDetail.do?ccbaAsno=0021140000200&ccbaCpno=1121121140200&pageNo=1_1_1_1&sngl=Y)列为**金属活字本、98卷32册、时代1482年（成宗13）、2021年2月17日指定**。它的国家遗产编号**2114-2**、32册和馆藏机构与[奎章阁 GK05554_00](https://kyudb.snu.ac.kr/book/view.do?book_cd=GK05554_00)中的奎貴5554对应，因此确认两份现代官方元数据**指向同一保护对象的可能性很高，且具编号绑定**。

然而，奎章阁现行同物品目录明记刊年**[刊年未詳]**，现代遗产门户「时代1482」是现代文化遗产归年标签，不自动代替古籍本身刻记、纸张、活字型模和具体馆藏印次定年。历史作品于1451年完成，亦不能代替1482或该具体古纸本刊年。**12ZF中对物理印次「未详」的限定继续有效，不删旧断言。**

另一数目差异必须保留：遗产页面列**98卷32册**，魏志江、陈卓[版本研究](https://www.aisixiang.com/data/121297.html)描述5554残存**105卷32册**。这些可能来自目录/存卷的不同编目与残页统计口径，不足以断言任何一方必然错误，尤其不能以数字多数投票决定表文。流通的韩国宝物条目[二级复载](https://7390882.tistory.com/entry/보물-2114호)把**卷40—52**置于**第6至10册**，本轮仅作物理册次优先检索线索，不能认作直接核对奎章阁物理原图所见。
