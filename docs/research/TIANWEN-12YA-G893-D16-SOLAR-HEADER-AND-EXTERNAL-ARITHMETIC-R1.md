# 天问 12YA — G893 太阳 D16 原印双栏、邻日与异本数列的隔离复算

## 原书物证与可证边界

本轮只处理一件已经取得的馆藏：**奎章阁奎貴893 / GK00893_00《授時曆立成》**。从原先 33,525,981 字节 ZIP（SHA256 `ee9ecf1de3bb6abe5678e0f8ec8383ef985051e77d091ee40840756e57081107`）独立重验 CRC、204/204 原始 JPG SHA。对原书 `001a` 冬至太阳表头、`002a` 同表前续页以及 `002b` 15/16/17 日对照，另外重算 **6 个有坐标的原始 RGB 区域**。具体页 SHA、像素矩形和逐区域 SHA256 记录在 12YA JSON；不使用 OCR，不再次把 204 张图当作独立古本，也不将古籍原 JPG 上传至公开仓库。

直观印本可见 `001a` 有「積日」「盈縮加分」「盈縮積」及解释性「日差加一秒八十六少」等不同层级文字；`002b` 15/16/17 日按纵栏分别刊写成组的原数。需要严格区分**表头所说的递增规律**、**实际印在每一日的多列数表**与**明本/收本所谓第二差分栏**。目前源页可以锚定日次及其双栏版面，却不能由说明文字或相邻数串直接指定哪一栏就是 Ming 1569 的 `WINTER_SOLAR_SECOND_COLUMN_DAY_16`。这只是不具备足够的同字段积极证据，**不是**「G893 全书无此数」的阴性证明，更不是将未知 G893 D16 数字赋值为任一外本值。

## 外部两分支的确切邻日算术（与 G893 原数严格隔离）

仓库既有明1569对《高麗史》校勘总账记录了相邻日的公共候选序列、递增常数及两个 D16 值。仅对此**已登记的外本资料**，用四位定点十进制独立重放：

| 检查 | 精确计算 | 结论 |
|---|---|---|
| D15 加单位日递增 | `5.2176 + 0.0186 = 5.2362` | 与明1569 D16 `5.2362` 相等 |
| D17 逆推 | `5.2548 − 0.0186 = 5.2362` | 与明1569 D16 相等 |
| 两邻日对称中点 | `(5.2176 + 5.2548) / 2 = 5.2362` | 与明1569 D16 相等 |
| 收本 D16 相对同序列中点 | `5.1362 − 5.2362 = −0.1000` | 出现**0.1000**的外本数列偏差 |

这是严格限定的 **外本数列内部一致性检查**：它加强了「明本 5.2362 符合已登记邻日匀加级数，而《高麗史》收本 5.1362 不符合该候选数列」的复算力度；**不能**自动证明《高麗史》原印错误原因或改变任一古籍正文，更不能假设 G893 的同字段原值已被辨读。

## 研究结论与待完成事项

- 六项目标原印页位：6/6；完整原字段仍 **5/6**，D16 仍待栏目身份及完整印本数值。
