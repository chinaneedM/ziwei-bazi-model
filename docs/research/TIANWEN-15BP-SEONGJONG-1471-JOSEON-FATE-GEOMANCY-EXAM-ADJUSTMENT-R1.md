# 天问 15BP｜1471《成宗实录》观象监取才奏议与命课学兼讲：1430—1485制度层缺口

**日期**：2026-11-23。**阶段**：双体系历史传承广度优先。**证据层次**：国家史书官方数字汉文受读文本（C）；1471的事件纪年不等于现存目标原版片或现代转录的形成时间。本批新增一条尚未在13ZU、15A、15BN、15BO或根登记表出现的官方条目。未取得原叶图像，未核准其现存实录物理副本版次，不宣称A类原字或1471当天原奏折尚存。

## 一、新增精确事件与文本证据

韩国国史编纂委员会[《成宗實錄》卷10，成宗二年六月三十日辛未，第二条](https://sillok.history.go.kr/id/kia_10206030_002)，官方数字汉文收文：

> 《大典》內: ‘地理學, 遞兒二、生徒十五人; 命課學, 遞兒二、生徒十人。’

奏议随后称命课学「只習命書，其任不切」，建议「請令兩學人兼講地理、命課諸書，其分數多者，授遞兒職」，末尾「從之」。此处一共能支持：

1. 1471年的官修史录叙述：**地理学二遞兒、十五生徒；命课学二遞兒、十生徒**，这是奏文引《大典》的当年定员，不是我们重新核过的1471年《辛卯大典》原页正文。
2. 奏者认为两学任务与人手分配失衡，提出**兼讲两类书籍**和依据成绩授遞兒职，获准；它说明有**交叉课程的行政要求**，但不证明每名学生实际兼讲、各书具体版本或教学机械规则。
3. 同奏的「重修大明曆」「交食」与各学定员是一份文书中的不同议项，**不能**把该历法考试请求直接转为紫微或四柱的时刻、节令、交运算法祖源；MD-G03仍OPEN。
4. 官方受读版汉文标有**「命(譯)〔課〕學」**的校改痕迹，此外「吏典謄祿〔吏典謄錄〕」也显式列改字；目前没有原页影像判定各笔划及底本异文，所以此处只照录数字校勘表示，不把方括号中的校字当1471原纸直接字形。

同一网页为太白山史库本标出**第3册卷10第48张A面**，现代国编影印第8册第586面。这是官方页面给出的原始叶面**定位**，不是本批取得的原始图片哈希；今后若免费公开的1930太白山本影印或其他原版图可访问，应以印页逐字对读「譯/課」「只習命書」与前后的《大典》引文。

## 二、把1471放在既有1430/1466/1474/1485/1791连续时间轴

| 年代与史料 | 可支持内容 | 不能外推 |
| --- | --- | --- |
| 1430 [15BN](./TIANWEN-15BN-JOSEON-1430-1485-ZIWEI-EXAM-FOLIOS-R1.md) | 阴阳学考书列《紫微數》《三車一覽》及连续未标点的袁天綱/五行精紀书名 | 具体应试书版与起例未证 |

| **1471（本批）** | 《大典》所载两学员额与兼讲建议「從之」；历法考试另案 | 没有1471《辛卯大典》卷三〈取才〉目标原叶，不可填入该版真实术书清单 |
| 1474 [15A](./TIANWEN-15A-JOSEON-INSTITUTION-CURRICULUM-1462-1791-R1.md) | 既有官修收文称初设命课学生徒十八，现「所業成就者鮮少」「將至廢絶」，建议调整人员、设杂职训练，末「從之」 | 1471**现引十人**与1474**初设十八人**属两个不同时间限定，不是必然互相矛盾；「將至廢絶」不是正式永远废止全部命书考试或私学之直接证明 |
| 1485定本传统 [15BN](./TIANWEN-15BN-JOSEON-1430-1485-ZIWEI-EXAM-FOLIOS-R1.md) | 《經國大典》列《紫微數》《徐子平》等为临文科目 | 后世版本里书目存在不证明1474—1485每年教学不中断，更不证明同版 |
| 1555注解 [15BO](./TIANWEN-15BO-JOSEON-1555-CODE-ANNOTATIONS-ZIWEI-ZIPING-ATTRIBUTION-GATE-R1.md) | 《徐子平》条的徐大升与格局归属、《大定數》《範圍數》陈抟归属分别可定为后世收文说明 | 不能回填1471奏折作者或原考书的宋代传承 |
| 1791 [15A](./TIANWEN-15A-JOSEON-INSTITUTION-CURRICULUM-1462-1791-R1.md) | 命课当时「今掌諏吉，而專講祿命」，提出转向择吉书的改革 | 不证明同一体制完整延续320年或改革全部实际完成 |

从1471的「只習命書」到1791的「今掌諏吉，而專講祿命」，可做**官修史录对两代机构自我陈述的并列对读**，不能把「命課」直接等同不间断、相同技术的紫微或子平命盘学校。另一点是1474的现代韩译标题概括为“废止”，但原文的精确断言是**「將至廢絶」与调配请求**；有批准，不等于原文出现「永罷命課學」这类句子。
