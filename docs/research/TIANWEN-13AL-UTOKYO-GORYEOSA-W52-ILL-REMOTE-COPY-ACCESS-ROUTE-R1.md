# 天问 13AL｜东京大学《高麗史》卷52 复制申请的机构门槛与原叶采集契约

## 本批新增的第一方访问事实

东京大学总合图书馆的[学外用户正式说明](https://www.lib.u-tokyo.ac.jp/ja/library/general/user-guide/outside/gakugai)明确写明：**不接受个人直接向馆方提出远程复印资料的申请**。应经所属机构图书馆或居住地公共图书馆申请。因此“已找到卷52实物馆藏”不能升级为“个人远程复印可直接执行”。

其[馆际互借／文献复制正式说明](https://www.lib.u-tokyo.ac.jp/ja/library/general/user-guide/outside/other-inst)进一步区分：参与 NACSIS-ILL 的大学图书馆可以走馆际复制流程；日本公共图书馆渠道接受文献复制、**不办理图书借出**；两者均以馆藏状态和文献保护政策为先。标为贵重／准贵重的资料不能按普通电子复印处理，须按要求提交相应许可并由指定人员拍摄。英文[跨国馆际服务说明](https://www.lib.u-tokyo.ac.jp/en/library/general/user-guide/outside/other-inst)把国外图书馆请求限于图书馆人员、并有“馆方独有”与保护限制；没有证据显示这两册满足独有性测试。

[非校内人士预约说明](https://www.lib.u-tokyo.ac.jp/ja/library/general/user-guide/non-member)另允许以学术调查为目的预约现场阅览：通常须在希望使用日期前10—3个工作日申请、工作日现场不超过两小时；现场使用与远程复制是**不同授权路径**。具体资料是否可见、保存库还是古籍、是否已有替代影像，必须先向馆员就两项原件核实；不能仅由 G23 书号或 NII 联合馆目断定。
