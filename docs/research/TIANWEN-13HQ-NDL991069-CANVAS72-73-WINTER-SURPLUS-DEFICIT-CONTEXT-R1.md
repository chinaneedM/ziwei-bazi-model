# 天问 13HQ｜NDL991069《高麗史》卷五十二第72—73幅「冬至前後」表格跨页定位

本批**不添加新的古历数值裁决**；使用先前已从馆方 IIIF 真实获取并存入 Actions artifact 的相邻来源图，补上 13HP 尚未厘清的日次表季节文本上下文。

第72幅为 **1600×1248** 来源预览，原图 SHA256 `295a3a839914f51a33c19f6e7cea6c113413d9bcb3c2423c60589bb51bdf5c86`，封存于 [13HN run 40276733041](https://github.com/chinaneedM/ziwei-bazi-model/actions/runs/40276733041) 的 artifact `12630338053`（ZIP SHA256 `f0776fc9d679ac72c481241edb08010be889413ad15f8b36c8d25427726de69d`）。在**同一左叶表格上方**可见「太陽冬至前後二氣盈初縮末限」，相邻「授時曆立成」，其下自「初日」起逐列至「五日」。第73幅对应 **3773×2943** 馆方 full 响应，SHA256 `c5fc1b3aeff9aedb84bc36fff02fad2a865e7c86c9fd1e624f7f18a548f945bb`，来源 [13HP run 40312727158](https://github.com/chinaneedM/ziwei-bazi-model/actions/runs/40312727158)、artifact `12645481673`（ZIP SHA256 `5fa5a8d197238794d16ed5c3e37e33fe5d74b4838d4d51da27195548c42935e9`）。第73幅右叶上段接「六日」至「十一日」，下段续「十二日」至「十七日」。

因此 13HP 的「十四日／五分一九九〇」和「十六日／五分一三六二」可进一步限定到 **1909 年刊本「太陽冬至前後二氣盈初縮末限」文字上下文之连续表列**；这不是对元朝古本原数、精确技术列/古单位或旧物理副本的裁决。韩国 NIKH 照片「夏表十四日／四分六六三〇」在另一来源、另一季节文本作用域，不构成与本刊本直接同栏对立。
