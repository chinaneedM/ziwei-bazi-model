# 天问 13HZ｜NIKH《高丽史》冬表第十八日双向约束

经核对[韩国国史编纂委员会《高麗史》卷52原文编辑页](https://db.history.go.kr/goryeo/level.do?levelId=kr_052_0010_0010_0020_0010&types=o)，第十七至十九日三栏支持以下**仅针对现代校录的无量纲算术**：

```
日差17=4243711-4191163=52548
日差18=4191163-4138429=52734
前侧推得积18=80002697+4243711=84246408
后侧推得积18=88437571-4191163=84246408
```

两侧计算一致，但同一官方现代校录第十八日「盈縮積」原文字串为**八千四百二十四六四〇八三**，尾部保留「三」，数字流为 `842464083`。维基文库[现代收本](https://zh.wikisource.org/wiki/高麗史/卷五十二) 为**八千四百二十四六四〇八**。两种网页文本不是两份原刻实物，双侧递推不授权删去源文字末尾「三」，也不能确认原刻是否如此。13HY 对 13HX 的非法数值归一化撤销继续有效。

NAJ、早稻田、NDL1909 原图第十六日「五分一三六二」维持原字，算术「二三六二」仍非原字见证。下一任务：先复核现成原图 NAJ 第18幅、早稻田第23页及 NDL1909 后续页第十八日原始「盈縮積」列，并对比更早独立版次。不得把同一影印链、编辑文本、计算反事实计为新增独立见证。
