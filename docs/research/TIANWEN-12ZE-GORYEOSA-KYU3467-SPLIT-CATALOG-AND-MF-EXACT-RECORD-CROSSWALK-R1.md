# 天问12ZE｜《高麗史》奎3467数字分组、乙亥字册与馆方缩微胶卷标识逐级交叉定位

## 已直接核验的两条 item-level 第一方记录

继12ZD从馆方专题表找到**奎3467 第6冊即卷52的乙亥字原页候选**之后，直接读取奎章阁[GK03467_02](https://kyudb.snu.ac.kr/book/view.do?book_cd=GK03467_02)和[GK03467_04](https://kyudb.snu.ac.kr/book/view.do?book_cd=GK03467_04)。前者馆号 **奎3467의2**、乙亥字、**零本5冊**，而且其「所藏本」字段明确指出**第9冊1冊木板本**；后者 **奎3467의4**、乙亥字、**零本1冊**。两份原生详目均未给出「本记录所藏第6册=卷52」的册图绑定。尤其不可因为一个目录大标签称乙亥字，就将同一本中第9册木刻本抹去。

在[第一方《高丽史》目录清单](https://kyudb.snu.ac.kr/book/list.do?book_cate=KRE01&mid=GDS)中，奎3467四个数字分组的**整体类型**分别是：奎3467의1木刻本、의2乙亥字、의3-v.12抄本、의4乙亥字。后两类的前提是**馆方书目类型**，不是目标纸页的印刷方式鉴定。现阶段把 GK03467_02、GK03467_04 作为卷52目标的**有条件候选数字入口**，不能二选一、不能确定四分组之间的分藏物件数量，也不能因馆号拆分而计入四个独立传承本。

## 缩微胶卷与“同版”菜单的作用域

两条已核对的详目均显示两个原样 M/F 字符串：`M/F82-16-206-1` 与 `M/F82-166-206-2`。其「16」与「166」区别**原样保留**，既不自作主张订正为一组，也不把末尾-1/-2 自动转成第6册或某一叶。源页公开了“原文图像、目录信息、微缩胶卷”入口以及“选择册次”的 PDF 菜单字样，但本次访问没有解析出带有卷52与具体纸页、图像字节、SHA的可复核原页。因此二者均仍是**书目与数字访问入口**，不产生一张新历史原字投票。

另外，馆方在 GK03467_02 的「同一版」栏目关联 奎3467의4、奎貴5553、奎貴5554、奎5874의2。这只是馆目分类信息；即使有相同字形，也**不能自动证明独立实物、出版日期或直接抄传方向**。作品1451完稿日期与任何一个现存乙亥字物件的刊年严格分离。

## 校勘边界及接续条件

本批没有取得新的日16／日18原叶、没有修正已有 CADAL 扫描件的 D16 原字，也没有证明奎3467与那个 CADAL 扫描是同一份实物。TW-OPEN-0005 仍开放、G893已读原本目标 **5/6**、跨原本机械终判 **0/6**、全体11个遗漏问题保持、排盘产品 CLOSED、算法未重开、传承图未增独立边。跟进应当以精确两个详情页提供的**实际册序选择器**为起点，先找到第6册卷52的源发原图或准许的馆方复制，再登记相应实体、数字页、哈希及 D16/D18 两处字形；不得拿馆藏菜单或同版推荐替代目标叶。
