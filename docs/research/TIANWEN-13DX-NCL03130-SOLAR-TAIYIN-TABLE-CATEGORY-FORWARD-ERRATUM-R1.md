# 天问 13DX — NCL03130《高丽史》太阳／太阴原表归属前向勘误

**本轮裁决：13DT、13DU、13DV、13DW 在 NCL03130 第 86 页把「二十八」作为太阳夏至 D28 待校目标，属于表别归属错误；第 86 页实为「太陰限數遲疾度」第 28 限。** 此勘误只修正该来源图像的机械字段身份，既不撤销原 SHA、也不修改原批研究记录，更不宣告太阳 D28 数值或历史算法裁决完成。

## 受影响的历史断言和防污染规则

- 13DT 的原页采集有效，但 p81–90 不是一套可以直接认定包含太阳 D28 的连续影像；13DU p86 三裁区有效，但此前取名的「夏至 D27–D29 行度」目标在表别上错误。13DV／13DW 未填写 XingDu 值的 fail-closed 决策是正确的，**需要更严格地升级为“已确认是另一张表”，而不是仅“同页多栏暂未读”**。这些旧文件保持原样，勘误以新文件的证据等级覆盖其错误归属。
- 本镜像中太阳 D28 的真正原页和「行度」数值**尚未重新取得**；别本的 0.994549 与算法候选 0.964549 不得塞入 p86，也不能当作 NCL 同本原字。
- p81 已印八十一至九十一日，p82 收尾九十二／九十三日，下一轮已建立 13DY 采集脚本与工作流，限定 p73–p80、源 PDF SHA 必须全字节匹配；必须从**原页实见日次与字段栏头**确认真正太阳夏至 D28，不能用“应在第76页”猜算替代校勘。
