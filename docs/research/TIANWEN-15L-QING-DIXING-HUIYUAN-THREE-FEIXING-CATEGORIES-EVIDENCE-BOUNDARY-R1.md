# 天问15L｜清代《地星會源》与《斗數綱要》：三种飞星说的传本界限

研究日期：2026-11-21。目标是补齐15J至今未单列的**清代独立术式／校抄文献**覆盖格，而非继续从明代相同书名推定直系传承。材料等级以**2011年出版者所作古籍提要（C，编者转述）**及**2011香港书籍的图书馆电子书元数据（B，现代出版物）**为限；未取得清钞本原页、逐叶书影、旧藏流转或书中实际排盘算例。

## 1. 可核查的两个现代对象与一个待核的清钞对象

- **出版社一手出版信息**：[心一堂《地星會源》《斗數綱要》合刊](https://publish.sunyata.hk/product/967.html)，2011，ISBN `9789888058754`、一册、标注164页；同页编辑提要称《地星會源》为一册不分卷的“清同治精鈔本”、虚白庐藏，又称书中有“鳳尾氏重訂”字样，并**猜测**凤尾氏可能即何汝檉别字、疑作者手稿。上述年代、藏本和作者身份均是**现代编者描述/推断**，尚无可独立复查的旧物版记、藏印与逐页证据。
- **图书馆平台的现代书籍元数据**：[高雄市立图书馆 HyRead](https://ksml.ebook.hyread.com.tw/bookDetail.jsp?id=23272)列书名、何汝檉修订、香港心一堂、2011、ISBN一致，电子格式PDF/JPG，页面显示168页。它**可以独立复查2011书籍的馆配记录**，但其简介与出版社明显同稿转载，不能当第二份独立清代旧物文字见证。164与168页为两平台不同分页字段，未得原书和电子封面/版权页前**不判两个印次**。
- **历史原钞身份**：仅凭出版社提要可登记《地星會源》与《斗數綱要》的**候选清钞书名/藏本线索**；不能说本次获得、校勘或认定了同治年的作者手稿。原文本形成时间、清钞实物日期、2011影印是否全页对应原物及现代数字代理的扫描/增页时间均未分别核定。

## 2. 清代飞星“第三种”所能支持的最强判断

心一堂提要**转述**何氏的三分法：第一类“紫微斗數”，第二类“小飛星”，第三类《地星會源》，并说后者以会合、冲破变化为特色。出版社的整理者进一步把“小飛星”**解释为**《續道藏》三卷本或《合併十八飛星紫微斗數全集》的相关术式；这层**现代同定不能视为清钞原句本身已经逐法证明**。此条从15J“只有两类常见术式的比较”扩展为“清代另有第三种术式主张的**晚出提要证据**”；不能直接证明三门系统各自有完整独立的机械法、各自流行范围或哪一个沿承自另一个。

HyRead 的**章节目录**在《埊(品土)會源》下列“起星例歌”“十二宮挨次逆布”“起長生法”“起大運流年法”，同时在《斗數綱要》列紫微、天府、十四主星、化禄权科忌和十二宫相关篇目。这只能确认**2011影印编目所报告的目录结构**，不能据目录名称替它计算星曜、断言与现代十四主星同公式，或重开 R1 排盘。出版社提要称匿名《斗數綱要》是摘《全集》《全書》并加补注的清钞本；这属于**现代校者提出的文本关系线索**，在未取得被抄页与对应版本的并列核读前不建立`EXPLICITLY_CITES`/直传边。

## 3. 双史纲和传承图谱的实际增益

1. **紫微清代覆盖**由“清末《全集》《全书》版次”增加“《地星會源》候选独立飞星术式 + 匿名《斗數綱要》摘抄/评注传统”两条研究入口。此处是**被2011年整理刊物报道的清代材料**，不是已取得的新清原物。
2. **地域层**明确区分声称的清代旧藏“虚白庐”与香港2011年影印出版、台湾图书馆电子平台传播；香港／台湾现代出版流通**不等于**清代师承路径。
3. **图谱仅增现代可证的作品题名节点与2011合刊版本节点**、一条版本收录关系（以《地星會源》为其中一部的现代出版编目意义），**无清代原钞物理同定、无三种术式间已证传承边**。
4. **四柱并行性**：本批只涉及紫微，不新增四柱清史事实；15I宋元“年本日主”问题与既有四柱史纲保持独立。

## 4. 后续证据门槛

优先寻找**免费、可合法取得的《地星會源》/《斗數綱要》清钞原页**或注明原底本来源的完整公共影印，检查凤尾氏与何汝檉指称的实际上下文、三类术语的完整段落、起星例歌的输入变量和星序，并与《續道藏》及明刊《捷覽》《全集》《全书》按同一机械测试轴比较。若无合规原页则保留此支线为“现代出版提要/馆目已证、清稿正文未核”，转至另一个广度缺口，不重复付费或登录路线。
