# 天问 13U｜早稻田《高丽史》独立馆藏原本：首轮册次定位采集

沿 P0 风险 TW-OPEN-0005，已有国图 Commons 转储的卷52第40数字册原页哈希与 D16/D18 文字，但馆藏实物身份及多个来源相互独立性仍需校验。为避免继续在同一NLC代理资料中重复寻找独立见证，将**实物馆藏不同**的早稻田本作为下一条来源链的原影像路由，暂不设定预期数字读数。

## 证据约束

- **第一方书目已核实**：早稻田大学图书馆 https://www.wul.waseda.ac.jp/kotenseki/html/ri06/ri06_02809/index.html ，馆号 **リ06 02809**，《高麗史》80册、31cm、朝鲜装、有朱书与补帖；刊刻地、刊刻年均未知，不能将作品成书的1451年当作该实体本印年。
- **首轮源地址直接请求过**：`https://archive.wul.waseda.ac.jp/kosho/ri06/ri06_02809/ri06_02809_0030/ri06_02809_0030.pdf`，网页读取方返回所需PDF 48,797,544 字节超过其内容上限，证明有明确原件图像访问路由；当前仓库状态仍无该文件PDF哈希，也未读其内卷首。
- **抽样册与作品卷的映射未定**：早稻田80册中的数字第30册不等于《高丽史》作品第30卷，也没有证据声称它含卷52。选用单个样本是为了通过原图真实卷首/卷尾推算映射区间。
