# 天问 15AG｜台湾《中华星相》试刊号与第17号的免费可见实物照片、1979–1982书系辨名

核验日期：2026-11-22。承接15AE、15AF近现代台湾学会期刊史，继续遵守**广度优先**与零付费公开资料原则。发现实体期刊/书籍的旧书商**实拍照片**，只把图片实际可见部分作为范围有限的封面文字证据；卖家自行标注页数、年代、出版责任属于商品说明而非独立原书刊记。

## 1. 明确进展：不再只有后出的出版年表

### 1.1 民国65年／1976年《中华星相》试刊号

[原刊物旧书商公开商品页](https://www.ruten.com.tw/item/22501551343663/)与[可见封面照片](https://gcs.rimg.com.tw/g4/4f2/11a/s_sou688/7/a0/2f/22501551343663_816.jpg)：**封面直接可辨“中華星相”“試刊號”**；另有[内页照片](https://gcs.rimg.com.tw/g4/4f2/11a/s_sou688/7/a0/2f/22501551343663_887.jpg)，可见编辑性质标题“寫在試刊號之前”，以及对页的另文/表格。商品说明说“中華民國星相學會發行”、29页、15.5×21.1厘米、有水渍；刊年民国65年来自商品标题并与封面下部年代字样相符，但**未取得可验证的完整版权／出版页、全29页、扫描文件哈希、出版责任人独立身份**。

分类：**卖家拍摄的原刊样本封面／局部页图，附商业刊物书目资料**；不是完整原刊、馆藏认证、独立学会档案、证据充足的期刊沿革。可以审慎确认公开照片里存在**以“中華星相”为封面名称的“试刊号”对象**，不据此推断试刊号应计入1–31册、32期哪一序列。

### 1.2 民国66年／1977年《中华星相》红色“17”封面

同一旧书商[公开商品页](https://www.ruten.com.tw/item/22636572657955/)与[封面照片](https://gcs.rimg.com.tw/g4/4f2/11a/s_sou688/2/cd/23/22636572657955_116.jpg)，封面直接可辨“中華星相”和红色**17**，刊年民国66由商品标题及封面下方日期字样佐证；精确日/月不在本批裁决。[局部内页照片](https://gcs.rimg.com.tw/g4/4f2/11a/s_sou688/2/cd/23/22636572657955_961.jpg)显示文章标题“奇門遁甲概論（三）”，至少说明该样本不限于现代软件的紫微、子平术语。商品说明称43页、尺寸15×21.1厘米，属于卖家著录，不等于全书逐页确认。

分类：与试刊号同一商业卖家提供的**另一册号／外观相近的对象**；封面“17”目前只做可见数字，不在未核目录或刊记前擅自裁决是“第17期／第17册／第17卷”。来自同一商家，不假装构成两个独立发行机构认证的来源票数，也不自动建立二者之间的版片连续、责任主体或刊号体系。

### 1.3 对既往15AE／15AF关系的边界更新

- 行卯出版社年表（15AE）著录1976《中华星相》学术期刊1–31册，**如今已有1976“试刊号”与1977“17”两个封面层实物线索**；年表不因可见两件物品而被整体认证。
- 梁湘润2009年自述1973年《星相月刊》32期，与2013年回忆用语《中华星相月刊》，**仍然没有原刊同一性证据**；不把1976/1977物件强行并入1973开始的32期。
- 香港袁树生／哲学出版社1977–1979《星相》月刊1–20期（15AF学术脚注）仍为**另一地域、不同标题的独立检索对象**，不能被这两册台湾照片“证明”或“否证”。
- “中華星相學會”“中華民國星相學會”在不同资料的字样未由原刊版权页与组织登记同一性闭合；2007同名法人继承关系仍未证。

## 2. 《中华国粹百科全书》1979年六册与“中华星相国粹百科全书”修订本：不同层级

### 2.1 日本古书商的1979年六册著录

[鶴本書店公开商品项64810](https://turumoto.koshoten.net/catalog/product_info.php/products_id/64810)著录《中華国粋百科全書》、1979年、**6册**、精装B5，字段“著者名”为“中華星相雑誌社”；其“出版元”字段却为泛称“中文書”，不能当作真实出版者。此前15AF Google Books 把“中華星相雜誌社”标为**出版者**；两网站对同一名称的**责任字段并不一致**。该差别只能作为书目角色冲突登记，**不证明任一方的原版作者／出版社角色**，更不能从6册商品目录判断原版六册的完整性或版次。网站有付费售书，但本批只读免费商品详情，**不购买、不登录、不索取有偿扫描**。

### 2.2 修订版系列《神煞探原》第一册与《堪舆辞典》第四册

台湾两个其他旧书商展示：
- [《神煞探原》商品页](https://www.ruten.com.tw/item/22610211463143/)与[封面照片](https://gcs.rimg.com.tw/g1/a/ab/e7/22610211463143_884.jpg)：可见“梁湘潤編著”“神煞探原”“中華星相國粹百科全書”“修訂版第一冊”；**没有从封面核得原刊年份、版权页或同版正文**。
- [《堪輿辭典》商品页](https://www.ruten.com.tw/item/22442991679005/)与[封面照片](https://gcs.rimg.com.tw/g5/005/4a7/poju3/1/66/1d/22442991679005_534.jpg)：可见“梁湘潤編著”“堪輿辭典”“中華星相國粹百科全書”“修訂版第四冊”；**民国71年／1982年是卖家标题之著录，未核书内刊记**。

这是两份**不同内容题名、修订版分册号不同**的实物封面线索。“中華星相國粹百科全書”比Google Books《中華國粹百科全書》多“星相”两字，不可仅凭题名相近及梁氏相关性就宣布1979六册与1982修订版同一版片、同一编次或作者结构。1979 Google Books书目、1979古书商六册商品与后来两册“修订版”保留**三个不同证据身份**。

## 4. 衔接与下一批优先级

1. 查找台湾国图、国家图书馆期刊信息、大学馆藏对1976试刊号和1977数字17的机构级目录绑定、完整刊次／日期；本次未见可免费取得的同册完整扫描。
2. 查找1976试刊及1977样本**公开完整版权页／发行页**，确认学会、编辑、日期与发行人、栏目的物理原文字形。绝不拿卖家水渍图证推定32期、31册一致。
3. 查找1979《中华国粹百科全书》及后续《中华星相国粹百科全书》修订本的**原书端、分册目录、版权页**，优先免费公版或合法开放资料；不购买。
4. 台湾师大2020施郅芹论文仍等待合法免费全文途径的询问回复；本轮检查尚未见到回复，不绕过验证码。
5. 双历史骨架继续推进已不足覆盖的早期紫微机械、时代/地域桥，避免在单一商业书目链长期打转。
