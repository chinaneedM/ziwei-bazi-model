# 天问13E｜卢明镐《高丽史》版本学论文及奎章阁异本校勘项目

2015-08-19 韩国历史学会会议录：https://historykor.re.kr/homepage/boardMedia/14484；作者卢明镐（노명호），原145页PDF的零基103–104页（印刷94–95）已作现代论文原页目检。作者提出乙亥字最佳早印本约1456年，1610年前后对乙亥字进行覆刻木版；两者均是作者的年代研究，不是绑定现存物理本的原叶印次。

他讨论了乙亥字传世残缺、后期覆刻校改、印板磨损脱字、现代影印修补和混合底本问题。这些问题要求卷52 D16/D18 必须分别按实际原书叶、实物馆藏号、印次和图像哈希校勘，不能用几个现代数字页面互相投票。

首尔大学奎章阁官方项目 https://kyudb.snu.ac.kr/contents/content_detail.do?code=A06B02&limit=20&listtype=grid&ridx=2&sort=&year= 登记 KIKS-2014-452-23205，2014-05-01至2015-01-16，负责人卢明镐，题为《21世纪奎章阁版高丽史定本编纂事业——最善本选定及主要异本校勘》。2015会议论文直接引用该负责人早期结题报告。完整结题报告及卷52目标页尚未读到；不能将二者算作两个彼此独立的原古籍见证。

现存关于乙亥字年代的1455、约1456、1475—1476三种学术主张并存。所谓1610覆刻板片不能自动作为1613现存印本的实际印印年份。原件5/6、独立跨本0/6，11项遗漏风险未闭，排盘算法不重开。
