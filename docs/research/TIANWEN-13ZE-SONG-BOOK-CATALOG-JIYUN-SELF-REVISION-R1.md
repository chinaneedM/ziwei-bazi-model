## 2. 同一清代考据者的前后版本：重要不能忽略的反向解释

**先前文本：**《四库全书总目》卷109《李虚中命书》提要及《四库全书·李虚中命书》提要，对韩愈墓志“始生年月日”等作“没有时刻干支”的解释；并因后半卷多用“四柱”和部分职官称谓，提出宋人掺入/后加之**清代考订判断**。提要署乾隆四十六年九月（**1781年**）恭校上；此为该提要内部日期，不当然是现阅每一种书页的刊刻日期。

**后出的自我修正文本：**纪昀《阅微草堂笔记》卷十二《槐西杂志二》复审“所直日辰”之句读，认为“日辰”可能为时辰，提出此四字应接“年月日”理解。他明确指出自己编《四库全书总目》时亦曾沿用“不用时”的旧说，附记改议“以誌余過”。但他同时仍称《永乐大典》所收书文兼论八字、宋人伪托疑问“莫能明”，**没有宣布证明现在所有四柱条文都出自唐代李虚中**。

### 训诂分歧与研究裁决

关键争议是“所直日辰”应否上属出生年月日，且“日辰”一词在该句是否属于独立的出生时刻描述。两种句读可以分别构成**历史解释候选**。纪昀后见使“李虚中一概不用时”为定论的说法被明显削弱，但**词义解释本身并非唐代时柱排法原始操作示例**，更不能证明存在“日干为主、十神、格局、起运”整套现代子平架构。

这里出现清代考据者对**自己的先前判断**明确修正的传承史节点，必须并存记录，不能只抽取1781《四库》“其说起宋”一句，也不能只抽取《阅微》的“志过”便认定唐代已完整有八字。

## 3. 作品层、版次层、实物层的非边

1. **晁公武三卷 ≠ 郑樵一卷**：仅能判定书目著录差异，不能从卷数推书籍物理同一或文本直接删节关系。
2. **宋代著录唐人撰 ≠ 唐代亲笔著述/留存唐本**：归属是一项宋人的目录主张，需再核目录写作层、传本、实物年代。
3. **“五命”时、胎两项 ≠ 今日“四柱”算法的自动继承**：现代机械对象要有明确输入、排法与例证。
4. **纪昀晚出修正 ≠ 抹除其1781提要**：两个观点均存，前后次序是清代考据思想史关系而不是唐宋师承边。
5. **印页 A ≠ 原宋版 A**：1930前后之说本轮未取得第一方出版记录，故本轮不确定《万有文库》具体年份；不以数字文件名当实物来源认定。
