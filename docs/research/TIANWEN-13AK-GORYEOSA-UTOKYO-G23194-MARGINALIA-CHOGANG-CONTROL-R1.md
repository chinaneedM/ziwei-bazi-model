# 天问 13AK｜东京大学《高麗史》G23:194 逐卷墨书与「草江書院」同名对象的版本防火墙

## 本批补充的实物目录事实

NII [CiNii BC15973641](https://ci.nii.ac.jp/ncid/BC15973641) 正式登记东京大学总合图书馆朝鲜刊本《高麗史》137卷（81册），目标卷52为 `G23:194 / 0008542011`，但出版年及出版地均写为「不明」。

这份馆目不仅记 **包背装、四周单边九行十七字双鱼尾**，还称有「補鈔」「蔵書印1印」「書き入れ」「虫損」。更重要的是其**明确限定卷次**的历史痕迹：

| 所在卷次 | 馆目所载 | 层级 |
|---|---|---|
| 114、124 卷卷首 | `草江書院冊` | 墨书，*非原页直接亲读* |
| 2 卷末 | `官上` | 墨书，*非刊刻牌记* |
| 10、30、110 卷末 | `光州校上` | 墨书，*非刊刻牌记* |
| 127 卷末 | `光卯校□□` | 目录记录的残缺字样，不能擅补 |
 
这些位置**不包含卷52**。馆目说明并不排除其他卷另有藏记，但**不能推得第52卷已证相同墨书、先前藏主或文本所含数据**。卷52第16日原图、字形、行度数及印版状态依旧未获取。

## 同名背景来源不是实物家谱

韩国学中央研究院的 [《草江書院》百科](https://encykorea.aks.ac.kr/Article/E0056937) 将该书院置于忠清北道永同郡深川面，记载 **1611 年创设、1868 年毁撤**。这只证明存在一处同名朝鲜书院及其历史年份，不证明东京大学 `G23:194` 的墨书曾由该书院书写或拥有，也不能使用1611年限制该古书原始版刻的成书或印刷年。

本批把 `草江書院冊` 与现存同名书院的关系正式定为 **UNRESOLVED_SAME_STRING_NOT_DIRECT_PROVENANCE**。不能假定书院是刻书地点，更不能将墨书的「光州校上」升级为「光州刊本」的题记证明；更不得将卷114/124的记录转嫁给卷52。即使未来确认书院收藏该套本，仍须另找证据判定**具体实体、书页和不同卷次的拼配关系**。

另一东京大学钞本 `BC15670118/G23:12/0008535809` 的馆目另行记有 `40-42: 補配`、朱笔书入，不能将 G23:194 的所有记录照搬到钞本。<https://ci.nii.ac.jp/ncid/BC15670118>
