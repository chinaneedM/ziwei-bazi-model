# 天问 12YV｜梅文鼎《大統歷志》「八卷／十七目／十七卷」目录题法的证据等级隔离

## 本轮可复核的发现

在继续核查12YU已取得的梅文鼎《大統歷志》卷三、卷四数字原书影时，检索到同一作品的卷数题法存在**公开传录层面的冲突**：

1. 《四庫全書總目提要》[CText公开转录](https://ctext.org/wiki.pl?chapter=810234&if=gb)题**八卷、附录一卷**，列为「两淮盐政采进本」。这是目录文字的现代转录，不是本轮亲读原目录叶。
2. 《四庫全書簡明目錄》[另一公开转录](https://www.xuoda.com/hj/jmml/36.htm)亦题**八卷、附录一卷**，同条列**法原七目、立成四目、推步六目**，计十七目。
3. 维基文库所载[《欽定四庫全書總目》四库本卷106](https://zh.wikisource.org/wiki/欽定四庫全書總目_(四庫全書本)/子部/卷106)公开转录却题「**大統書志十七卷**」并出现「**其書舊不分卷，今以所立十七目，一目定爲一卷**」。这一异文需回到**确切原目录叶图片**核实其题名字形、卷数、传录或修订情况。
4. 丁福保、周雲青《四部總錄天文編》[公开影印检索结果](https://upload.wikimedia.org/wikipedia/commons/e/ec/SSID-11568313_四部總錄天文編.pdf)还明确按十七目／一目一卷质疑「八卷」题法。但目前只校到搜索提取字句，**未取得精确书页的无OCR像素级复核**；该近现代文献也不是一份额外的清代原抄本证据。
5. 已经经过12YU原像验证的CADAL06054965数字书影p2题「大統歷志卷三四」，p3卷三，p126卷四，属于**同一既有126页扫描源**，并非本轮新增物理副本。

## 训诂及版本学裁决

「目」是书内篇目单位；「卷」是分卷编次；「册」是装帧实体单位。**七＋四＋六＝十七目**，并不能孤立证明现存实体一定是十七卷。反过来，两个网站记「八卷」也不能直接将十七卷题法判为扫描错误或另一个真实印次。当前只证明*数种数字转录/后出书目之间存在未决的题法冲突*，须用具体馆藏的原目录叶与梅氏原书各卷题署闭合。
