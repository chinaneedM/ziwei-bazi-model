# 天问 13KN — 黄氏／《明史》／梅氏月离历运算对象分层与 167／168 索引边界

本批承接 13KM 上海馆来源原图的 P75/P79 正例与 13KG 哈佛《明史》原印本正例，新增**现代收本文字的语义与算子对象分层**，**没有新增任何原书字形正例**。

## 三个不同的对象，不得凭“益加损减”四字合并

1. **黄宗羲《授时历故》卷四**：识典古籍公开转录段「损益分……益加损减……次日损益分」指**下一日损益分**；同卷另有「一百六十七限」倒减读法。识典的文本定位为 [CADAL02093993 卷四](https://www.shidianguji.com/book/CADAL02093993/chapter/1laylkzccub7j)。此处属于**收文／转录证据**，尚不能绑定 13KI Commons 上海源 PDF 原页。13KM 在 P79 看见的「益加損減」被严格定位于**大衍叙述语境**，不能借同字覆盖这条“次日”转录。
2. **《明史》卷三十三**：13KG 哈佛印本 PDF P12 实际印「益減損加」，操作是**下一限损益分**；P11 精度写作与 13KM 上海 P79「五秒八十一微五十纖」不同。日、限单位与初末限编号仍需完整解读，不能简单认定两书对同一机械运算提出互斥古法。
3. **梅文鼎《大统历志》卷四**：现有[四库收文](https://zh.wikisource.org/wiki/大統厯志_(四庫全書本)/卷4)的「疾历益加损减，迟历反之」所处理的是将损益分施于**每限月平行度，求最终行度**。这是**终值合成**，不是上面两种“递推下一日／限的损益分”；相同四字不等于同一算子或同一出处。尚未获得该版的可绑定原始物理页影像。

## 可执行、但不作古代数表证据的运算对照

以虚构 prior=100、delta=10 作**算子方向测试**：
- 黄氏收文的「益」更新下一日损益分为 110，「损」为 90；
- 《明史》印文的「益」更新下一限损益分为 90，「损」为 110；
- 梅氏收文的疾历终值以 baseline=100、amount=10 得 110／90，迟历终值反向得 90／110。

相同测试结果不代表变量相同；反向测试结果也不足以宣判古籍抄错。这个对照只用于防止研究器或未来实现将**递推分量**和**月行终值**混为一个变量。

## 167/168 不可偷换为确立的 0-based/1-based

13KM 原图 P75 直接确认 168 中限、84 初限、336 周限。识典收文中 `167 - obtained_limit` 仍只是一条**尚未核得原字的现代转录**。若候选域为 0…167，反射常数 167；若为 1…168，完整反射常数是 169。两者不能直接互换，也不意味着源书“167”一定错误。原限符号、行文“算外”、起讫点及 83/84 转折均需原页逐字证明。
