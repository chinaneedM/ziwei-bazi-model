# 天问15AA｜越南《芸臺類語》R.118抄本公开页图与范氏家谱2019版身份

核验日：2026-11-21。本批接续15Y/15Z广度补格：确认《芸臺類語》的可公开检视原始抄本数字载体及2019《唐安丹鑾范家世譜》现代书目。所见原图仍未完成第37/38条逐字校合，不得误称已验证18世纪原始字形。

## 1. 原始馆藏R.118：第一方直接可读的数字影像，不等于目标古文已校

- [越南国图／喃字遗产基金会R.118卷一](https://lib.nomfoundation.org/collection/1/volume/1132/)：项目NLVNPF-0996-01，黎貴惇《芸臺類語》卷一，42个网站页面，汉文手写，28×17厘米，未注明实体抄写年，2009-10-15数字化。馆目同时声明该藏本组缺第三、四卷。
- 本轮抽看若干公开原图（包括[p18](https://lib.nomfoundation.org/collection/1/volume/1132/page/18)、[p21](https://lib.nomfoundation.org/collection/1/volume/1132/page/21)、[p28](https://lib.nomfoundation.org/collection/1/volume/1132/page/28)、[p36](https://lib.nomfoundation.org/collection/1/volume/1132/page/36)及[p42](https://lib.nomfoundation.org/collection/1/volume/1132/page/42)）。仅证明页面入口及局部图像可核；未取得原始影像字节SHA，亦未完成全文校勘。不得把网站索引页码当成现代译本叶码，更不得从未查看部分推断目标段落不存在。
- 分开记录：黎贵惇生平/作品时代、R.118实际抄写年代不明、2009数字化日期、2026取证日；这些不能互换。

## 2. 第37/38条的越文收本对照不是汉文原字

- [Quách Ngọc Bội署名的越语公开摘译](https://bacdautravel.com/tin-tuc/le-quy-don---van-dai-loai-ngu---phan-ly-khi-54-dieu-39.html)将《理氣》分54条，第37条讨论子平、五星、紫微前定三类数术，第38条报告罗纶序、华山了然僧、陈抟归属相关说法并提出批评。此为受读文本与译者编排，尚未与R.118物理第几叶、第几行、何字相连。
- 可保守得出：有明确的现代译读回查目标，且译读语境区分子平术语和紫微源流叙事。不可由此断言黎贵惇本人所用汉字、相应段落一定在这份R.118中，更不能以文本对传说的转述来证明真实师承或说明宋元绝无类似术数。
- 下一步按R.118源图原生分辨率核两段词句，记录独立源图SHA、页码及上下文，并对照其他传本。现阶段原叶句读和实际四柱/紫微规则均未闭合。

## 3. 范氏家谱2019译编本的ISBN与馆藏对象

- [胡志明市综合科学图书馆官方目录590751](https://phucvu.thuvientphcm.gov.vn/Item/ItemDetail/590751)的搜索公开索引显示2019年河内Văn học《Đường An Đan Loan Phạm gia thế phả》，署Phạm Đình Hổ和Trần Thị Kim Anh（介绍/翻译），268页、24厘米、ISBN 9786049768149，馆藏VV 2013/2019与VV 2014/2019。官方详情当前通过外部工具打开超时；记录为机构搜索索引可复现的书目信息，不假装逐叶读过2019版。
- 两件现代馆藏不等于两部独立古谱，也不揭示2019整理者使用的是A.909、VHv.1353还是其他底本。15Y提到的页117–118范珪/范嘉運叙事仍待该版实物原页与古谱核对。

## 4. 1990年前期资料用号有细节差异

- [汉喃研究院1990年第1期附注](https://hannom.vass.gov.vn/web/tchn/DATA1/9001v.htm)所列参考本写为VHv.1353/2及A.909，后来正式馆目简列VHv.1353。本批不得将尾缀/2当成新增第三件独立抄本，须先弄清册次/组件/馆目简写。
