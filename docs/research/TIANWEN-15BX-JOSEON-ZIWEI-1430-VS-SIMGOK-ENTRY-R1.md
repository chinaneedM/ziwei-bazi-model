# 天问 15BX｜朝鲜《紫微數》早期书证与金緻《深谷秘訣》「首次传入」说的证据分层

研究日：2026-11-23。广度优先研究，承接 14U/14W、15BN、15BW。**本批未取得明以前《紫微數》具体操作原书的新定年叶**；目的在于补入此前尚未登记的《深谷秘訣》馆藏解题与2018年韩国学术源流论，同时按早期取才原影裁定「首入朝鲜」叙事的合法作用域。

## 2. 2018「首入朝鲜」的两个不同范围

吳定祐（오정우），〈중국 자미두수의 조선전래 연구 : 金緻의『深谷秘訣』저술 배경을 중심으로〉，2018，《원불교사상과 종교문화》78，457–483；KCI https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART002431369 。公开摘要认为金緻借中国明代《紫微斗數全集》在17世纪初引进术法、撰《深谷秘訣》，并追述陈抟创建、罗洪先1550编集及之后约五十年传朝鲜。**仅阅读摘要及书目，未核该文27页完整论证及其原件**。

- **广义术名首见/首次传来**：若命题是「朝鲜直到17世纪才有任何名为《紫微數》的书」，则已由15BN的1430原影与1485法典存在同题的事实形成**有界反证**，不能把该全称命题保留为史实。
- **具体明刊《全集》版次入朝**：1430书名无法证明当时已存在后世某一《全集》文本，更不能否定17世纪另一次版本输入可能性。这种窄命题需找到金緻作品的定年正文、引用来源、卷页与特定明刊的同文特征。
- **首个朝鲜本土著述**：早期取才书目不等于已有署名朝鲜作者；1644实录所述家中绘盘亦不能提供更早本土书的原稿。金緻作者归属、最早撰述与纸本抄年均未决。
- **1550罗洪先师承**：15AI及13ZP已把1550序末署年、明本有序/无序、不同《全书》《全集》《捷览》家族分离。2018摘要不提供1550独立原刻证明，不得提升为谱系CONFIRMED。

结论须同时防范二种过度推断：1430书名不能证成今日斗数体系；17世纪某一传承故事也不能抹除1430官修术书题名。书名/机构试书/机械规则/版本首传/当地作者五个历史轴分别填写。
