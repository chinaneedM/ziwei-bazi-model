# 天问 13HV｜三馆冬表十五至十七日同栏原字：1362 不是仅见于1909年的异文

将此前已经由馆方下载并封存的 NAJ、早稻田及 NDL1909 三组 JPEG 重新取回，验证 ZIP SHA256、JPEG SHA256、图像尺寸并直接逐字核读，同一《高麗史》卷52「大陽冬至前後二象盈初縮末限」表「日差加一秒八十六少」栏的十五、十六、十七日，三处均为：

| 来源 | 十五日 | 十六日 | 十七日 |
|---|---|---|---|
| 日本国立公文书馆第51册第17幅 | 五分二一七六 | **五分一三六二** | 五分二五四八 |
| 早稻田大学第33册 PDF第23页 | 五分二一七六 | **五分一三六二** | 五分二五四八 |
| NDL 1909刊本第73幅 | 五分二一七六 | **五分一三六二** | 五分二五四八 |

每一来源分别用非 OCR 直接源图查读，三日九个原像素框、RGB SHA256、JPEG 和原 ZIP SHA256、以前的 Actions artifact ID 均在同名 JSON。NAJ 完整 source JPG SHA256 `8362e8a2b8ddf5f36408d4450a81ebad2d9548b32f49dbe37e01493592b7c3e9`；早稻田第23页 `388f3d5dd9e9861f8ce90c304b154edaeaee98614bb12cd3468f957dcde6fc66`；NDL1909 第73幅 `c5fc1b3aeff9aedb84bc36fff02fad2a865e7c86c9fd1e624f7f18a548f945bb`。

差分仍为 `2176→1362 = −814`、`1362→2548 = +1186`。插值预期 `2362` 不见于这三份源图，继续作为 **NON_ATTESTED_ARITHMETIC_COUNTERFACTUAL**，不得直接覆盖一三六二。这不是1909年晚本独有的笔误：另外两个已注册的不同馆藏实物对象也保存了一三六二。

这不意味着已证明三者独立版木，也不意味着三者从同一有误祖本直接抄来；实物印次年代、版刻谱系、术语单位及更早版本其他读数仍需证据。NAJ/Waseda/NDL均为**原先已登记的实物来源**，本批新增来源数/实物见证计数均为0。
