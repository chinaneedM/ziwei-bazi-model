# 天问12ZF｜《高丽史》奎貴5554原件候选与1972影印本的来源边界

本轮直接核对[奎章阁 GK05554_00](https://kyudb.snu.ac.kr/book/view.do?book_cd=GK05554_00)，确认为乙亥字、残本**32册**、刊年未详、宝物2114-2；页面没有提供可绑定卷52第16日与第18日数表字形的实物原页。页面出现的「卷50—52历志」是**作品总目录**，不能据此冒称已取得5554的目标页。

魏志江、陈卓[《高丽史》版本源流与编纂体例考](https://www.aisixiang.com/data/121297.html)给出奎貴5554存卷**40—52**的二级学术线索，并介绍1972年亚细亚文化社以此乙亥字本作底本、缺卷由木刻本补配的影印方案。这仍不是直接读过1972影印卷52原字，也不能以全书底本说明担保某一具体页未受木刻补配。

**书目交叉指向发现：** 5554官方详情的七段 `M/F74-102-17-1` 至 `-7` 均注明**奎5553**，而[奎貴5553官方详情](https://kyudb.snu.ac.kr/book/view.do?book_cd=GK05553_00)又列完全相同的七段号码。现阶段只能确认证据是「5554公开目录字段引用5553项目」；该字段不能证明5554自身的缩微原页在哪里，更不能未经核验擅自订正后台书目。

馆方对5553的46册记录包括第8、26、29册补抄，扣除此三册的保护范围是43册；不能将「46」与「43」当成不同历史版本。二级学术转录将最后一册补抄写作28册，与官目录29册冲突，本批明确保留差异，不把次级文字升级为原物权威。

**可执行追索路线：** [CiNii Books: BA63617326](https://ci.nii.ac.jp/ncid/BA63617326)明确登记1972年首尔亚细亚文化社《高丽史》上、中、下三册，收藏机构包括九州大学、神户大学、国立历史民俗博物馆、日本大学和丽泽大学。五处馆藏属于同一现代影印版，不是五条古代来源。卷52在三册中的具体位置及其影印底本尚待原页比对。
