# 天问 13D｜1454《高丽史》广布说的近现代证据循环与原始事件语义

本轮核对两家机构出版或托管的学术综述，不将它们计为两份古代实物。

## NIKH《新编韩国史》第26卷的关键证据跃迁

官方[历史网站分节](https://contents.history.go.kr/front/nh/view.do?levelId=nh_026_0020_0030_0010_0020_0030)与[PDF](https://contents.history.go.kr/data/pdf/nh/nh_026_0020.pdf)是同一个学术著作的不同载体。已经直接目检 **PDF 零基第114—115页／印刷第124—125页**（非古籍原叶）。文中先按注63引1452年《端宗实录》请求准印；再按注64引1454年实录已少印、仅存内府的报告；继而把李克堪奏请后以郑麟趾名义印出并在一般社会广传作出肯定性叙述。其最后一步属于**学术叙事推断**，同一1454年实录句本身并未直接记录交付完成。

## AKS《韩国民族文化大百科全书》的独立署名现代解释

[《高丽史》条目](https://encykorea.aks.ac.kr/Article/E0003456)明示 **申安植／신안식** 编写于1995年、最后修改于2024年5月22日。条目将1454年广布归于后世《国朝宝鉴》《增补文献备考》，并叙述1455乙亥字印本。该条目明确说明文字属于署名学者的学术意见，不能代替两部后世史书具体原叶、印成或领受文书。

## 证据裁决

- 1452印书奏准、1454此前少印仅藏内府及再次批准、1469再请颁行都是不同时间的**官方实录转录事件**，不得与已完成印刷或流通混同。
- 13C奎章阁、13D AKS 和NIKH对1454年的现代学术说法，即使多个机构重述，也不能叠加成几份独立1454年原始印本票。NIKH网页/PDF还是同一著作。
- 《高丽史》139工作卷与任一馆藏75/85/33实体册不能混为一类计数。AKS所写75册不得通用于所有物理版本。
- 卷52实物册号及D16/D18古原叶仍空缺；1454打印完成日期、交付批次和纸本印次同样未决。
