# 天问 13KW：13KU 引文来源归属前向勘误

## 需纠正的旧记录

13KU 在 `docs/research/TIANWEN-13KU-MINGSHI-V35-FOUR-PHASE-RETURN-AND-RECEIVED-OPERATOR-R1.json` 的 `received_operator.source_id` 将来源指向通行的 [《明史》卷35](https://zh.wikisource.org/wiki/明史/卷35)，而其 `operative_phrase` 旧值中的首句是「推遲疾限　各置遲疾歷」。**此处来源和引语并不一致**：截至本批复查，实际该通行电子页是「推遲疾限　各置遲次歷」，而 [《明史（四庫全書本）》卷035](https://zh.wikisource.org/wiki/明史_(四庫全書本)/卷035) 电子转录则写「各置遲疾歴」。

本项目因此采用 **FORWARD_ONLY_SOURCE_ATTRIBUTION_ERRATUM**：保留原 13KU JSON 和 Markdown 不变，在新的 13KW 证据 JSON 中逐字冻结旧引、真实通行页读法、另一本电子页读法、来源链接和纠正原因；从此不再把 13KU 的「遲疾歷」说成普通页面的精确原文。

## 作用域与影响

本勘误仅纠正 **电子转录出处归属**，无任何新原书扫描字形、实物版本、历史发明者或抄袭关系证明。13KU 已经确证的有理数四相位算术 `4×90.06830865−2×168.083060=24.1071146` 不变。13KV 所保留的 13 朔策 `238977.09/288977.09` 数值异文同样继续悬而未决，不能把电子页面不同误算为古代独立实物见证。

优先行动仍是哈佛 v11 原书第7—12页及四库对应原页的源图和坐标核验。研究缺漏台账 `TW-OPEN-0005` 保持 P0/OPEN；根源647、扩展118、总765，Matrix222、图谱252/238、11项风险不结案，排盘 R1 保持 CLOSED。
