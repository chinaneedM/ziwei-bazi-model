# 天问 13MR｜周相 1569《大明大统历法》：原版推算语句与数表字段的限定校勘

## 原页及本批实际取证

在公开原版影印 PDF [卷六](https://www.kotenmon.com/cal/arabe/vol6.pdf) 直接查看 **PDF 第14、15、16页**（第14页为原表前页，第15页是连续日次，第16页是后续日次）。未进行 OCR。本批沿用先前 13MK/13MQ 已登记的 **同一份** 45页数字对象，已归档源 PDF SHA-256 `4c006b7ce131902fe33012d42f62cd2bbc2140affa3d5886e0da02966352cb7c`。本轮通过公开展示页面作目视复核，**没有重新下载整份 PDF 字节、重新计算来源 SHA 或原始像素 SHA**，不得把既存归档校验当作本轮新增哈希实测。

第14页源印右幅「**推盈縮差度分法**」中可辨的连续算法语义为：
- 「其積日下盈縮加分乘之得數」
- 「復加其下盈縮積度全分」

这说明**该卷本身**区分「積日」「盈縮加分」「盈縮積度」作为运算中的不同角色。第14页左幅另有「**太陽冬至前後立成卷第二**」的数表标题，第15页接续第十五、十六、十七日表行；第16页继续日次。因此可将这段文字视为**同一来源内部的操作语境**，但还不等于已在原像素上把每一条印刷纵列对应到各名称及位制。

## 与 G893 的严格对读边界

## 不得越权的四个边界

- 周相 p14 表名、操作语句存在，并不证明 p15 第二数栏是同名 **盈縮積度** 的哪一个具体数位；仍需原像素中列线、承前省字、表首至第15日的严格几何索引。
- G893 `001a` 版面可见 **少**，不能直接改写为其他书印出的 **微**；术语与实数换算必须逐版证明。
- 1569 为资料题识/版本描述的历史年份，不等于这次数字影像所摄特定**物理印次**已认证，更不是 PDF 的制作日期。
