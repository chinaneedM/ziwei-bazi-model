# 天问 13B｜《高丽史》首印与流布日期：奎章阁现代解题对 1454 年实录的证据边界

本轮新增的是**馆方现代历史解释的年代分歧**，不是取得古籍原叶。沿用 12ZP 原文校勘，不覆盖先前来源记录。

## 第一方现代解题

首尔大学奎章阁[GK03269 基本解题](https://kyudb.snu.ac.kr/book/view.do?book_cd=GK03269_00&notes=basic)对全书形成过程提出：1452年12月似已印出，但无法确定活字还是木版；1453年10月癸酉靖难后似广泛颁布，但该最初印本已不存。韩文原句及限缩判断保存在同批 JSON。此处解释文字出现在**奎3269的书目网页**，不意味着其实体奎3269即1452年的原印本，也不能并入奎貴3539（1613年太白山实物）。

## 与当时官方记录核对

- 1452-11-28《端宗实录》「春秋館啓請印《高麗史》, 從之」：只证明请求获准，未证明12月完成。
- 1454-10-13《端宗实录》「《全史》則少印, 只藏內府」且又奏请「印《全史》廣布」：当时报告的既往状态为宫中少量印本，新准印颁并非已完成。此记录与1453年10月后即已“广泛流布”的回溯推测有**证据张力**，但目前不能把馆方推测简单定性为错误或把新批准误作实物交付。
- 1448年前身《权草／红衣草／全文》另属版本，不可算1451最终本的印出时间。
