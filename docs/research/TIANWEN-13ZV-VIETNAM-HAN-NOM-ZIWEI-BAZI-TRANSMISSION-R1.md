# 天问 13ZV｜越南汉喃本紫微斗数与八字材料

越南馆藏可分见以喃字传授紫微的文本、以生辰八字为题的占书，以及近现代子平典籍的越译著录。第一轮按馆藏号核实对象、文字和用途，区分馆目（B）、学者报告（C）与仍待原叶确认的判断（D）。
