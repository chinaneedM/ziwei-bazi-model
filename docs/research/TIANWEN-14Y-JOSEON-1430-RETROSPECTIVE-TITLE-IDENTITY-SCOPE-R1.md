# 天问 14Y｜1430 朝鲜取才短题与后出《三車一覽》《紫微數》释名的边界

核验日：2026-11-19。续接 14X，本批为**现代学术百科与既有原史录、馆目、原页之间的书目年代分层**。没有取得乙亥字《紫微数》新增原叶、高丽大学三册本〈繼善篇〉或其刊记原影；不得据现代释名推定1430年实际试书身份。

## 来源、年代与物理实物四层

1. **1430 同时代题名层（C）**：[《世宗实录》世宗十二年三月十八日](https://sillok.history.go.kr/id/kda_11203018_002)官方史录的现代数字转录列《紫微數》《三車一覽》为阴阳学取才书目，未交代两书作者、卷数、具体刻本、原文规则和师承。
2. **《三車一覽》后出学术释名层（现代二级）**：[韩国学中央研究院 Sillokwiki〈삼거일람(三車一覽)〉](https://dh.aks.ac.kr/sillokwiki/index.php/%EC%82%BC%EA%B1%B0%EC%9D%BC%EB%9E%8C(%E4%B8%89%E8%BB%8A%E4%B8%80%E8%A6%BD))，署李秀東（이수동），将1430取才简称与徐大昇《新編三車一覽子平淵源註解》并列解释，并列三卷、1518年、金属活字及高丽大学馆藏；其正文报告1517冬序、1518秋熊上恩刊行。此为**近现代学者回溯性的书目识别和序刊记转述**，不是1430原书的页图或当年同版证明。
3. **高丽大学书目层（B）**：[天册](https://dcollection.korea.ac.kr/srch/srchDetail/000000134095)与[人册](https://dcollection.korea.ac.kr/srch/srchDetail/000000134097)为同一三册馆藏；人册馆目列〈繼善篇〉。1518年的刊记报告不等于当前乙亥字实物印制年份已获原叶确认，天、人册不能计为两份独立古本。
4. **《紫微數》后出学术释名层（已有来源复用）**：[Sillokwiki〈자미수(紫微數)〉](https://dh.aks.ac.kr/sillokwiki/index.php/%EC%9E%90%EB%AF%B8%EC%88%98(%E7%B4%AB%E5%BE%AE%E6%95%B8))同署李秀東，既引用1430取才名目，又著录汉阳大学藏1870年明經閣六卷六册《新刻合倂十八飛星策天紫微斗數全集》及传统陈抟题署。该1870文献入口已在根源注册为 `EXT-AKS-SILLOKWIKI-HANYANG-MINGJINGGE-ZWDSQJ-HOLDING`，此次不重复增加来源；它不是1430试书实物，更不能用题署证明陈抟亲撰该卷本文字。

## 既核原页与不成立的跨年等同

14W 已有英国图书馆方谦之**十卷**《三車一覽命書詳論》第一册原页、所载1261年序及〈論四柱〉。1261是序年而非该乙亥字印本确切印年；其同名简称与高丽大学徐氏**三卷**本不自动同一，亦无同期证据能证明1430用书一定就是其中之一。

14W 又用《玄藪》p57–61原影的木三局起卯、太极在巳、天库在丑，重放韩国国图乙亥字《紫微数》一幅原盘，说明可比较的技术操作，**不证明同一实物、抄印方向或1430与1870的传承**。乙亥字残本数字号 `CNTS-00109610231` 的〈定十二宮〉、〈起天數／地數〉目标篇叶尚未核得。

## 限定性结论

- 可证：1430两短题见于史录转录；现代百科分别用后来藏本解释这些书名；现有方氏十卷本、徐氏三卷本、1870明經閣六卷本是不同作品或版本层的实际书目对象。
- 不可证：1518熊氏特定刊本已在1430使用；1870明經閣本是1430紫微官署教材的同版；晚出署名证明古代作者、抄袭关系或机械规则首创。
- 未决：1430三車短题对应方氏、徐氏早期前身或其他作品；1430紫微短题与乙亥字残本、《玄藪》之间的文本身份、印年与承袭。
