# 12VD — 《靜志居詩話》近似「惜其書未刊行」語境隔離

本輪對照四川大學期刊社所載庞石帚1959年〈跋《萬曆野獲編》〉[摘要](https://journal.scu.edu.cn/info/1109/11943.htm)、[《靜志居詩話》卷十七〈沈德符〉受本文字](https://ccddb.net/靜志居詩話/卷十七/沈德符)及[卷二十三〈釋子·道源〉受本文字](https://ccddb.net/靜志居詩話/卷二十三/釋子/道源)。

**新發現（有限）：** 卷二十三道源條有「惜其書未刊行」，緊承道源（石林）注李義山詩三卷的敘述；1959摘要引為朱彝尊評《萬曆野獲編》的「惜其书未刊行于世」。二者語詞相近，**尾語不同、文本主語和所指著作不同**。卷十七沈德符條則記「所撰萬歷野獲編，事有左證，論無偏黨」，在該公開條目內未見1959所引完整語句。這是一個可檢查的**近似詞句易錯指稱對照點**，不是「找到1959原引文」或「證明其誤引」。

史料等級：兩條 CCddb 是公開接受本文字，非已見之1819扶荔山房實物葉；1959是期刊摘要而非已核全文。因此不把卷二十三文字搬移到卷十七，不推斷庞氏抄錯／朱彝尊原稿差異／版本間直接傳抄，也不裁定明刻本存否。日後須原頁圖像、卷葉、物理版本與1959正文完整引證鏈。
