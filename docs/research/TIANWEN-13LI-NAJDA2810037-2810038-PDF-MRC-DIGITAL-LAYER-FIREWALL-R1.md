# 天问 13LI｜《明史》卷35两份日本国档 PDF 的 MRC 数字图层鉴别

本批发现上批 SIFT 校勘的一个**证据介质限制**：两份 NAAJ 数字替身都由 `LuraDocument.jpm v2.05` 制作，PDF 页6并不是一张单一原始相机照片，而是复合彩色与文字黑白遮罩的多层格式。此结论来自 SHA256 验证的 281-0037 第10册与 281-0038 第11册 PDF 本体的 /Image 元对象；不依赖 OCR 或现代转录。

| 项目（原PDF第6页） | NAAJ 281-0037 | NAAJ 281-0038 |
|---|---|---|
| 原数字对象 SHA256 | `8892b16c...` | `73322281...` |
| 数字文件生成时间 | 2016-02-13（PDF metadata） | 2015-01-16（PDF metadata） |
| 彩色背景 JPX | 2100 × 1484, 8-bit RGB | 2067 × 1500, 8-bit RGB |
| 黑白文字遮罩 JBIG2 | 6300 × 4450, 1-bit | 6200 × 4500, 1-bit |
| 彩色前景 JPX | 2100 × 1484, 8-bit RGB，SMask 引用遮罩 | 2067 × 1500, 8-bit RGB，SMask 引用遮罩 |
| 遮罩整幅解码灰度 SHA256 | `a1816429...d081b` | `5d1c5e28...5193` |

两本页6均以 xref **32** / **33** / **34** 分别存放背景、文字遮罩、前景，文字遮罩采用 `JBIG2Decode`，并用于前景的 `/SMask`。PDF 制作时间**不是**古籍物理印次年。

**推断防火墙：** 解码文字遮罩像素较多，并不自动等于古书页面的光学摄影分辨率；JBIG2 可以采用阈值化、分割和依编码器选项而定的字形复用/替代。当前**没有证据证明这两份 PDF 实际发生了错误字形替换**，同样不能宣称解码图已完整保留了刻版裂损的原生物理细节。若以文字遮罩中的某个缺笔断定两本共版，可能把数字化处理痕迹误当作雕版缺陷。

13LH 第6/7页 SIFT 一致性结论仍保留为**局部版面/字形几何高度兼容**，但版片相同、确切乾隆印次、图谱直接传承边依然 **UNPROVEN**。二本原页同读 **238977.09**，CADAL《四库》独立原页 **288977.09** 继续并列，不按票数裁决，不改排盘。

本批首次把 PDF **复合层**、**源摄影图**与**实体刻版**三种证据级别剥离。目标后续是取得馆方原始未分层照片，或进行彩色背景/黑白遮罩的同一缺笔双层核对，严格标注数字分割带来的歧义。
