# 12UI — 筑波大学、国立国会图书馆复制服务与原刻证据门禁

本批只校准 12UH 两条独立馆藏的实际复制途径，**没有原叶、没有字形投票、没有任何申请或付款**。

## 筑波大学卷20（BA62912433 / 10076865665）

- [馆方线装古书全页复制规程](https://www.tulips.tsukuba.ac.jp/lib/ja/visitor/waso)：已有数字化或缩微副本应优先核查；未数字化／未缩微线装古书不接受通常局部复制，而是外包**全页数字化**；个人申请不受理，须经大学或公共图书馆提交。公开价格为税前基本5000日元、国内运送手续费1000、黑白每切150或彩色每切300日元。**该书未知切数、未知适格性、没有馆方个案报价，也没有支付。**
- [馆方ILL规程](https://www.tulips.tsukuba.ac.jp/lib/ja/visitor/ill)：图书馆间请求按资料类别办理；和装古书原则上不出借，已有缩微可按缩微复制，未有者转全页规程。
- [馆方古典资料规程](https://www.tulips.tsukuba.ac.jp/lib/ja/collection/guide-koten)：必须先查OPAC具体资料类型、是否已有电子图像，必要时再进入古典资料室申请。由该书目录出现卷20编号，**不能推出该编号对应影像已公开或必可申请部分扫描**。

**前瞻校正12UH**：原12UH建议“申请限定目标叶数”只是期望研究范围，并未证明此馆对此未扫描和装古书允许按几叶定价。若属未扫描物件应按馆方整册规程处理；先核实当前馆目数字影像、缩微及具体分类，不把计划路线说成可执行申请。

## NDL馆藏 184-65（书目000007607208）

[NDL Search第一方远程复制规则](https://ndlsearch.ndl.go.jp/en/help/remotecopy) 支持按明确书名、文章或页次指定研究复制，注册者或馆际参与者办理；珍贵古籍可能额外邮寄特别复制许可，馆方优先用已存缩微／数字文件以保护原件。公开服务规则≠证明该馆这本184-65已经扫描或有卷20页面、更不表示收到复制后可确认1700年原印次。先定位卷20条目及版心或申请馆方页次协助，避免交费后只有无身份链的派生页。
