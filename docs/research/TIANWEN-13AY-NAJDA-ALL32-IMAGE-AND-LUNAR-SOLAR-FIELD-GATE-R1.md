# 天问 13AY｜《高麗史》物理第52册32幅馆方原图与太阳／太阴表分流

**核心结论：** [日本国立公文书馆《高麗史５２》](https://www.digital.archives.go.jp/img/en/4898854) 所有32幅公开 IIIF JPEG 已从 [13AY GitHub Actions](https://github.com/chinaneedM/ziwei-bazi-model/actions/runs/39408552959) 四组独立取回，逐件JPEG魔数与SHA256校验共32/32通过，总31,952,791字节。源Manifest SHA256 `a7ef9f1d7953eca9c44168dee0f482f2a408ca1a18a093410b0b5c1da221f7d2`。生成的是3000×2215馆方 JPEG 影像，不得称作原生6500×4800 JP2。

机器证据 `docs/research/TIANWEN-13AY-NAJDA-ALL32-IMAGE-AND-LUNAR-SOLAR-FIELD-GATE-R1.json` 保留四份原始ZIP artifact编号、ZIP SHA及直接重点原页SHA；各artifacts自带32幅独立`result.json`的原图SHA清单，原样馆方Manifest和源JPEG，能够重放。只做**全32幅缩览和五幅重点全页视觉复核**，不是逐字穷尽校勘，不证明全书或其他物理册不存在目标条文。

- 原图第3幅起数表已排至「十二」，后经第4幅「十六」等顺序至第24幅「一百六十八」；第24幅紧接原字「五星立成」「木星」。和传世《高麗史》卷五十二 **太陰限數遲疾度** 0..168限、随后五星立成的顺序符合。这组 **「十六」是太阴限序号，不是太阳冬至表的第十六日**。这是前轮“十六”含混归属的直接源页纠偏，不授权推断某数字原字就是太阳D16。
- 第27幅可见「土星」，第29幅「水星」，第31幅卷尾「志卷第六」。全部仍是同一物理册，绝不多算历史独立票。
- 韩国国史编纂委员会现行数字正文的太阳冬至表第15/16/17日分别为「五分二一七六／五分一三六二／五分二五四八」，属于**现代转录文本**；这一表在文本次序上位于此册可见太阴后段以前，却**未在本次32幅图原页中直接看到其目标字形**。不能将现代D16的「一」自动判成历史原版，而G893同栏「二」原字仍保留。
- 原始NAJ馆方索引另有 [高麗史５１](https://www.digital.archives.go.jp/item/en/4898853) 的 **source-emitted** 物品链接。仍未知实物第51册的正文起止、是否延续卷五十二前段、是否包含太阳原表；其图像和目标字形尚未获取。下一轮优先原馆 item→Browse→Manifest→末页/交界原图，不猜物品id或API。
