# 天问12ZM｜奎章阁专题馆藏表：5553卷81–83、3467卷52与1972影印的三角核对

## 一、第一方专题表给出实物册与作品卷的绑定

韩国首尔大学奎章阁官方专题“[5. 王室의 歷史敍述 - 1) 正史의 편찬](https://kyudb.snu.ac.kr/brd/viewBrd.do?book_cate=HEJ23&focus=d11sd114&listChk=tree&menuId=10022&mid=HEJ&postSeq=10775&siteCd=DBSP)”（署名 정재훈）在“[표 1] 규장각 소장 『고려사』”明确列出如下本馆表述（第一方解释性目录而非原书页图）：

- 奎5553 **第8册 = 卷19–21**；**第26册 = 卷73、74**；**第29册 = 卷81–83**，三册为后补抄本。
- 奎3467 **第6册 = 卷52**，列于“部分乙亥字本”之下；不能移植为奎5554第6册，更不能声明已读取奎3467卷52历表原字。
- 奎5554只列为残存**32册乙亥字本**；专题表没有给出该件卷52精确实存册号、原叶和影像。

这项机构页面与[奎5553独立项目目录](https://kyudb.snu.ac.kr/book/view.do?book_cd=GK05553_00)中第8/26/29册补写说明一致，更重要的是把**第29册实质绑定卷81–83**。相比12ZL只存3个册号，新增一条可追溯馆内卷册交叉绑定。

## 二、卷81、82可用于未来检验现代影印底本选择，但还不是原件

2021年[遗产说明二次转载](https://7390882.tistory.com/entry/보물-2114호)称5554乙亥字卷81、82可弥补5553缺少的原铸字页，却同时把5553第三个补写册记成第12册/卷31–33。这与奎章阁两份现行页面第29册/卷81–83不一致；没有旧版馆目、遗产正文物理级对照或具体实册，不可把某一支称为历史错误原因已明。

魏志江、陈卓[2020年研究论文](https://sir.sysu.edu.cn/sites/default/files/2026-07/%E9%AB%98%E4%B8%BD%E5%8F%B2_%E7%89%88%E6%9C%AC%E6%BA%90%E6%B5%81%E4%B8%8E%E7%BC%96%E7%BA%82%E4%BD%93%E4%BE%8B%E8%80%83_%E9%AD%8F%E5%BF%97%E6%B1%9F.pdf)（印刷页100/PDF第8页，已核对该PDF的目标页）称1972年现代影印以5554为底本却用木刻页填补包括卷81、82在内的部分卷。因此**同一个作品卷号81、82至少同时牵涉5553抄补本、5554可能的活字本、1972编辑选入的木刻本三个不同版本层**。这是一组很好的未来原图校核对照坐标，**不是**三份都已直接观测的同文古籍物证，也不证明某件原刻本校勘优劣。

## 三、未解决界限与下一步

奎3467卷52的“第6册”属于单独馆藏对象；奎5554卷52仍无实册编号、D16/D18原刻页或 SHA。5553的第12/29册矛盾仍开放；原件新投票0、G893源内5/6与跨独立物理本0/6、11项研究遗漏开放，Matrix222/222，来源注册647+59=706、图谱252节点238边、确定性排盘封版、算法重开0。
