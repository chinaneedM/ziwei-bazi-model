**本轮取得一项原图肯定证据，但没有取得夏至 D28「行度」数值。** 从 GitHub Actions 已封存的 13DT/13DU 原图工件，人工无 OCR 重新核对 p82、p83、p86：p82 可见「九十二」「九十三」数字列与「限」解释段，p83 顶端重新按右至左列「一」至「八」，p86 可见「二十七」「二十八」「二十九」。这些是源页的正面见证，不等同三种不同抄本。

## 新的跨栏结构实证

13DU 第86页「二十八」原生 RGB 裁区 SHA-256 `4aa02c6a50b2cc9a6e9259396b9a2af1f5989fb3561adf2638f3f5194c44f2a1`、原 PNG SHA-256 `5428823bed7f7b25fce08fae873583cdd3ae01b4717ac5a396cb81da86f30167`，右至左单位行可见「日／分／度／度」。此数列是并列**多个纵列**而非一个孤立数值串。源裁区边缘还可夹入相邻日的列头；因此从「D28」标题到某一内部数值列的同一字段身份，尚须另外绑定整表名称、栏位语义与精确 bbox。

本批的文字肯定判读仅是「二十八」及单位行「日／分／度／度」；**不声称 p86 已印出或否定任何特定「初度九十九四五四九」「初度九十六四五四九」**。即使早稻田、NAJ 原图在各自印出日次 D29 皆见 0.994549，而 1909 印本在 D28 见 0.994549，也不能把这个数直接迁入 NCL03130 的 D28。
