# 天问 13JT｜1972《高丽史》混合影印的十卷／十二卷补版清单差异

本批对照韩国学中央研究院《韩国民族文化大百科全书》的《高丽史》条目与项目 **12ZL 已保存的魏志江、陈卓2020年版本学研究**，另以韩国国史编纂委员会《高丽史》全书目录作卷号标准。**双方差别不是直接的“志卷”与“全书卷”同名冲突；换算后仍有两条实际不一致：卷78、卷82。**

## 1. 可复核来源与换算

- [韩国学中央研究院百科条目](https://encykorea.aks.ac.kr/Article/E0003456) 的“서지적 사항”列1972亚细亚文化社影印本之木板补版：**世家19、20、21、31；志27、28、31、33、35、37**。条目2024-05-22修订。此为学术百科文字，不是1972影印本原图。
- 12ZL 已登记的魏志江、陈卓《高丽史》版本源流研究（《史学史研究》2020年第1期第100页）记1972该本的补版全书卷次为 **19、20、21、31、73、74、77、78、79、81、82、83**（共12卷）。该历史文件保持不可变。
- [韩国国史编纂委员会《高丽史》官方目录](https://db.history.go.kr/goryeo/itemLevelKrList.do?levelId=kr_054r_0010_0010_0050) 将全书1–46卷列“世家”，全书47–85卷列“志1–39”。故按**全书卷号 = 志内部卷号 + 46**机械换算。官方目录明确列出全书卷78为志32食货一，卷82为志36兵二；这是作品目录结构而不是1972影印具体页的来源证明。
