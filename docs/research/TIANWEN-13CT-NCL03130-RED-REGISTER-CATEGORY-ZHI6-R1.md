# 天问 13CT｜03130书首朱笔“世家少、志少、传少”局部直读与志第六映射

**本批新证据不是另一本古籍，而是13CS已获取的同一份公开镜像第一页分件的高清第7页。** GitHub Actions 运行 [39773078687](https://github.com/chinaneedM/ziwei-bazi-model/actions/runs/39773078687)，artifact `12423406394`，源204页 PDF SHA-256 `24fb9612634ba085d2546ba6c1f02305aa2a02b9ddfd02f0b645ba0409b5e01e`。高清 `front-page-007.png` 的 SHA-256 是 `baa5ab0199a41af85ee6a5290601d15390a7faf7ea2c247b0cdd8e7867dee456`，原渲染尺寸1474×974；朱笔局部约为像素 `x905–1155, y90–800`。可依来源SHA、GitHub artifact、PDF页号与图片SHA复核。全程**直接视觉阅图、未OCR**。

## 1. 直接视觉阅图的新增内容

右侧空白页朱笔至少可辨认分类标题及缺少语素：**「世家少…」「志少…」「傳少…」**，每组后有朱书的卷数／数字形态。13CS仅确认“第7页有红字”，本批将这一局部提升为 **书首按体裁列缺卷的原页候选**，与Commons书目转录的「缺卷朱記于首」位置、功能互相吻合。但这里没有完成逐字、逐数对校，未以书目转录代替原字，也未以相符题意证明吴重熹本人即为每笔朱书的作者。

**重要限制：朱字中每项具体卷次尚未可靠读全；不得说“志第六在缺表内”，也不得用“不见六字”推定不缺。** 此处报告的只是单一数字镜像的页面直接视觉现象，不能再多计一次古本见证。

## 2. 将全书卷五十二归到正确的局部卷数

韩国国史编纂委员会《高丽史》[官方原文](https://db.history.go.kr/goryeo/itemLevelKrList.do?parentId=kr_052_0010_0010_0010&types=o) 明列 **「志卷第六 高麗史五十二」「曆三 授時曆經下」**，且有《授時曆立成》目标。故下一次必须核对朱书 `志少` 后是否写有**该体裁内部的第六卷（志六）**，不是漫无目标在三组里寻找阿拉伯52，也不能混用物理分件编号、全书卷号和「志」局部编号。

该当代数据库是确定**收本文本结构映射**的官方资料，但不是03130缺卷朱笔、清初旧钞年代或1905补钞字形的直接证据。

## 3. 未决和冻结项

- p7朱字是**疑似具有缺卷登记功能的直接原页**；所有具体卷次，特别是志六，仍 `UNRESOLVED`。NCL第一方208/03130到Commons影像的链路仍 `UNBOUND`。
- 全书卷52具体实叶是清初旧钞、1905补钞还是更复杂层次仍 `UNBOUND`。第01件不等于40实体册中的第一册，也不等于存有卷52的册件。
- 两份已核原物 D16 日差均印 **5.1362**；由邻日差分推得的 **5.2362** 仍只是数学猜校，不能反写前者。
- 研究风险仍11项OPEN/BLOCKED、Matrix222/222、来源754、传承图252节点/238边；R1排盘 `CLOSED`，零算法重开。

本批由 **13CS的“仅见红色批注”进展到“朱书体裁缺卷标记 + 官方卷号映射”**，但**未解决志六是否列缺，更没有得到第三份历史数值见证**。后续只应围绕朱笔 `志少` 的数字进行高置信度两人独立校录，再通过实物／馆方记录复核作者、印次、书册及原叶。
