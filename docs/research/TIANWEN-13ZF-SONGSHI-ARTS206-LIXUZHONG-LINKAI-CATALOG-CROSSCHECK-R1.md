# 天问 13ZF — 《宋史》卷206《艺文志五》与宋代命书异名异卷交叉核对

日期：2026-11-16。研究阶段：双术数历史骨架广度优先。证据级别 **C（后出正史/接受文本）**；此批未取得元代《宋史》原刻、宋代《郡斋》《通志》原叶，亦未证明任何唐代完整四柱机械规则。严格区分**正史编纂时代**、**其记录的前代著作**、**当前网络转录时代**。

## 一、核对位置与逐项发现

1. 《宋史》卷二百六、志第一百五十九《艺文五》“五行”类，维基文库可读转录，条文直接并列 **李虚中《命书格局》二卷**、**《珞录子赋》一卷**、李吉甫《三命行年韬钤秘密》二卷、元兢《禄命厄会经》一卷、杨龙光《禄命厄运歌》一卷（同一分类中的邻近著录）。定位：https://zh.wikisource.org/wiki/宋史/卷206#五行 ，页面五行类前段。这里是**元修《宋史》的后出著录见证**，不是宋代原书或操作术式。
2. 同卷“五行”类较后段见 **林开《五命秘诀》五卷**，并列文靖《通玄五命新括》三卷、董子平《太阴三命秘诀》一卷、何朝《命术》一卷、李蒸《三命九中歌》一卷等。参同页五行类后段。此处的“五卷”与已经在13ZE逐条登记的《郡斋读书志》卷十四、郑樵《通志·艺文略》所见 **林开《五命秘诀》一卷**存在明确**目录卷数差异**，尚无依据判断是分卷方法不同、节本、不同版本、目录误记还是异文。仅登记 **CATALOG_COUNT_VARIANT_UNRESOLVED**。
3. 《郡斋读书志》卷十四著录 **《李虚中命书》三卷**；《通志·艺文略》著录 **《李虚中命术》一卷、《李虚中命书补遗》一卷**；《宋史》另作 **《命书格局》二卷**。这些书目共同构成“李虚中名下**三卷／二卷／一卷＋补遗**”的不同见证。**书名相近并不足以认定实为同一作品，也不足以证明真实作者为唐人李虚中。**对照前批13ZE。
4. 《新唐书》卷五十九《艺文志三》明确设“五行”类；本次检视可读传本的分类结构，未取得能把其中某条命书认作**李虚中所作四柱全套原书**的直接证明。对旧《四库总目》“唐书艺文志亦无是书”仅补一个**复核入口**，不作全目录所有别名的穷尽否定。入口：https://zh.wikisource.org/wiki/新唐书/卷059 。

## 三、研究意义与下一步

- 新增的是**宋命书历史著录网络**，不是三条独立传授链。尤其《宋史》对“林开五卷”与《郡斋》《通志》对“一卷”的分歧，应在未来**目录版本/印次对勘**中保留；现在不建立“宋代某师承→后世子平”的确定传承边。
- 对紫微史纲不造对称性新发现；其**明前文献断层及明清三作品家族**仍是并行优先空白。
- 后续应核《宋史》早期印本与《新唐书》卷59五行类的可靠版影；并转入宋元→明《渊海子平》作品层/版次层、紫微民国出版锚点和地域传播的广度补证。
