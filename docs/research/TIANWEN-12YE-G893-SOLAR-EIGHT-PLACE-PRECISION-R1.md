# 天问 12YE — G893 原印八位小数与四位截断的区别

原件仍是奎章阁奎貴893 / GK00893_00 的同一份《授時曆立成》。本轮重新取得此前留档的 **33,525,981 字节**原图包，确认 ZIP SHA-256 `ee9ecf1de3bb6abe5678e0f8ec8383ef985051e77d091ee40840756e57081107`、CRC 及 **204/204** 张馆方原始 JPEG SHA-256 一致；直接查看 `001a` 表头与 `002b` 第十五、十六、十七日，未使用 OCR，也没有增加古籍物理见证。配套 JSON 记录两张原页摘要，以及三个逐列、一个邻接双列的 RGB 原生像素 ROI SHA-256。

| 日次 | 原页纵列完整原字 | 十进制字面候选 | 前批12YD的四位前缀 |
|---|---|---|---|
| 十五日 | 五分二一七六八二四九 | 5.21768249 | 5.2176 |
| 十六日 | 五分二三六二六〇七三 | 5.23626073 | 5.2362 |
| 十七日 | 五分二五四八三七一一 | 5.25483711 | 5.2548 |

八位 Decimal 精确运算：`5.23626073 - 5.21768249 = 0.01857824`；`5.25483711 - 5.23626073 = 0.01857638`；二阶差为 **`-0.00000186`**。此前四位前缀的两段增量 `0.0186` 完全相等，**不能由此断言原书完整精度的日差恒定**。

这项同本正证值得继续核对原书表头 `日差加一秒八十六少`，但“秒”“少”的历法单位、表头与右/左两栏的实际对应、长栏进位、舍入及原印数字生成步骤尚未证明，**不能凭数形巧合建立同一公式**。明1569数表的「第二栏」与该列是否同字段、是否有直接抄传关系仍未决。六个主要直接目标字段保持 **5/6**，跨版本机械结论 **0/6**；研究遗漏问题 TW-OPEN-0005 为 P0 OPEN，确定性排盘 R1 仍 CLOSED。

12YD 的原四位字形存档保持不变。12YE 是同一原件更高精度的前瞻补证，不计算为第二份独立物证。下一步对照 D14—D18 相邻长栏的单位、进位和递推，再决定 D16 原目标字段是否满足同字段证明。
