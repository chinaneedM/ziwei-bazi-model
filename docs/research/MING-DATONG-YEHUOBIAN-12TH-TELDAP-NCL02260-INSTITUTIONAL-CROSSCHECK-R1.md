# 天问12TH｜台湾国图 02260 的机构级联合目录二次核验

本批直接从[中央研究院TELDAP／国图来源联合目录的02260馆藏对象](https://catalog.digitalarchives.tw/item/00/08/4f/4c.html)读取现存版本和物理对象信息，而非从Commons同页的二次转录中反复推导。联合目录对象544588明确：书号02260、舊鈔本、線裝、16冊，国图持有，匡框19.7×13.8厘米。[该馆藏分类列表](https://catalog.digitalarchives.tw/Organization/List.jsp?CID=6572&CShowPage=1&ShowPage=17)还在相邻条目单独列出书号02261、绿格钞本。

TELDAP 记录中所谓「连结到原始资料」此轮打开后进入 **NCL古籍检索总入口**，未解析出该单本的稳定书目详页；因此不能把它当作周星诒印章、手稿年代或〈改造漏刻〉篇章原字的新一票。周氏收藏印目前仍仅有NCL来源的Commons公开目录转录，未在本批直接审阅馆藏影像印模。

## 可执行的身份边界

- 02260 = 一件有书号的旧钞本；TELDAP登记与Commons托管影像是 **同一件馆藏的两个元数据／数字访问来源**，不是两个独立古籍版本。
- 02261 = 另一件「绿格钞本」馆藏；仅可在具体页文字比对后评估传承。
- 2019年杜学林将李慈铭所谓「明刊本」联系周星诒旧钞的解释仍为专业版本学 **学者论点**，没有从本轮联合目录记录升级为证明李慈铭亲阅 02260 的直接文献。
- 无1827未修本原页、1869修版原页或CADAL/1174共同拍摄底图的新增证明。原来源注册增加一条机构级目录定位，标记 BIBLIOGRAPHIC_METADATA_ONLY，物理字形权限 false。
- TELDAP网页可见的目录数据授权说明不代表可任意再发布原古籍扫描图像。此轮没有实际申请、下载或处理收费复制服务。
