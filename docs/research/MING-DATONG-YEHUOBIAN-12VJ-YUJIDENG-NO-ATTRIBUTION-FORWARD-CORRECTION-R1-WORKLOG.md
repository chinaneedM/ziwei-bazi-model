# 天问12VJ：前向更正——《皇明典故紀聞》卷十一并未把目标数表明署“彭德清奏”

**性质：训诂及来源归属更正；保留12VH/12VI历史原记录，不覆写当时见证。**

## 更正原因

12VH的机器记录把《皇明典故紀聞》卷十一的段落定位成 `卷十一彭德清奏摘要`，这是对文句归属的不当补足。

直接复核可公开读到的 [CText《皇明典故紀聞》卷十一](https://ctext.org/wiki.pl?chapter=349188&if=gb)：第91段“正統十二年，禮部右侍郎馬愉卒”的逸事之后，第92段独立以“南京北極出地三十六度；北京出地四十度強”起首，载北京冬至日出“辰初一刻”、夏至日入“戌初一刻”，第93段改叙郭璡。该目标段 **没有明写彭德清、奏、上言或奏准**。独立 [维基文库卷十一](https://zh.wikisource.org/wiki/皇明典故紀聞/卷十一)亦显示相同的相邻段落边界，但两个网站文字不能当作两份古刻本。

[《明英宗實錄》卷一百六十](https://ctext.org/wiki.pl?chapter=638064&if=gb) 的正统十二年十一月甲寅条，**另行明确**写“欽天監監正彭德清言”，并载北京日出入同一刻数。它是具备彭德清奏言归属的另一来源，不能把其句法主语嫁接到余继登文本。对应的 [《萬曆野獲編》〈改造漏刻〉CText收本](https://ctext.org/wiki.pl?chapter=418967&if=en) 明署彭德清，却记北京冬至“辰初二刻”、夏至“戌初二刻”。这些比较证明 **不同收本文字与表述边界并存**，但还不能证明谁抄谁、哪一个原刻正确。

另外，[识典古籍卷十一](https://www.shidianguji.com/zh/book/CADAL02047821/chapter/1l88x1ilkgzky) 的数字书目路由包含 `CADAL02047821` 标识，其目标段亦展示一刻读法；这一 URL 仍不是馆方原始影像、版次、原叶或 SHA256 绑定。不能从此推定其属于 NCL 02253、02254，也不能将现代电子转录提升为独立古本字形票。
