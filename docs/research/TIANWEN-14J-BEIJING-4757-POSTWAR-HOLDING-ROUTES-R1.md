# 天问 14J｜《紫微照膽經》4757 号钞本的战后馆藏分流路径

核查日期：2026-11-18。目的：为 [14I 旧目录原页核读](./TIANWEN-14I-XUDAOZANG-ZIWEI-ORIGINAL-LEAVES-R1.md) 所记录的《北京人文科學研究所藏書目錄》“《紫微照膽經》一卷／不著撰人／鈔本／4757”寻找**可核查的现代馆藏追索路径**。本批是机构档案和书目层研究，**未获得目标钞本原叶、现藏馆索书号、印记或原件图像**。

## 1. 旧号与对象等级不能跨越

- 1938—1939 年《北京人文科学研究所藏书目录》（续编下）原目录 PDF p59：一卷无名钞本的末号 4757。见 14I 哈希及原页记录 `docs/research/TIANWEN-14I-XUDAOZANG-ZIWEI-FOLIO-EVIDENCE-R1.json`。4757 只可当作**当时馆目旧编号**，绝不直接转换为当代馆藏号或作品成书年。
- 《文淵閣書目》后出传本录同题一部一册阙；《菉竹堂書目》后出传本另录一册。《续道藏》卷一内有〈照膽經四言十八飛星直指序〉，但**共享题名不能证明同书、同抄本或直接传承**。

## 2. 战后接收与两条现藏路径

| 时间／来源层 | 获得的可核对信息 | 保留的边界 |
|---|---|---|
| 1945-10 至 1946-08，学术研究回顾 | 研究记录1945年10月沈兼士接收相关机构藏书、1946年移交史语所；另一篇日文学术研究细列1945-10-05移交和1946-08-01再移交。 | 机构批次层历史，不是4757件的移交凭证。 |
| 1947–1949，傅斯年图书馆路径 | 《中正汉学研究》文章转引馆藏研究，记1947年底张政烺挑选1,400余种、约万余册转运南京，1949随史语所迁台。 | 文章脚注特别说明：傅图的另一官方统计仅称挑选**700余种**；两说有冲突，均保留，不选择单一数字。 |
| 1950 起，中国科学院文献情报中心路径 | 2019年《中国科学报》对馆藏工作人员的采访，称其余古籍由1950年成立的中国科学院图书馆接收。 | 新闻访谈是机构层转藏线索，未查到4757的具体移交清单或当代索书号。 |

**学术来源 A（出版史、转运数字及冲突）：** 《傅斯年圖書館藏黃嘉善本〈古今書刻〉研究》，《中正漢學研究》PDF pp106–107（PDF实际页码与印刷页码应分开核），[公开论文](https://ccjournal.ccu.edu.tw/var/file/58/1058/img/173/34_05.pdf)。文章正文与脚注34均须一起读；它的个案是《古今書刻》，**不能把此书具体流转直接套给4757**。

**学术来源 B（两次机构交接的时间线）：** 猪俣貴幸《中央研究院傅斯年圖書館藏明鈔本「條例全文」殘本三種について》，《立命館東洋史学》第43号，印页61–62；[论文 PDF](https://ritsumei.repo.nii.ac.jp/record/14575/files/eah_43_inomata.pdf)。实际校核的实物为条例抄本，非照胆经。史语所馆藏印章范例提供未来物件身份比对线索，但不证明4757具有同样藏印。

**访谈来源 C（大陆余藏路径）：** 袁一雪《鲜为人知的古籍“宝库”》，《中国科学报》2019-01-04，第5版，[原报网页版](https://news.sciencenet.cn/sbhtmlnews/2019/1/342384.shtm)。其“剩余藏书”所涉批次需要用原接收清单逐件核验。

## 3. 可查的免费馆目入口（未取得目标条目）

1. **傅斯年图书馆**：其[善本古籍资料库官方介绍](https://dap.ihp.sinica.edu.tw/database/1/)确认提供书目检索与影像浏览；但本批**没有可复述的《紫微照膽經》目标结果**。站点列有账号申请入口，不视为已授权登录或可免费远程复制。
2. **中国科学院文献情报中心**：国家图书馆出版社第一方[2022《古籍普查登记目录》全五册书目](https://www.nlcpress.com/ProductView.aspx?Id=11748)，说明收录1912年前古籍四万余条，含书名、馆藏号、版本和存卷；该出版社页**未公开4757对应项**。本项目不购买付费书籍，不把“目录可购”写成已读目录正文。

## 4. 对早期紫微史的有效增量与待判问题

当前**证实的是历史目录、机构批次转藏路径和当代目录入口**，不是实物存在于具体馆的肯定定位。需要分别从两条路径查询“紫微照膽經／紫微照胆经／照膽經”、一卷、无撰人、旧号4757，优先寻找馆方公开书目记录、旧藏印影、1945–47 移交/择选名册、卷端与卷尾。若查到对象，再与《续道藏》卷一 p27–32 的〈照膽經四言十八飛星直指序〉及其十八飞星、天杖安命和紫微起例逐条比较。
