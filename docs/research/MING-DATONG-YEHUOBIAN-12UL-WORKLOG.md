# 12UL — 京都大学《野获编》CiNii目录“康熙30年[1700]”不合纪年

## 一、冲突定位

[京都 CiNii BB18578034](https://ci.nii.ac.jp/ncid/BB18578034) 对扶荔山房道光七年《野獲編》记载：「萬厯34年[1606]の[自]序, **康熙30年[1700]の凡例あり**」。其中**康熙三十年=1691，康熙三十九年（庚辰）=1700**，两者不能同时成立。[国立台湾文学馆正式年表](https://db.nmtl.gov.tw/site2/chronology)直接列出 1691/30 与1700/39。书目本身发生纪年矛盾，是可确证的**目录层元数据不一致**。

## 二、既有原影像已提供更强的年月对照

回溯本库 12QF 原影像证据 `docs/research/MING-DATONG-YEHUOBIAN-12QF-CADAL-FIRST-PREFACE-DIRECT-DATES-R1.json`：CADAL02096900 卷首文件 SHA256 `711dc16b17d139612fbe852dc99869bb709b85c161440dfc7618ee1dbd6f38fa`，原文件 page10 页图 SHA256 `dad8fd03b6eceb08a0c9212f5751a11a18e7bf15608ac83af3223e3a09d3fc27`，无 OCR 人工直读为**「康熙庚辰八月桐鄉錢枋識」**。其纪年与1700年相合。另有早已登记的维基文库和 CText 收本文字相合，但不能把网站副本视作新的古本实物投票。此前12QF已包含 1606作者自序、1700钱枋分类凡例、1827姚氏序及1869重校记四层日期，不能将凡例年写成印刷年。

## 三、需要保持的边界

CADAL02096900 **并未**被证实与京都 BB18578034 共享同一实物副本；因此现在最合理候选是CiNii书目阿拉伯纪年 **30 或系 39 的误植**，但**京都实体原页尚未见到**，不能断言该实物上印的是「三十九」，也不能由此裁决原刻本或同治递修本字形。馆藏目录纠错属于元数据问题，**不是把本项目 Matrix 已修复的45项增加为46项**，更非排盘算法错误。
