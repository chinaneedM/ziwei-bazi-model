## 2. 最关键：第五日原图「四分」栏出现「五」

取自第 **2** 张 `kr_052_1056.jpg` 的 *NIKH 发布者保存图像*：

- 原始 JPEG **261,092 bytes**，**1026×2000**，SHA-256 `0b8e8a2a280d52068e79c8fdb04b1c7caae994205dd5502403c35672c51b21a7`。
- 在该**同一**图像的第五日栏，能目视见到日序标题 **「五日」**，下方列名 **「四分」**，与其连属的四字字形依次为 **「五一七二」**。直接页图局部读作 `四分五一七二`，不依靠 OCR，也不靠现代数字正文回填。
- 无插值或伪造的 RGB 原像素绑定：`PIL.Image.open(JPEG).convert('RGB')`，日序框 `(110,263,210,432)` 的原 RGB bytes SHA `427d4b129cadc2e7fccb018f7e2a0a3322ee0a111e79c10c109bc5e140e9f41b`；四分字列框 `(167,606,250,1450)` 的原 RGB bytes SHA `e3bcf659d342b6fe46349eb0dbb91433992d59b0cccb3befbb17d5c401a4c833`。框均是原1026×2000像素图坐标，不是放大预览坐标。

前轮 NLC p74 照片在同一 D5 标签下可读作 **「四分〇一七二」**；KRDB 现行编辑文本为 **「四分五一七二」**。因此现存可重复检验的证据不仅是“国图图像〇 versus KRDB正文五”，而是进一步获得 **另一官方馆藏图像路线上的「五」字正面印迹**。

**此证据只支持 NIKH 图像本身的正面读字，不支持宣布 NLC「〇」必为错误。** GK05553 原叶的确切实物册号、叶号、像素与馆藏物项的最后绑定尚未完成。亦未证明 NLC 与 NIKH 是两个明确印次，或是同一底版不同补抄/影印/数字处理层。因此目前只能登记“两个已保存来源图像读法冲突”，不得将其放大为已证版本分叉或可选定赢家的历史数值。
