# 天问12ZL：1972年《高丽史》混合影印与奎貴5553补写册号异文

本批实际新发现两类互相关联但证据等级不同的**版本身份风险**；不声称新发现古籍原件。

## 1. 同一5553实物补写册号：馆方现行目录与二次转载不一致

- [首尔大学奎章阁 GK05553_00](https://kyudb.snu.ac.kr/book/view.do?book_cd=GK05553_00) 现行第一方目录在“所藏本”“宝物排除”两处标记 **第8、26、29册**为补写本，印期标记「刊年未详」。
- 2021年[韩国文化财厅说明的网络二次转载](https://7390882.tistory.com/entry/보물-2114호)对5553标记 **第8册卷19–21、第12册卷31–33、第26册卷73–74**为手抄代补，共三册八卷；并称另一本5554的乙亥字卷81、82能补5553之不足。**当前官方遗产详情页重访HTTP403，不能把转载段落写作本轮直读第一方**。
- 转载三处卷数 **3+3+2=8**，全书139减8恰为131，与该转载的“131卷43册”为乙亥字见证相容。但 **8/26/29 与 8/12/26 的具体册号分歧不因总数相同而消失**，第12、第29册原叶仍应独立校验。

## 2. 1972现代影印本非单一古本

[中山大学机构网站上的魏志江、陈卓学术论文](https://sir.sysu.edu.cn/sites/default/files/2026-07/%E9%AB%98%E4%B8%BD%E5%8F%B2_%E7%89%88%E6%9C%AC%E6%BA%90%E6%B5%81%E4%B8%8E%E7%BC%96%E7%BA%82%E4%BD%93%E4%BE%8B%E8%80%83_%E9%AD%8F%E5%BF%97%E6%B1%9F.pdf)，《史学史研究》2020年第1期，PDF第8页/印刷页100及脚注指出：1972年亚细亚文化社以**奎5554乙亥字本为底本**出版影印《高丽史》，残缺卷补用**木板覆刻本**。脚注列所补卷：19、20、21、31、73、74、77、78、79、81、82、83；其中部分被指出本可选乙亥字本却仍用了木刻版。故1972年整套影印是现代编配结果，不能按书名或总底本名归并为一件原印实物，更不能未经卷52实际影像校验把D16/D18视为5554直接原字。

大学网站刊存2020年论文，并不说明URL目录里2026-07是古籍刊年或论文撰写年。这里实际获得的只是**现代学术页级说明**，未取得1972卷52原影像、5554物理卷52精确册号或目标页 SHA。
