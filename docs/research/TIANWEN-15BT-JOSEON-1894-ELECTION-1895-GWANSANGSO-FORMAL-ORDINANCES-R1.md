# 天问15BT｜1894《選擧條例》《銓考局條例》与1895第47号《觀象所官制》的生效范围

日期：2026-11-23。接续[15BS](./TIANWEN-15BS-JOSEON-1894-1909-EXAMS-AND-OBSERVATORY-TRANSITION-R1.md)。本批针对15BS明确列为OPEN的**法规具体条款**，取得两个不同年代的国史编纂委员会**官方数字受读文本**。15BS的当时未知状态保持原文，不静默改写；以下是前向补证。所见HTML不是本批亲自目验历史原纸印叶。

## 1. 1894旧历七月十二日：已定位选举与铨考局正式条款文本

[朝鲜·大韩帝国官报数据库，开国503年七月十二日《草记》](https://db.history.go.kr/modern/gb/level.do?levelId=gbdh_1894_07_12_d00000_00030)清楚区分两个条款组：

**《銓考局條例》：** 铨考局考各府衙所送选举人，分**普通试验**、**特别试验**；普通试验列国文、汉文、写字、算术、内国政略、外国事情；特别试验按选状载明适用才器单独发题。原受读条文还规定普通试验通过后才能参加特别试验、铨试状的发给及部分免再考试情形。

**《選擧條例》：** 原受读四款规定各府衙门大臣选任所管奏任、判任官；广泛选取有品行、才艺、时务能力之人并将选状移送铨考局；候选人经普通、特别两试后再由府衙门按局课征用；学校广设之前另有五都八道依乡贡法推荐的过渡安排。**这不是命课学专项试书名单，更不包含哪一道旧《袁天纲》复考命令。**

同一页标题/编目为《草记》，因此只从受读本认定**官方程序中确实出现完整成文条例文本**；不根据单页草记推出所有考场已经按条款实际实施。后出[韩国学中央研究院百科《選擧條例》](https://encykorea.aks.ac.kr/Article/E0028604)将旧历七月十二日列为制定时点并把它定位为新式任官考试取代旧科举的改革，这是**现代制度史解释 D**；与历史原件 C 相互参照，不能算第二道1894法规。旧历月份与现代公历描述绝不可混用。

## 2. 1895三月二十五日：第47号《觀象所官制》确实有批准、颁布与施行条款

[国史编纂委员会《高宗实录》卷33当日第11条](https://sillok.history.go.kr/id/kza_13203025_011)明确记载**敕令第47号《觀象所官制》裁可颁布**，第一条把观象所置于学部大臣管理之下，掌**观象测候、历书调制**；第二条编制所长1、技师1、技手至多2、书记至多2；第五条及之前规定管理和事务；第六条明确**“事务之分课由学部大臣定”**，第七条定自**开国504年四月一日**施行。网站给出原本37册卷33第28张B面、国编影印本第二册542页定位。

**关键实证区别：** 与15BS的1894官署草记相比，1895文本不仅有部门职能，更有**具体令号、裁可颁布、施行条款**，可以把“1895改制”从后出百科描述升级至同年官方记录受读 C。仍不能把《高宗实录》的网页转录当成原纸字形 A，也不能通过条文未明列命课学就断言“择吉业务完全终止”，因第六条将**内部事务分科**另交学部大臣决定——该后续分科令仍未见。

## 4. 两术的规则身份边界

这批文书可填充**朝鲜王朝晚期国家教育、官署和人员选任制度的历史骨架**，并可解释为什么不能把1471/1485的《紫微数》书目、1867《选择纪要》、1894—1895机构法规自动写成一条连续的安紫微星法或子平四柱技术传承链。第47号令列历书调制是历法业务，并不能证明哪一套日主十神或星曜宫位算法曾被教学或用于考试。
