# 天问 14Q｜1985—1992 紫微斗数日文出版与台湾中文本在日馆藏的分层

日期：2026-11-18。阶段：双体系历史源流广度优先，补齐日本20世纪后期紫微出版的**非香草社**渠道。承接13ZK日本香草社研究及13ZT/14E台北中文本著录，不因题名相同推论规则相同或师门相通。本批三条均为机构书目 **B**，无原书版权页、目录/排盘正文的原件核读。

## 1. 东京出版的两条日文著作记录：书目B

1. 日本国立国会图书馆 **NDL书目000001794318**、请求号 **Y78-8303**、全国书志号 **86033164**：**鮑黎明**著《紫微斗数入門》，东京 **オレンジ出版**，**1986年2月**，244页/18cm，Orange Books系列，ISBN 4-87179-008-8，正文语码 **jpn**。[NDL官方书目](https://ndlsearch.ndl.go.jp/books/R100000002-I000001794318)。这是日文、东京出版社的真实著录，非“在日本藏有某本中文《全书》”的地理误读。作者国籍、教学经历、使用的中文底本或流派，书目都未直接认证。
2. 日本国立国会图书馆 **NDL书目000002176038**、请求号 **HR511-E301**，另有数字化永久号 **ndljp/pid/13282940**：**西村天然**著《「紫微斗数」星占術入門 : 中国四千年の知恵が生んだ凄い的中率》，东京 **徳間書店**，**1992年4月**，305页/18cm，Tokuma Books系列，ISBN 4-19-504830-3，正文语码 **jpn**，一般注记为折叠图2张。[NDL官方书目](https://ndlsearch.ndl.go.jp/books/R100000002-I000002176038)。书目页面另示数字内容需要符合资格的注册/传送服务；本批**未登录、未取受限全文**。书名副题中的预测有效性宣传只是标题层的作者/出版表述，**不是本项目验证结论**。

两条东京出版记录展示：1970—80年代已知的香草社中日译解之外，1980年代后期及1990年代初还存在**独立出版社与不同署名作者**的日文紫微出版物。这是出版市场与文本媒介的广度，不是“日本流派分成三派”或具体师承的证据。1986/1992均为各自被著录的印年；是否首印、序言实际年代与编著来源仍无原页证明。

## 2. 东京大学收藏的1985年台湾中文书：书目B，但不是“日本出版”

国立情报学研究所 **CiNii Books NCID BA57765475** 登记：**顧祥弘**著《飛星紫微斗数 : 命身十二宫詳解》，**台北：金剛出版，1985年6月**，**181页，21cm**；出版国码 `ch`、题名与正文语码 **chi**。列一处日本大学馆藏：**东京大学东洋文化研究所图书室**，排架号 **CB99:10**（对象号6401266314）。[CiNii书目](https://ci.nii.ac.jp/ncid/BA57765475)。

本书至少建立一个1985年台北中文飞星题名印本进入日本研究机构藏书网络的**馆目事实**。它的1985年为著录的出版事项，不是收藏入藏年；**台湾刊印地 ≠ 日本保存地 ≠ 日本实际授课地点**。这本书不能凭“飛星”二字归入明刊《捷览》、道藏《紫微斗数》十八飞星或近代四化飞星中的任一机械法派；和14E台北1972《飛星紫微斗數》也尚无可裁决的版次关系。

## 3. 与既有研究互补而不虚构传承

- 13ZK/13ZL：香草社1975、1977及1980年代的中文署名者—日文译者书目，及《紫薇發秘》后出明确译解说明。
- 14Q：两家非香草社东京出版社的**日文编著**及一本**台湾中文著述的日本机构保存**，首次在本研究中分出两个不应合并的地域出版/保藏轴。
- 日本国会图书馆有1940年《神相全編稿本》陈搏题署的书目，但它属**相学、人相文本**，不得误归为1930—40年代“紫微斗数日本出版”；陈抟署名与人名检索不是书类辨认。

**证据限界**：本批没有1985/1986/1992任何一本原始版内页、出版权页、讲授活动或具体规则源流对照。三条机构元数据来源不建立直接拷贝、师徒、学派或算法边，不进入排盘实现。后续可寻找1986《入門》与1992《星占術入門》的原版序/目录、1992附图、及1985台湾本规则目录；如需个人注册/权限则保留书目边界，转继续早期紫微、四柱其他时间地域缺口。
