# 天问 13HW｜《高麗史》冬至表首末锚点与第十六日「原字≠数表推算」的全幅度约束

## 研究增量

13HV 已直接核读三个已登记馆藏原像，十五至十七日均为 `五分二一七六→五分一三六二→五分二五四八`。本批补充的是**独立于相邻三日插值的首末锚点约束**，并严格限定其证据等级：韩国国史编纂委员会（NIKH）《高麗史》卷52官方**现代校录**公开了 `初日 四分九三八六`、`八十七日 六分五五六八`，另有 `八十八日 六分五七五四`。这不是新的古本实物，也不是新增原叶直接字形读数。

正式校录：[NIKH《高麗史》卷52〈授時曆立成〉](https://db.history.go.kr/goryeo/level.do?levelId=kr_052_0010_0010_0020_0010&types=o)，条目 `kr_052_0010_0010_0020_0010`。本批复用既有来源 `EXT-KRDB-GORYEOSA-V52-SHOUSHI-LICHENG`。

## 算术重放（数字拼接仅用于计算，不命名古单位）

约定将 `四分九三八六` 临时转为无量纲整数 `49386`，`六分五五六八` 为 `65568`，则：

```text
第0日 = 49386
第87日 = 65568
间隔 = (65568 - 49386) / 87 = 186
规则计算 v(n) = 49386 + 186 * n
```

这仅核验六个明示锚点，**不声称本轮已逐项读取0至88日全部90行的每个字段**。十六日 `五分二三六二` 是可重放计算的候选，不是本批在三馆影像或官修数字校录中见到的原字；同源见证 `一三六二` 保留。

## 后见技术文本：方法旁证而非实物订正

后世《歷算全書》卷二十四《歷學駢枝》现代公开转录，在「布立成法」解释从初日 `四分九三八六` 到八十七日 `六分五五六八` 相差 `一分六一八二`，每步 `○一八六`。[定位页面](https://book.chinakongzi.org/BookContent.aspx?ContentID=15882&bookid=201708230058)。另一《明史》卷33的现代转录说明 `一秒八十六微` 的递增运算。[方法文本](https://doosho.com/cn/31/2/9/1)。

这两者都是**后见文本且本批未取得对应古刻原叶**。不得据此推断它们与《高麗史》`日差加一秒八十六少` 的「少/微」古单位严格等同，更不能从后见的正确算式倒填元代原表。

## 历史用字不能强制归一

NIKH 《高麗史》此表为 `大陽冬至前後二象盈初縮末限`；项目 Batch 11N 已注册的 [《世宗實錄》卷156《七政算內篇》官方校录](https://sillok.history.go.kr/id/wda_50016011) 则载 `太陽冬至前後二象盈初縮末限`。两者**不同作品、不同见证作用域**，不能用某一字形全局校改另一文本；同词或同数不足以证明直传或共版。
