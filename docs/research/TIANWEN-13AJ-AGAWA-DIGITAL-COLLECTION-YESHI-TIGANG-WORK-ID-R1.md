# 天问 13AJ｜东大阿川数字馆藏：可见目录与《麗史提綱》/《高麗史》非同书

## 核验到的官方数字馆藏

东京大学数字档案门户直接开列 [阿川文库数字馆藏](https://da.dl.itc.u-tokyo.ac.jp/portal/collection/agawa)。当前公开网页显示 **69 个子馆藏题名入口**，这是 *该网页当前展示*，**不是实体阿川文库约5000件的穷尽名录**；网页不显示《高麗史》四字绝不能当作整个馆藏、G23:12或G23:194的不存在证明。

官方门户显示其中有 [《麗史提綱》23卷](https://da.dl.itc.u-tokyo.ac.jp/portal/collection/2a3f9aa1-1221-8d86-589b-c41908ab81dc) 子馆藏。首卷条目的 [原生资产记录](https://da.dl.itc.u-tokyo.ac.jp/portal/assets/013eda81-9246-8e19-54cc-171ac5076e3c) 明确：

- 著者 **兪棨**；作品为《麗史提綱》23卷，卷首记录《麗史提綱 序目, 凡例, 卷之1-2》；
- 实物索书号 **A00:4671**；当前门户将此资产置于 **阿川文库** 分类树之下；
- 原书条目记 **「顕宗8 [1667] 序」** 与 **「後印本」**。1667 是**序纪年**，不能自动上升为**这件现存实体的刻印/后印年代**；
- 存在对**这一件**《麗史提綱》的官方 IIIF manifest，但此轮**未进行原件页逐字校勘**，不报告历史数表原始字形。

## 规则身份与数字载体的双重防火墙

**《麗史提綱》23卷不等于《高麗史》137卷**，尽管首卷条目还载小口书「麗史」。不同作者、题名、卷数、资产编号和实物索书号，已足够排除把该相似题名纳入 G893 /《高麗史》卷52第16日计算异文交叉投票。自动检索不得以含「麗史」即判《高麗史》。

数字目录里一件**已经确认归入阿川集合的**物品以 A00:4671 编号，不能推断 G23 与阿川必然互斥；此前 13AH 的《朝鮮記》G23:236 南葵反例又证明 G23 不独属阿川。两个《高麗史》目标 `BC15670118/G23:12/0008535809`、`BC15973641/G23:194/0008542011` 的**馆藏来源及第16日原字仍未核验**。
