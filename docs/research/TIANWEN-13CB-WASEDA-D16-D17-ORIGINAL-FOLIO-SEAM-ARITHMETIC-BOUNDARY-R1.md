# 天问13CB｜早稻田《高麗史》日16／17原页中缝数栏：核实数字，保留字段归属疑问

**问题编号 TW-OPEN-0005，证据级别：同一馆藏原始JPEG逐像素哈希／人工原字复核，无OCR。** 接13CA已经证明的“積日”与“盈縮積”原印栏名区分，本批检验第23页双开书叶日16／17附近的*跨书叶*数字，纠正把相邻版面当作独立的“同日C字段”的风险。

## 来源与直接正证

Waseda `ri06_02809` book33 官方PDF p23 xref70 JPEG SHA-256 `388f3d5dd9e9861f8ce90c304b154edaeaee98614bb12cd3468f957dcde6fc66`，与13BR存档 artifact `12340588249` 内 `original-source.jpg` 相符；本轮再次按原始尺寸2592×1728以 RGB 像素读取。新隔离原始书叶左页外侧数栏坐标 `[1135,680,1175,1410]`、crop SHA-256 `39915c512c38efb29fa64b9b97be6528e3144284dd2ce1af74466514dd661fa2`，逐字可见 **「七千五百七十〇六六二四」**，换写十进制 **7570.6624**。其左书叶外边位置，和右书叶最左侧“十六日”题头之间有装订中缝，局部空白及版框另有两份哈希绑定的ROI。

此前13BS已经在**同一原图**独立证实右页“十六日”所见行度 **429.6073**（原印「四百二十九六〇七三」）与五分一三六二；13BO已独立证实左书叶“十七日”对应的窄栏数值 **8000.2697**（该批表头映射作用域）。本批做出的整数精确运算，仅为：

```text
7570.6624 + 429.6073 = 8000.2697
（按万分位整数：75706624 + 4296073 = 80002697）
```

它是三个同一来源上可复核数字之间的**局部关系**，而不是另一次原图印本见证，也不是“古书已经明说C16”的证明。

## 必须保留的栏位冲突

13BE把 7570.6624 登记为旧**版面位置**“printed_under_day17_layout”的相邻累积数字；13BO则经窄ROI把日17的目标累计字段另行绑定为8000.2697。这两种字段／版面记账方式不同，旧原始记录原样保留。**不允许**将13BE的“在某日版面附近”静默改为“该日的盈縮積字段”。新隔离的7570数字来自**左书叶的最外数栏**，并非直接落在右书叶“十六日”字列之下。

后续可将其作为“跨书叶累计栏位候选”接受反证检查，但没有经原印栏位结构独立裁定前，仍标 **Waseda D16 same-day 盈縮積 = UNBOUND**。绝不凭算术等式擅自更正原书数值或认定Waseda/NAJ通用日差、G893少／微与明1569同量纲、两馆藏必有直接传抄。
