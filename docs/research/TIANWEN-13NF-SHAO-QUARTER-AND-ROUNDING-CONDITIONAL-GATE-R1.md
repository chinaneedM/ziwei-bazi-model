# 天问 13NF｜“少”的四分语义与 G893 日差精度的条件性排除

## 已得到的有效结论

1. 《晋书·律历下》景初历“推加时”明确说明余数四分以后，第一份为“少”、第二份为“半”、第三份为“太”；《新唐书·历志四》开元大衍历又明确写有“凡四分，一为少，三为太”。这是**古代历法系统使用“少=四分之一”的直接文字依据**，但属于各自算法的术语证据，**并未证成 G893 的具体“秒/少”位值**。
2. 已封存的奎章阁《授时历立成》G893 原图（上一批13NE）表头作“日差加一秒八十六少”，表中初日 S0=4.9386、十五日 S15=5.2176（相同原件、同一短列）。韩国国史编纂委员会（NIKH）现代韩文译读将表头作“1초 8625”，属**现代编者的数值解释**，不是额外原刻实物。
3. **条件性排除：**若把编辑译读“1초 8625”理解为 1.8625 秒、每秒=本表显示分值的 0.01，并假设精确日增量 0.018625 逐日累积、仅末尾在四位小数舍入，则 S15=4.9386+15×0.018625=**5.217975**，按常规四位舍入为 **5.2180**，与原刻 **5.2176** 不符。已知原刻从 S0 至 S15 的显示差为 0.2790，平均每显示日为 **0.0186**；4.9386+15×0.0186=5.2176。**此数学结果只否定上述复合假设，不证明历史上确实“先截断再累加”**。
4. 若 S0 本身只显示四位小数，原始隐藏小数位未知；但四位四舍五入的原值扰动通常不超过 0.00005，不能解释末日相差约 0.0004。仍不能排除不同单位基数、特定位置的取舍、先制表后抄数、分段处理等历史可能性。不能把十进位数值的近似一致直接升级为 G893 与明1569原历表的同一机械算式。
5. 《元史·授时历经上》有“弦策，七日三千八百二十六分四十八秒少”，为同一授时历术语体系中的“秒少”平行用例；这是**收本文字级术语背景**，不是 G893 原版格内进位法的原物校勘。
