# 天问 13MM｜《高丽史》收本第十六日异常，与周相 1569 原版三日对读

## 结论与证据层级

本批只建立**收本文字的可重放异常检测**：韩国国史编纂委员会官方现代阅读页和维基文库的《高麗史》卷五十二均显示第十六日 **5.1362**。二者均是**公开收本 / 数字文字层**，不能算两种独立物理古籍或原叶的两张赞成票。官方页：https://db.history.go.kr/id/kr_052r_0010_0010_0020_0010 ；收本对照：https://zh.wikisource.org/zh-hant/高麗史/卷五十二 。

独立层面的既存证据来自 13MJ 已哈希校验的周相 1569 《大明大统历法》卷六原版 PDF：第十五至十七日同一表行印数 **5.2176 / 5.2362 / 5.2548**；PDF SHA-256 `4c006b7ce131902fe33012d42f62cd2bbc2140affa3d5886e0da02966352cb7c`。该图像已由 13MJ 证据归档，本批**没有重新获取或人工读取新的实体原叶**，因此不重复计数。

## 五日精确算术

| 日期 | 韩国官方现代收本文本（日差字段） | 四位小数的相邻差 |
| --- | ---: | ---: |
| 十四日 | 5.1990 | — |
| 十五日 | 5.2176 | +0.0186 |
| 十六日 | **5.1362** | **−0.0814** |
| 十七日 | 5.2548 | **+0.1186** |
| 十八日 | 5.2734 | +0.0186 |

由十五、十七日独立插值得到 **(5.2176 + 5.2548) / 2 = 5.2362**，与周相 1569 第十六日原版数值相同。收本所记 5.1362 与此差 **−0.1000**，对应十分位的一字差候选。但**算术一致不等于证实《高丽史》任何指定实物原书必定是刊误或抄误**；具体异文发生阶段仍需实物版刻证据。

## G893 原叶映射仍未闭合

此前 13MK、13ML 在 **同一个**奎章阁数字替代本 GK00893_00 中，确认原表首 `積日`、`日差`、`盈縮加分`、`盈縮積度` 与 `加一秒八十六少`，并确认 002a→002b 九至十九日次跨页连续。此范围证明版面及原字，尚**没有**完成 001a 字段→002b 第十六日两条数字细列逐列、逐单位绑定。

所以，周相原版的 5.2362 与收本邻日的算术吻合，目前只能提升**收本 D16 更正候选**的机械支持，不可提升为 G893 自身原始 D16 数值赢家，也不能证明直接抄传。其余六组 G893 物理跨证源目标仍是 **0/6**。
