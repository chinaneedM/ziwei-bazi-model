# 天问13IG｜奎3467的“卷首”目录描述与残册实物证据分层

本批核查了首尔大学奎章阁第一方公开目录 `GK03467_04`，将**整书/版次书目说明**与**现存第六册卷52所拍原叶**区分。结论是证据层级校正，**不是找到新表首、缺叶或独立古本**。

## 一、书目实际提供的范围

馆方书目列「零本1冊」「乙亥字」「[刊年未詳]」，并给出「卷首：進高麗史箋：景泰二年(1451)八月二十五日……」「高麗世系、目錄」等著录。这里的卷首/序箋文字是公开书目中的**描述字段**，没有按现存卷52残册的原图、叶码或装帧连续性完成独立验证。1451是史书编成或所引序箋日期，**不能转换为该件残册的印制日期**。

馆方的「1冊外缺」是整套存佚范围，不能由此推断现存那册局部缺多少叶。即使原目录包含统一版式描述，也不自动证明相应书页仍在现存残册中。
