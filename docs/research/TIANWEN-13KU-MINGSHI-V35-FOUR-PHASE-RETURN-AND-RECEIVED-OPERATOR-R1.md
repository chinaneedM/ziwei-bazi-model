## 四相位源数算术

本批用有理数（Python `fractions.Fraction`）严格计算，无二进制浮点和隐式四舍五入。

- 日转限：`61/5 = 12.2`，一日基本单位 10000。
- 转中限 `H = (275546/2) × (61/5)/10000 = 168.083060`。
- 弦转限 `Q = (295305.93/4) × (61/5)/10000 = 90.06830865`。
- 朔转限 `S = 19759.93 × (61/5)/10000 = 24.1071146`。
- 基本单位关系：`295305.93 - 275546 = 19759.93`。
- 同一组原印数的**严格恒等式**：`4Q - 2H = S = 24.10711460`。
