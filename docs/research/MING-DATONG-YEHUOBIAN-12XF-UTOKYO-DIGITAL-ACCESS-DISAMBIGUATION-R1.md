# 12XF 东京大学影像资源分型与原刻目标隔离

本批不新增古刻原叶，不新增「清刊本真实字形」证据。目的：从馆方不同数据库的机构同名、用户目录选取与历史影像计划中，阻止错误的原本归属。

官方 [善本全文影像库介绍](https://shanben.ioc.u-tokyo.ac.jp/intro.html) 给出**截至2009年3月的** 4630 条题名，其中 A 类 4019 条（全球开放全部页）、B 类 611 条（指定机构可用全文，馆外可能只见部分）。这是当时的**分类/开放策略**，并非 2026 年两册《野获编》已数字化或当前授权的证明。图像再版和散发另有规定。

官方 [精选书目列表](https://shanben.ioc.u-tokyo.ac.jp/list.php) 的先前可重演取证 12WR 显示 3889 条、195 页，一次源表单检索「野獲編」返回 0 笔，12WS 已裁定这是**特定索引**的查询结果。2009 年的 4630 和该列表 3889 既不同时也不等范围，不能相减构造失踪题名或将零命中推广到全馆。

官方 [倉石武四郎講義ノート系统](https://kuraishi.ioc.u-tokyo.ac.jp/about_system.html) 记录 40 册个人讲义中 35 册数字化。**个人讲义档案不是倉石文庫:20128:11 实体1869年《野獲編》**。另有[东京大学NIJL合作数字藏品](https://da.dl.itc.u-tokyo.ac.jp/portal/collection/tobunken_nijl)，尚未发现两份确切清刊本的物品—页码绑定。

基于前期 12WZ 原生馆目、12XA 原始详情HTML（只有1959年排印本9928有 PDF 图片入口）、12XE 两份目录保藏说明，这些现代数位平台暂时仍只能提供**目录/入口信息**。实际目标保留：1827大木 9927/6403767830；1869仓石90972/6403148395。独立两件原刻卷20《改造漏刻》的扫描原页仍为零；不能从现成照片书、同姓名称或者馆方2009开放政策“补齐”原页。

后续只使用馆方实际签发的索书号和对象页位，先取得复制与使用条件，验收字节来源与 SHA-256，再人工复核四处古字及版片特征。没有提交咨询、复制申请、付费，也不变更算法、图谱或来源注册；Matrix222/222、修复45/45、来源647+59=706、谱图252/238、正式487批、R1排盘CLOSED。
