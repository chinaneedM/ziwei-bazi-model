# 天问 13BM｜早稻田《高麗史》跨叶积数日序原字复核与 13BJ 前向校勘

**核心发现：数字正确不等于归属日期正确。** 本轮重开同一早稻田原本第33册馆方 PDF，直接复核 PDF 第23页 xref70 与第24页 xref73 原始 JPEG 像素（各有独立 SHA-256）。本次人工读字、ROI 像素摘要均取自原件，未使用 OCR。

对应的三个日期标题也已在原始 JPEG 上逐一直接核读，六个 ROI 均保存来源图像 SHA、矩形坐标和 RGB 裁片 SHA，见机器 JSON。两页跨页衔接的积数差：

## 对旧 13BJ 的明确限定性勘误

13BJ 对 Waseda PDF p23 某张 ROI `[601,690,686,1400]` 的数字 `8843.7571` 读数及 SHA 均属原始图像真实像素，但旧 JSON 把该 ROI 标为 `D20_CUMULATIVE`。本轮把上方日期标题和相邻页逐字对照，确认同一数值列在早稻田**印刷十九日**的版面分组内。再往左的 Waseda 印刷二十日原始积数为 `9257.6000`，PDF p24 的印刷二十一日为 `9666.1509`。

因此 **13BJ 的累积列“D18/D19/D20”日序绑定不能继续作为独立、已终审的原始印刷标题证据**。保留其旧版本、历史数值和所有哈希，不静默篡改；新 13BM 是 forward-only 纠错层，且不对尚未逐列复核的整张表作负面或整体改判。

NAJ《高麗史》原件旧 13BK 登记的印刷 D20 = 8843.7571、印刷 D21 = 9257.6000，与本轮 Waseda 的印刷 D19/D20 形成**局部数字相同、印刷日序不同**的配对；这可能涉及版面列序或原表语义，但不能据两个数字决定两本印次关系、祖本、全表统一偏移或历史正误。
