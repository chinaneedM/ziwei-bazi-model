# 天问13F｜《国朝宝鉴》卷九1454年刊印命令与1782年馆藏身份

已直接阅读[维基文库《國朝寶鑑》卷九](https://zh.wikisource.org/wiki/%E5%9C%8B%E6%9C%9D%E5%AF%B6%E9%91%91/%E5%8D%B7%E4%B9%9D)「端宗朝／甲戌二年／九月」的转录文字：「命刊印高麗全史。廣布中外。」。其中「命」修饰刊印和广布，是**皇命／行动意图**，并不直接证明印刷完工、发书数量、领取清单或实际传播。该句与此前《端宗实录》「請印《全史》廣布。從之」可能描述同一命令，禁止将两处记述充作两份独立的已印证明。

[首尔大学奎章阁 GK03942 官方书目](https://kyudb.snu.ac.kr/book/view.do?book_cd=GK03942_00)登记《國朝寶鑑》（太祖—英祖）为1782年正祖命编木刻本，共68作品卷、22实物册，目录中卷九为端宗；这可以给传世文本的**作品与候选版次**提供第一方书目定位，但不证明维基文库的底本就是 GK03942。1454为故事所记事件年，1782为目前书目载本的版本年；未取得实际卷九册号、原叶、图像 SHA。

13D历史快照中的『原篇章未读』应保留原状，13F追加『网络收本篇章文字已定位』，但**实体原叶仍未取得**。《增補文獻備考》对应卷叶尚待检索，卷52 D16/D18独立刻本原字同样未得。根647、扩展81、登记总728；十一研究遗漏仍开放，传承图不擅加边、排盘不重开。
