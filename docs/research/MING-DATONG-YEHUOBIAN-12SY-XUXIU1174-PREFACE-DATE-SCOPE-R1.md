# 天问 12SY｜《野获编》前言纪年与版片年代的分离

同一份《續修四庫全書》第1174册现代影印 PDF 的第119页，经原页直读，存在三个不等价的纪年：**1606年**「萬曆三十四年丙午仲冬日沈德符題於菱汲軒」（作者序署年）；**1827年**「道光七年歲次丁亥春二月錢塘姚祖恩」（姚氏序署年）；**1869年**「同治八年己巳春月重校刊補」（重校刊补声明）。上述都是**影印文本里的纪年记载**，不能各自自动转为具体物理副本的印刷时间。

来源：Commons 1174公共文件，完整 PDF SHA256 `bee08d95d6b141a978f4d7fb068b97b74cf8ee25b46c6273110b2891a0faf953`。第119页已渲染 JPEG SHA256 `f76a74aff8c11113ae9ec7f55d2db7286d114d82032291835751f294312312ae`；采集工作流 [12SV 成功](https://github.com/chinaneedM/ziwei-bazi-model/actions/runs/38201033731)，artifact 11725486250。手工辨字，无OCR。

第506页《改造漏刻》的四处读法仍依12SX为「宮禁／官漏／辰初二刻／戌初二刻」，仅代表这份**2002年现代影印件**的直接图像证据；2018年是数字文件上传时间。第119页留存1827年序与1869年题记，**不能判断第506页目标版片有没有在1869年重刻**，也不能据此推论1827年未修原刻的读法。
