# 天问12ZK｜GK05553 与 GK05554 共用作品卷目，不等于实存卷52

## 一对一第一方馆目校勘

[奎章阁 GK05553_00](https://kyudb.snu.ac.kr/book/view.do?book_cd=GK05553_00) 的实物项目为 `奎貴5553-v.1-46`、`139卷, 卷首, 合46冊`，其中第8、26、29册有抄补；[GK05554_00](https://kyudb.snu.ac.kr/book/view.do?book_cd=GK05554_00) 是另一实物项目 `奎貴5554`、`零本32冊`。两者版式均标乙亥字，印年同标 `[刊年未詳]`，这不证明同一次刷印。

**新增的两项目交叉约束：** 两页的“목차”字段都呈现相同的全书目录片段：`卷1-46:世家(太祖-恭讓王), 卷47-85:志:卷47-49:天文志, 卷50-52:曆志`；“所藏本”说明也重复同时谈论 5553 的抄补和 5554 仅余32册。这些都是作品级目录及多项目说明，而非 5554 的逐册实存卷号报告。将“作品卷52列于目录”推成“5554现存卷52原刻页”属于误读。

尤其需要防误认：两个页面均列 `M/F74-102-17-1(奎 5553/v1-9)` 等七条缩微编号，括号内明确全部指向 **5553**。共享登记不允许把这些图像改记为5554原件。“同一版”目录关联也不能合并不同馆藏物理本或赋予独立祖本投票。
