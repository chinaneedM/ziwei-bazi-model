# 天问 14X｜朝鲜《三車一覽》1430 书目与1517／1518 版本年代分层

核验日：2026-11-19。续接 14W，限定为**馆目与后出研究论文互证的书目年代范围核查**，未取得高丽大学藏本的目标原叶。此处不裁决 1430 年官署用书的作品身份，也不把馆目刊年升级为实物印年。

## 证据层与可复核入口

1. **1430 年官方数字转录（C，朝鲜官修史料的现代数字转录）**：[《世宗实录》世宗十二年三月十八日](https://sillok.history.go.kr/id/kda_11203018_002) 在阴阳学取才项目中列《紫微數》与《三車一覽》等简称。该条没有给出《三車一覽》作者、卷数、版本、印本或所用术式；同题不足以识别具体书本。
2. **高丽大学三卷本馆目（B，馆藏编目层）**：[《新編三車一覽子平淵源註解》天册](https://dcollection.korea.ac.kr/srch/srchDetail/000000134095) 载乙亥字、徐大昇撰次、逸人集解、熊上恩訂刊，馆目时间字段含中宗十三年／1518，且同时标示「刊寫者未詳」。[人册](https://dcollection.korea.ac.kr/srch/srchDetail/000000134097) 记录〈繼善篇〉篇目和末册馆藏号；天、人册属于**同一三卷三册馆藏组**，不计独立物理版本两票。
3. **后出学术研究／书目解释（次级）**：[《朝鮮時代陰陽科之研究》公开论文副本](https://files-scs.pstatic.net/2025/09/25/WxS4FR5Fwy/%EC%A1%B0%EC%84%A0%EC%8B%9C%EB%8C%80%20%EC%9D%8C%EC%96%91%EA%B3%BC%EC%97%90%20%EA%B4%80%ED%95%9C%20%EC%97%B0%EA%B5%AC.pdf) 第141页附近报告正德十二年冬（1517）序和正德十三年七月（1518）熊氏厚德堂刊行信息，并提醒现存朝鲜活字本实际刊印年未详。**本轮未读到该印本的序跋原叶；1517／1518 在这里是研究者报告的文本年代，不是本文独立核实的实物字形。**
4. **方氏十卷本（A，先前14W核读原影）**：[英国图书馆藏方谦之《三車一覽命書詳論》](https://upload.wikimedia.org/wikipedia/commons/7/7c/CNTS-00109637789_1_%E4%B8%89%E8%BB%8A%E4%B8%80%E8%A6%BD%E5%91%BD%E6%9B%B8%E8%A9%B3%E8%AB%96.pdf#page=47) 载1261年序文、十卷结构及卷二〈論四柱〉，馆目所给明宗至宣祖间印年范围仍只是藏本断年范围，不将1261序年当实际印年。详[14W原页与SHA记录](./TIANWEN-14W-XUANSOU-FANG-SANCHE-FOLIO-EVIDENCE-R1.json)。

## 独立判断与反推边界

- **成立**：1430 年官署书名出现早于徐大昇三卷本当前已见的1517序／1518刊刻记，因此不能把**1518年的这一刊刻行为或其后形成的现存印本**直接说成1430年取才已经使用的同一后出实物。
- **不成立的推论**：这并不证明1430年条目必指方谦之十卷本；亦不排除存在更早、同名或简称相同但现已佚失的底本，也不直接证明徐氏体系在1430年前不存在。
- **尚未绑定**：高丽大学乙亥字本的本体印年、其所载1517／1518序跋的原字、较早版本的出现时间、二书互相引用关系、1430阴阳学用书的明确责任者与卷次。
- **严格分层**：作品形成日、篇首序／刊记日、朝鲜藏本的实际印制日、现代数字记录日分别登记；题名／篇名相合与实际直接承袭不是一回事。
