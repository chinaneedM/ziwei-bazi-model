# 天问 13ZU｜朝鲜王朝取才书目、命课教学与紫微斗数实录

朝鲜王朝把星命与禄命类书列入官府取才，实录也记载了命课教学的安排。1644年同一条供词又把「紫微斗數」和「紫微數」用于同一个家庭的推命活动，使朝鲜紫微线有了可定位的本地使用陈述。以下年份分别指事件、法典定本或馆目所标的刊刻年代。实录与法典为机构公布的汉文传文（C），大学目录为馆藏书目（B）。本批没有核读这些物件的原叶图像。

## 子平文献与高丽大学藏本

- **《三车一览》有两层见证。** 1430年的取才书目提供该简称。高丽大学书目号 **000000724230** 登记《新編三車一覽子平淵源註解》三卷三册、乙亥字，列徐大昇撰次、逸人集解、熊上恩订刊。天、人两册领用号分别为华山贵135-1、135-3，登记号461225367、461225369，属于同一套书。天册目录可定位正官、杂气财官、时上一位贵等题目，人册有〈继善篇〉。这些题名仅用于定位内容。馆目同时显示「中宗15(1518)」与数值1518，而中宗十五年为1520。韩国学中央研究院的《三车一览》条把1517冬置于序文、1518置于熊氏再刊记。馆藏乙亥字本的印年和1518熊氏再刊之间的关系仍须以书端、序跋、版式原页查明。[高丽大学天册](https://dcollection.korea.ac.kr/srch/srchDetail/000000134095) · [人册](https://dcollection.korea.ac.kr/srch/srchDetail/000000134097) · [《实录辞典》三车一览](https://dh.aks.ac.kr/sillokwiki/index.php/삼거일람(三車一覽))
- **《五行精纪》另有朝鲜活字馆藏。** 高丽大学书目号 **000000740556** 将《五行精紀》乙亥字残本归为朝鲜明宗年间，著录为残五册。已核目录的卷18–21、26–29共用此书目号，登记号分别为461372111、461372113。所列食神、正印、财、凶杀及男女命诸题可作后续定位。现存活字本补足既有宋元书目与后世抄本之间的传播见证，考试用本、活字本和既审抄本之间的逐叶关系仍未核实。[卷18–21馆目](https://dcollection.korea.ac.kr/srch/popup/srchMetaViewPopup/000000134151) · [卷26–29馆目](https://dcollection.korea.ac.kr/srch/srchDetail/000000134153)

## 传承判断及待查

1. 紫微线可独立记录1430年的简称、法典所列考试书名和1644年本地使用陈述。1644年同案并用长短称，为比较早期简称提供实质线索，仍缺1430应试书原叶及该书与明刊《捷览》《全书》《全集》的对应。韩国学中央研究院辞典另举1870年汉阳大学藏明经阁《全集》，相距数百年的藏本仍须通过中间文本方能接入早期取才线。[《实录辞典》紫微数](https://dh.aks.ac.kr/sillokwiki/index.php/자미수(紫微數))
2. 四柱线可记录1430取才与1445教学安排、明宗年间活字书目、1797试讲变化。1430《三车一览》与高丽大学现存详题版本的对应、法典简称《徐子平》所指篇卷及本地具体用法均列待查。官府同时采用多类命课书可说明制度并存，两门术数的机械源流仍各按自身证据梳理。
3. 图谱新增条文、供词、书目与馆藏节点，并将已读的书名和当事人称谓关联到各自材料。候选的版本关系保留未决。Historical Matrix维持222／222，命盘算法缺陷计数为0，产品状态为CLOSED。
