# 12VP — 名古屋大学校记后续刊期官方目录限定核查

本轮直接核读名古屋大学东洋史研究会《名古屋大学東洋史研究報告》逐期总目录：https://toyoshi.lit.nagoya-u.ac.jp/kenkyukai/backnumber.html。该目录列出43号（2019）井上进《万历野获编》的版本问题、44号（2020）《校记（一）》、45号（2021）《校记（二）》；46号（2022）、47号（2023）、48号（2024）、49号（2025）、50号（2026）所列题目中均不见《校记（三）》或该系列后续标题。

**负面证据的作用域只限这五期官方已列出的目次**。不能推断作者在其他学刊未发表后续论文，也不能推断尚未发表的研究不存在；更不能把「该刊目录无卷20校记」变为1827或1869原本目标字形一致/缺文的证明。2021论文的发表年份与仓库2024开放年份保持分离。
