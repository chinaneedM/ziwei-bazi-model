# 天问 13ZW｜晚唐至北宋初的星命见证与「八字」释义

晚唐传文出现按星与宫论命的叙述。北宋初敦煌写卷 Pelliot chinois 4071 提供有题记的十一曜星命材料，其开首同时记录出生年月日和时辰。它为两部史纲提供可以共同引用、分别解释的史料。本文所用证据为馆目（B）、整理或学术转录（C），早期直传关系仍待补证（D）。

### 出生输入和星宫机制

Isahaya 与 Lin 2017 的转录第157页首栏依次写庚寅、丙戌月、己巳日与申时。作者将出生日期换算为930年10月3日，写卷题记的975年属于另一日期层。首栏呈现年月日三组干支和时支，所转录文字没有写出时干。单凭该栏无法证明以日干推出时干，也无法证明整套日主、十神与格局方法。

同一转录第157–158页把五曜及其他曜定位到宿度与黄道宫，例如土星在斗宿并照摩羯宫，紫气在星宿并照狮子宫，并出现命宫。天秤、摩羯等黄道宫和星宿在文本中分工清楚。与杜牧传文对照，可确认早期星命语境已有按星曜方位及宫位论命的材料。紫微斗数的十四主星安置、四化等具体规则，要另有书名、原文与算法的跨代见证，才能建立传承关系。八字史纲采用此卷记录出生时辰用于星命的年代证据，并把时柱首证留给明确列出时干、或可由同一来源复核取干方法的材料。[Isahaya 与 Lin，2017，第157–160页及注38、44](https://www.jstage.jst.go.jp/article/historiascientiarum/26/3/26_153/_pdf/-char/ja)

## 吴融诗中的「八字」

| 证据层 | 对读结果 |
|---|---|
| 晚唐诗作，现读《全唐诗》传本 | 吴融《送策上人》用「八字如相許」接辞却官印之意。其《寄貫休上人》又有「八字微言不復聞」。两诗题均有僧人，第一首未说明年月日时、合婚程序或一套起算规则。[卷685《送策上人》](https://zh.wikisource.org/zh-hant/全唐詩/卷685) · [卷684《寄貫休上人》](https://zh.wikisource.org/wiki/寄貫休上人) |
| 清翟灏的解释 | 《通俗编》卷二十一〈八字〉把《送策上人》的词义倾向理解为推命，同时以疑问形式提出唐时是否已经采用该法。后一条〈十二宫〉又转引杜牧墓铭，属于后出的叙述链。[《通俗编》传本](https://www.shidianguji.com/zh/book/JDLS0278/chapter/1m31orsyoxvyy) |
| 现代研究的两种用法 | 赵卫邦1946年第295页把同作者两诗对读，以「生滅滅已，寂滅為樂」八字解释佛教可能性。程群2020年第34页把《送策上人》用作唐代已有合八字的线索。两种释读并存，诗句中「八字」所指尚无足够上下文锁定。[赵卫邦论文](https://asianethnology.org/downloads/ae/pdf/a40.pdf) · [程群论文](https://aj.xhu.edu.cn/xhdxxbzskb/cn/article/pdf/preview/10.12189/j.issn.1672-8505.2020.06.003.pdf) |

## 进入双史纲的证据

- 紫微前史登记晚唐星宫叙述和北宋初十一曜写卷。下一步寻找宋元材料中可识别的斗数书名与操作文本，再与明刊《捷览》对读。
- 四柱前史登记写卷的具体出生字段以及晚唐诗作的并存释读。下一步从宋代命书中查年月日时四组干支、时干起法和日主关系，分别记录可证年代。
- 本批引用馆目、后出传本及学术转录，尚未比对原叶字形。早期材料到后世紫微斗数或子平的直传关系留待补证。
