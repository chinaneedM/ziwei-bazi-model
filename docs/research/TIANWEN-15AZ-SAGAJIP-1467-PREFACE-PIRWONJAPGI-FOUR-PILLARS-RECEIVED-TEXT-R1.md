# 天问 15AZ｜《四佳集》1467《五行揔括序》与《筆苑雜記》四柱论：朝鲜本地命理著述年代分层

**年代判断（暂定）**：1458 与 1467 并不必然矛盾：**受命／启动编纂**与**进呈／赐名／写序**可能在不同时点；但亦可能是不同编次或数字传文纪年误读。现阶段只有 1488 追述与后传文集序文，不据此宣布确定的九年写作期。应追同代实录工作过程记录、1467 丁亥的朝廷记载和至少一件可读旧印〈五行揔括序〉原叶再判断。

**术法史判断**：序文把五行数理、禄命「窮理」以及凡例—吉凶神煞—论断三层整理为初学指南，是**十五世纪朝鲜本地编纂活动的文学叙述及分类史线索**；没有独立《五行揔括》成书全文就不能将这些标题复原成具体可执行四柱软件公式，也不能把此事当作现代「神煞一定正确」的证据。

## B. 《筆苑雜記》的定量反思与训诂风险

卷一原段记「甲己之年正月丙寅。甲**巳**之日生時甲子」，随后称「七百二十」乘「七百二十」得「五十一萬八千四百」。**公开转录作甲巳而非甲己**，后一处若按文字作为干支组合有语义问题；不在没有图叶时擅改，保留 `甲巳/甲己` 待校勘候选。转录中还夹入「편二」混合字符，显示数字文本存在污染，故该段只能标注为**受读可检但原字未认证**。518400 是该文本作者的论证计数，不等于已证其具体历法输入、月/时柱生成函数或现代独立盘总数。

论证语境是质疑「一组有限出生组合即可唯一决定命运」并反对术士将先贤之学机械化。后文对李淳風、李虛中、邵雍、徐子平的褒贬与叙述属于作者/传文**思想表达**，不能推定直接师承、原书版本、实际现代统计验证。权溥四段生辰是**有名氏命例形式**，不能无证据确定当时的真实出生时间或起例算法。

《筆苑雜記》页首现存两篇序在转录中分别记**丙午（1486）**、**成化二十三年（1487）**；这仅是对应**序文署年**，不是当前电子文本、其底本物理印刷或卷一命理段落写成年份。两书反复出现摠／揔／總诸字形，不得先当为独立著作或单一校误。
