# 天问 13KE：一百六十七限文本证据与「益／損」相反动词的前瞻勘误

## 发现及证据等级

在 [《明史》卷33〈布立成法〉现代收本文字](https://zh.wikisource.org/wiki/%E6%98%8E%E5%8F%B2/%E5%8D%B733) 与 [黄宗羲《授時曆故》卷4网络 OCR](https://www.shidianguji.com/book/CADAL02093993/chapter/1laylkzccub7j) 之间进行逐句核对，出现两项实质性新观察：

- **限号端点得到收本文字旁证。** 黄氏网页 OCR 明载「在八十三限已下者不減……已上者置一百六十七限以所得限減之餘為末限」。这为 13KD 的 `g=167-n` 提供明确的 *后世收本文字* 对应，不应继续简单描述为无文本根据的经验镜像；但这 **不是** G893/黄氏原版刻页已亲见的证据。
- **损益动作词方向冲突。** 《明史》收本作「益減損加」，黄氏网页 OCR 作「益加損減」。二者在字面上方向相反，不能作为同一条机械规则的无条件双来源印证。黄氏网页卷题甚至把作者「黄宗羲」转录成「黄宗羡」，有可见 OCR 风险；需源页验证是识读错误、不同句法层级还是实际版本异文。

第三项位序差异仍开放：《明史》收本文字在「五秒八十一微」止，而前文相加 `五秒六十二微 + 一十九微五十纤` 为 `五秒八十一微五十纤`；黄氏 OCR 明示「五十纤」。这足以支撑 13KD 的完整整数位序**算术候选**，不构成原刻漏字的证实。
