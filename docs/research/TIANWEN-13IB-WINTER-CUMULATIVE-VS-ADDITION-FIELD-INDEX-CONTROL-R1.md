## 有原印照片支持的交叉校核
早稻田第33册 PDF 第23页（13BJ）同一个「十八日」表头下：**盈缩加分 B = 四百一十九一一六三（4191163）**；**盈缩积 C = 八千〇〇〇二六九七（80002697）**。这两栏各由独立、来源原 RGB 哈希绑定的裁剪支持。

韩国国史编纂委员会 NIKH《高丽史》卷52的**现代编辑文字**：D17 B=4243711、C=80002697；D18 B=4191163、C原样为九位字串「八千四百二十四六四〇八三」。于是原印D18的B与现代D18相同，原印D18的C却与现代D17相同。**同一行不同栏的对应日序不同，足以排除这里“所有栏统一平移一天”的解释。** 原印D19 C=84246408，D20 C=88437571；相邻差4243711、4191163分别和现代D17 B、原印D18 B同数。这些是局部原印、现代编辑文本和算术的三种证据；不等于证明一条整表索引法则。
