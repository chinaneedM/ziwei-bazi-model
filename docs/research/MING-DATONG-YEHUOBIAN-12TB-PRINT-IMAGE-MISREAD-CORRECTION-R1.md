# 天问12TB：CADAL／1174 两项原页误读的前向更正

本轮重新从此前GitHub Actions的源图atlas读取CADAL02096915第121页（SHA256 `5e4f288f257a83b8f851c53c791dd2d2df52e18bd66276256ef6b64e546894a6`），并对比《续修四库全书》1174册PDF第506页（SHA256 `ece3094a332ca5f329a1c21f27f3e65a3412a2ad252452cae5a17fe50fd0ac11`）。两幅图像经人工放大重新校读，发现：

- 12QE 的CADAL「禁中**宮**漏」实际是「禁中**官**漏」。
- 12SX 的1174「夏至日入戌初**二**刻」实际是「戌初**三**刻」。
- 12TA据此生成的「三份影像各自一／二／三刻」结论撤回。旧记录保留，新裁决以12TB为准。

**影像配准独立控制：** 对两份已经核验SHA256的JPEG按登记矩形裁剪，灰度SIFT共得到2045组Lowe比率通过点，其中1842个RANSAC内点（90.07%），中位重投影误差0.335像素；仿射近似布局与完整字符笔画极为接近，配准后原始灰度相关0.954，Gaussian sigma2预处理后相关0.991。配准结果说明两幅现存页图的原版布局与字形有极强近似性，**不是**鉴定同一馆藏实物、同一数字原始照片、或1869年修版年代的最终结论。

因此，现有可见目标影像仅支持「戌初一刻」与「戌初三刻」两种夏至日入读法；「戌初二刻」仍见于现代接受文本，但未由本组独立原印目标影像证实。
