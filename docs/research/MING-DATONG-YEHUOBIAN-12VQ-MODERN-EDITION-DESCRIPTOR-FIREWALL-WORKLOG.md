# 12VQ — 现代引文的「影印」与「排印」证据防火墙

**目标没有变：1827、1869 年扶荔山房体系主题卷20《改造漏刻》四处原字。** 本轮仍未获得原刻目标页。

本轮直接视觉阅读《明代研究》第44期（期刊官网）陈冠华论文书目，PDF 第34页（零起第33页）、印刷页146，出现「沈德符撰、謝興堯斷句…北京：中華書局，1997，據清道光七年（1827）姚氏扶荔山房刻本影印」的现代书目表述。该文研究主题为画卷，未提供《改造漏刻》古书原页。尤其「影印」只是作者书目用语，不可据此认定1997实体中该段实际为原刻页复印，或将其标成1827实体古本票。

香港中文大学历史系 HIST3110 官方页面中，**2014/15页内另嵌旧2011/12纲要**，第二课 D 记1959中华书局本「据1827刻本排印」。此条只与1959本有关，不能反证1997本的书体；同理不证明1959每页具体印刷状态。二者**描述的是不同现代书籍，不是可以直接裁决的同一本书互相矛盾**。两项现代间接书目仅提供形式术语核查线索，不构成原刻页文本校勘。

严格保留：撰写年代、1827原刻年、1959现代版、1997现代版、2011/12旧教学纲要、2014/15网页、2026期刊版本分开；「据某刻本」不能逆推出馆藏实体同一或底版未经过改排校勘。
