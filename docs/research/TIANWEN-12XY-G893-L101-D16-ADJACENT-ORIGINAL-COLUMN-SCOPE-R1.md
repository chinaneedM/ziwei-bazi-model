# 天问 12XY — G893 太阴 L101 / 太阳 D16 原页邻行与栏目几何限定

## 1. 来源、原版与复验

原始物件为首尔大学奎章阁 **奎貴893 / GK00893_00《授時曆立成》一件馆藏**。复用此前正式采集的完整原 JPEG 档案（GitHub run `35324088110` / artifact `10538746764`，ZIP 33,525,981 字节，SHA-256 `ee9ecf1de3bb6abe5678e0f8ec8383ef985051e77d091ee40840756e57081107`），本轮独立通过压缩包 CRC、原始 JPG 204/204 SHA 比对。

本轮不是网上目录再查询，也不是重复下载204张；研究重点是针对已经定位却未核定栏目身份的两项目标新增 **5 个不同源页、8 处原始 RGB 区域**的页级/邻日证据，并逐一绑定页源 URL、原始 JPG SHA、像素坐标及裁剪字节 SHA。全部属于同一物理见证。原始 JPG 不存入公开仓库。
