# 天问 12XL：旧卷页图审查快照只增不改，允许未来真证据封闭

## 原发现及修正

12XK 将国图 411999003250 唯一物理馆藏 10 数字册／1030 页、1027 正文页的有限标题/主题视觉筛查登记到 `TW-OPEN-0009`，并正确拒绝“低清首轮审查等于全文不存在”的无据结案。

复核发现两项独立工程缺口：

1. 上一版跨提交比较允许借一个包含 `reason/evidence_refs` 的普通历史事件直接改写 `source_page_coverage`。这会破坏早期快照的前向可审计性。
2. 上一版只要有 `source_page_coverage`，就永久禁止 `RESOLVED_WITH_EVIDENCE`，即使将来获准取得原叶、做完整高分辨率校勘也无法正常结案；这与“真实证据能够修订判断”的宪章冲突。

现将历史 `source_page_coverage` 完整冻结。后续真正新证据只能新增 `source_page_coverage_revisions`，同时包含对应源 JSON Git Blob、馆藏身份、具体原叶、原图 SHA256、来源 URL、人工复核者及时间、直接字形阳性或全正文高清逐行阴性的明确类型。实际证据文档须含等值 `source_page_review_revision`，由 CI 复算 Git Blob 哈希并核对页/馆藏/复核类型。历史修订项不可被删除、重排或覆盖；增加时必须有可回放的历史事件。只有出现符合上述条件的新独立源页证据和明确结案凭证，才准改变 issue 状态。**本轮不产生任何这类新证据记录，11 项仍 OPEN/BLOCKED。**

## 图像精度作用域再澄清

12SH 源 PDF 第十数字册使用 **85dpi 派生 JPEG**；前九册各自有独立图像来源及参数，不能写成“1030 页全部 85dpi”。无论影像派生精度，过去 1027 页已进行的有限标题/主题初筛都不是逐行全文校勘。已有 `source_page_coverage` 的泛化标签保留作为历史快照，而将正确解释写入只增不改的 `source_page_coverage_interpretation`；不以修改旧快照掩盖之前的宽泛用词。

- 1827 大木、1869 仓石馆藏目录的卷二十仍无机构提供的原叶影像，本次公共检索未取得独立可确证的字形。
- 不将目录字段、书名、年份、现代复刻照片或搜索引擎文本转换为古刻页票数。
- 研究矩阵 222/222、缺陷修复 45/45、来源 647+59=706、图谱 252 节点／238 关系、487 个正式批次、11 项未结台账均保持；R1 排盘 CLOSED，算法重开0。
- 修复只涉及连续性机制；未来允许证据推翻旧状态，但必须保留旧断言的确切文件、时间、作用域及修订链。
