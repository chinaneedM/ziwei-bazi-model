# 天问12TE：所谓《万历野获编》明刊本与早期旧钞本的证据层级

本轮直接读取北京大学《中国典籍与文化》期刊官方文章页面（[杜学林，2019年第2期，25–29页](https://ccj.pku.edu.cn/Article/info?aid=235967606)），并用[西北大学文学院作者履历](https://wxy.nwu.edu.cn/info/1018/1084.htm)独立核对文章名称、作者、刊物和年份。

## 本轮得到什么

期刊官方摘要记载杜学林的版本学判断：所谓《万历野获编》「明刊本」说证据不足；李慈铭所称不同于钱枋整理本的「明刊本」，作者认为可能实为周星诒旧藏、今藏台湾的旧钞本，且该旧钞本可能保留1619年沈德符编定旧貌。

**这是经过核实的2019年学者论点，不是本轮直接鉴定了明刊原书或1619年沈德符手稿。** 本轮没有读到论文全文、该台湾抄本的〈改造漏刻〉页、1827未修印次原页、1869重校刊补原页，因而不能从该学说得到一条可用的晚明计时数值或早期传承直系。

## 针对当前《改造漏刻》门禁

1. 分开「作者初稿/1619定稿」「后世旧抄」「钱枋等重编系统」「1827姚氏刊本」「1869补修状态」「2002数字影印」，不以卷名、文字相同或一段论文摘要强行识别版刻实物。
2. 12TB已校定的CADAL p121和1174册p506读法仍为宮禁／官漏／辰初二刻／戌初三刻；两份数字图像高度配准仍不证明两份独立1827/1869原印实物。
3. 《野获编》的文本源流学说不能替代《改造漏刻》四点原页直读，更不能决定1447/1450计时制度或重新打开排盘算法。
4. 新增来源仅一条，标为BIBLIOGRAPHIC_METADATA_ONLY，绝无原始字形权威；来源根登记647，扩展14，合计661唯一ID，传承图节点248、边235不变。

结论：已确认一种对「明刊本」祖本假设具有挑战性的专业学说，并做了证据降级记录；未获得新原刻目标叶，MD-G03仍OPEN，产品R1维持CLOSED。
