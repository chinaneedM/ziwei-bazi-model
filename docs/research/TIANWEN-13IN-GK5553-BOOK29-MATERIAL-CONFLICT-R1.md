# 天问13IN｜奎5553第29册材质与1972影印的来源张力

首尔大学奎章阁官方[奎5553目录](https://kyudb.snu.ac.kr/book/view.do?book_cd=GK05553_00)将整套《高麗史》标为乙亥字，同时明确第8、26、29册系**補寫本**；其[第一方馆藏综述](https://kyudb.snu.ac.kr/brd/viewBrd.do?book_cate=HEJ23&focus=d11sd114&listChk=tree&menuId=10022&mid=HEJ&postSeq=10775&siteCd=DBSP)将第29册与卷81–83对应。整套目录的版式或版本标签不能直接提升为每册每叶的金属活字字形证据。

与之相对，2020年魏志江、陈卓发表于《史学史研究》的[原刊PDF](https://sir.sysu.edu.cn/sites/default/files/2026-07/%E9%AB%98%E4%B8%BD%E5%8F%B2_%E7%89%88%E6%9C%AC%E6%BA%90%E6%B5%81%E4%B8%8E%E7%BC%96%E7%BA%82%E4%BD%93%E4%BE%8B%E8%80%83_%E9%AD%8F%E5%BF%97%E6%B1%9F.pdf)第100页注⑥称1972年影印以奎5554为底本，未利用奎5553，其中卷31、77、78、79、81、82本可采用乙亥字本。对卷81/82，这与官目第29册的**补写本**分类形成材料层级张力。

本批**只新建OPEN冲突，不直接判论文错误**；后续必须读取馆方奎5553第29册卷81/82原影及1972影印本同卷实页，判断是否混配或学术用语泛指。此证据不解决独立的奎3467第六册卷52原表首、版心缺页、G893六项历史数字；不存在新古籍字形投票、算法缺陷、传承边。Matrix 222/222、外源761、图252节点238边、11风险、产品CLOSED不变。中山大学PDF原始字节SHA仍未核得。
