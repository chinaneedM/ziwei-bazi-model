# 天问12ZB｜追回已登记《高麗史》原页证据，交叉定位奎章阁不同版本

## 复核发现：早有来源级古籍影印判读，不应当作新增馆藏

在根来源注册表中找到 `EXT-COMMONS-CADAL-GORYEOSA-V52-FACSIMILE`，其前期研究 `GORYEOSA-V52-CADAL-FACSIMILE-CONTROL-READINGS-R1.json` 明确记载公开 [CADAL02050311《高麗史（四十九）》DjVu 容器](https://commons.wikimedia.org/wiki/File:CADAL02050311_%E9%AB%98%E9%BA%97%E5%8F%B2%EF%BC%88%E5%9B%9B%E5%8D%81%E4%B9%9D%EF%BC%89.djvu) 内部其实是《高麗史》卷五十二、志第六、曆三。扫描页 **39** 已由 33968138492 / artifact 9970086664 完成非 OCR 人工原影阅读，第16日直接可见 **五分一三六二**（5.1362，HIGH）。该工作流 artifact 的 SHA-256 是整体工作流产物摘要，**不是新增本轮原图页像素哈希**。

这意味着 12YY–12ZA 的“**NIKH 此条目的原图尚未取得**”只能在该官方页面自身的图像对象层成立；不能扩展成“《高麗史》卷52 D16 还没有任何已核的影印来源”。CADAL 为**已有**的受传影印见证，不得计作新发现纸本或十五世纪原刻。底本实物馆藏、印次、日期及与 NIKH 官网页图的实体关联仍未绑定。
