# 天问 14Z｜朝鲜1430试书短题与1466命课学官制的证据分层

核验日：2026-11-19。执行广度优先双史纲；复用14W–14Y已登记的韩国原史录与书目，不重登记1430《世宗实录》短题。本批新增一件1466官方《世祖实录》**受读数字汉文转录**来源；尚未取得刊刻原叶，不是原印字形裁决。

## 一、1430《世宗实录》取才书目：汉文数字转录的两个短题

官方《世宗实录》卷47，世宗十二年三月十八日（1430）第二则在「陰陽學：...星命卜課」下列有《紫微數》《皇極數》《袁天綱》《五行精紀》以及《三車一覽》。在网站**汉文「原文」展示**中，《袁天綱》与《五行精紀》之间明确有闭合、重开书名号，按当前数字标点是**两个并列题目**；同页韩文国译呈「袁天綱五行精紀」连读的译名，不得未经异本核读就把其推成某个「袁天纲著《五行精纪》」的单独目录条目。

- 原史录数字汉文：[1430原史录 id=kda_11203018_002](https://sillok.history.go.kr/id/kda_11203018_002)（汉文显示；卷47 / 14册28张A面之馆方定位，**未直接打开该物理叶**）。
- 正面资格：1430年的官署取才条目在现存史录受读系统内**分别出现**紫微与四柱/禄命相关题名，可供两条史纲交叉检索。
- 限制：网站现代添加的书名号是否能逐字代表古刻分隔，仍须校核原影和其他校本；即便确认分列，也**不证明**所见《五行精紀》就是今日廖中辑本的某一实物版、袁天纲亲著该书、特定规则被考核或存在从唐至朝鲜的直系师承。

## 二、1466《世祖实录》官制条：制度名称而非术书同版

官方《世祖实录》卷38，世祖十二年正月十五日（1466）记改定官制，其中数字汉文原文直接写：

> 「書雲觀改稱觀象監」；「陰陽學改稱命課學，置訓導二。」

并列「風水學改稱地理學」与「天文學，置敎授、訓導各一」，显示**命课学、天文学、地理学是同段官署职制的不同项目**。这是制度和术语使用的历史节点，不是古书中「命课学」具体排盘算法的证明。

- 来源：[1466官方数字史录 id=kga_11201015_001](https://sillok.history.go.kr/id/kga_11201015_001)（卷38，太白山史库本14册4张B面定位；**数字汉文转录，不是原版原叶直接审读**）。
- 此条可与1430「阴阳学」用语构成**文献年代先后、制度名称变更**的有据对照，却不证明1430名单所有书在1466后仍用、增删、读到或与1520年前后的刊本逐篇对应。
- 禁止把「命課學」与现代「四柱八字」划完全等号；不把书雲观→观象监迁衍成某一斗数师承边。

## 三、与14W–14Y的连续性及待补证
