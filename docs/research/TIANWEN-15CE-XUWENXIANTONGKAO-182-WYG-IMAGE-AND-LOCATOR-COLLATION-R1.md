# 天問15CE｜《欽定續文獻通考》卷182：十卷萬氏著錄原圖與網頁錯位定位的限界

日期：2026-11-23。接15CD的現代《明史》校勘記第5條，核查其明引的清代官修書目《欽定續文獻通考》卷182，不重寫15CB–15CD舊批。此為**廣度優先的清代書志／明代星學傳播接受史補格**，不是紫微斗數四化算法重開。

## 一、真正可見的資料層

1. [書庫卷182的分段數字轉錄](https://hhl.cnkgraph.com/Book/%E5%8F%B2%E9%83%A8/%E6%94%BF%E6%9B%B8%E9%A1%9E/%E6%AC%BD%E5%AE%9A%E7%BA%8C%E6%96%87%E7%8D%BB%E9%80%9A%E8%80%83/1406/KR2m0014_182)在「五行」明段列「萬民英星學大成十卷　三命通會十二卷」，後敘萬氏「字育吾、大寧都司人、嘉靖進士」；這是可定位的**清代編纂書目在現代網站的轉錄**。
2. 直接打開 [WYG0630-0436b PNG](https://c.sou-yun.com/kanripoimgs/KR2m0014/WYG0630/WYG0630-0436b.png)，可在圖中讀出「萬民英」「星學大成十卷」「三命通會十二卷」及相鄰著錄。證據作用域是**所見數字圖像的十卷／十二卷文字和萬氏列位**，強於單靠無圖轉錄；WYG編號、網站寄存與清代實物版印年代之間的同一性、藏號和物理葉位，本批未獨立認證。
3. 存在可重放的**圖文索引錯位**：同一 HTML 將該段標為「第14b頁／WYG0630-0432b」，但 [WYG0630-0432b實際PNG](https://c.sou-yun.com/kanripoimgs/KR2m0014/WYG0630/WYG0630-0432b.png)顯示的是另一頁的著錄而非萬氏段；真正含萬氏段的圖像URL為0436b。**不能把轉錄標註的14b直接說成0432b圖的實見葉位**，亦不把所觀測索引差異擅自解釋為原書缺頁或裝訂錯簡。站點映射成因與可靠物理頁碼保持未決。

## 二、15CD《明史》十八卷點校移正的論證邊界

15CD所引數字《明史》卷98校勘記5明說：原十八卷條曾緊隨陸位《星學綱目正傳》二十卷，後據嵇璜《續文獻通考》卷182及文津閣《四庫全書》改列萬民英。**本批確認所據《續文獻通考》明列的卻是《星學大成》十卷，不是十八卷。** 所以這個引據可支持清代官修書志有「萬民英／星學大成」關聯，卻不能越級推出「十八卷本已由該清書目原頁直接證實萬民英所撰」、十卷與十八卷為同一現存實物、或其條文為萬曆原刻內容。這不是推翻該校勘，而是標清**編者綜合判斷與原書逐字載錄**之差別。

清《四庫總目》十卷本、文淵閣傳本三十卷、俄藏清抄五卷、清人著錄十八卷，仍按作品、版本、實物、數字替身四軸分離，不以卷數四票裁決一套原稿。另卷182「徐子平徐氏珞琭子賦注二卷」「子平事跡無考」為清人對宋書志條目的編輯接受史，不是宋代徐氏原撰與術法實現的現物證據，應與四柱史綱已有的宋元禄命材料分開。
