# 天问 13AN｜日本国立公文书馆《高麗史》清写本128册与2022数字化计划：册次／卷次防火墙

## 直接检索结果

日本[国立公文书馆数字档案《高麗史》检索结果](https://www.digital.archives.go.jp/search?fond=1073275&lang=en&page=1)的馆方记录显示内阁文库请求号 **282-0006**，书目按 **写本：清** 描述，共 **128冊**。子项目有「高麗史５２」，但该条使用的字段是 **Book Order/冊次 0052、Subject No./件名番号 0052**；**不能把第52册直接等同《高丽史》正文卷52**。已见的资料目录只能证明机构级馆藏和册次，不证明该册收录目标太陽盈縮表。

馆方正式文件[《複製物の作成作業時期について》（2022-07-13）](https://www.archives.go.jp/news/pdf/20220713.pdf) **PDF第20页（从0起页序19）** 的「別紙4 デジタル画像作成対象一覧・内閣文庫（漢籍）」明确列 **282-0006 高麗史**。此为2022年度的**待制作清单**，不是完成报告；邻近清单说明另警示，保存状况可能导致年度内无法完成数字化。

本批核实两项官方资料，但没有取得第52卷的原叶，亦没有确定网页的「Open」利用状态是否对应现存可下载影像。「已列入数字化计划」不可提升为「可访问数字扫描」；「清写本」只是馆目年代／资料类别断言，不能作为原本抄写年代的物理考据结论。
